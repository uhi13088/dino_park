# 1. 게임 개요

## 1.1 컨셉

**"미지의 섬에서 시작하는 공룡 파크 건설"**

짧은 세션마다 섬의 비밀을 하나씩 발견하고, 조각조각 이어지면서 거대한 파크와 스토리가 완성되는 구조. 마치 매일 한 편씩 보는 드라마처럼.

## 1.2 장르

- 타이쿤 / 경영 시뮬레이션
- 방치형 + 능동형 하이브리드
- 스토리 드리븐

## 1.3 타겟 플랫폼

- **앱인토스** (토스 앱 내 미니앱)
- 추후 스탠드얼론 앱 확장 고려

## 1.4 타겟 유저

- 캐주얼 게이머 (20~40대)
- 타이쿤/경영 시뮬 팬
- 공룡/자연 콘텐츠 선호층

## 1.5 핵심 가치

| 요소 | 설명 |
|------|------|
| **접근성** | 라이트하게, 누구나 무료로 시작 |
| **수집욕** | 공룡, 위인, 기믹, 장식 수집 |
| **성장감** | Lv.25까지 장기 성장 목표 |
| **스토리** | 섬의 비밀을 파헤치는 서사 |
| **소셜** | 다른 플레이어 파크 방문 및 교류 |

## 1.6 콘텐츠 규모

| 콘텐츠 | 수량 | 비고 |
|--------|------|------|
| **스토리 챕터** | 6개 | 프롤로그 + 챕터 1~6 |
| **엔딩** | 4가지 | 희망의 새벽, 새장 속 평화, 필요악 + 히든 엔딩 |
| **공룡** | 82종 | 초식 25, 육식 25, 익룡 12, 해양 10, 하이브리드 10 |
| **위인** | 50명 | 8개 카테고리 (과학자, 건축가, 경영인, 탐험가, 조련사, 수의사, 보안, 특수) |
| **건물** | 50종 | 공룡시설 9, 관람시설 6, 쇼시설 4, 편의시설 7, 생산시설 8, 연구시설 5, 운영시설 6, 장식 5 |
| **기믹** | 30종 | 탐험 발견 오브젝트 |

## 1.7 앱인토스 최적화

- 3초 내 로딩 (최적화된 2.5D 아트, 점진적 로딩)
- 세로 모드 기본 (가로 옵션 제공)
- 토스 로그인 연동
- 토스페이 결제
- 푸시 알림 활용

# 2. 핵심 게임 루프

## 2.1 5분 세션 (Daily Loop)

```
접속
  ↓
오프라인 수익 수집 (방문객 입장료)
  ↓
공룡 상태 체크 (배고픔, 기분)
  ↓
오늘의 미션 1~2개 수행
  ↓
보상 획득 → 다음 접속 예고 (떡밥)
```

## 2.2 장기 루프 (Story Progression)

```
탐험 → 기믹 발견 → 파크 발전 → 관광객 증가
  ↓                              ↓
  ↓                           수익 증가
  ↓                              ↓
  └──── 위인 영입 ◄── 위인 포인트 ◄┘
              │
              ▼
      ┌──────┴──────┐
      │             │
   DNA 연구      시설 강화
      │             │
      ▼             ▼
하이브리드 공룡   특수 건물
      │             │
      └──────┬──────┘
             │
             ▼
      관광객 폭발 증가
             │
             ▼
       소셜 방문 유입
             │
             ▼
      위인 포인트 획득
             │
             ▼
         (루프 반복)
```

## 2.3 세션 플레이 패턴

- **짧은 세션**: 5~10분 (일일 관리, 수익 수집)
- **중간 세션**: 20~30분 (탐험, 건설, 미션)
- **긴 세션**: 1시간+ (스토리 진행, 이벤트)

짧은 세션이 이어지면서 결국 긴 이야기를 완성해가는 구조.

# 3. 스토리 & 챕터 시놉시스

## 3.1 메인 스토리 개요

### 배경 설정

주인공은 해양 생물학자로, 미지의 해역을 탐사하던 중 거대한 폭풍에 휩쓸린다. 정신을 차려보니 지도에도 없는 신비로운 섬에 표류해 있었다. 그리고 그곳에서 불가능한 존재를 마주한다 — **살아있는 공룡**.

구조를 기다리며 생존하던 주인공은 점차 이 섬의 비밀에 이끌린다. 왜 이곳에만 공룡이 살아있는가? 누가 이 섬을 만들었는가? 그리고 떠오르는 한 가지 생각:

**"이 섬을 세계 최초의 공룡 테마파크로 만들면 어떨까?"**

### 핵심 미스터리

1. **공룡의 기원**: 왜 이 섬에만 공룡이 있는가?
2. **선대 연구자**: 주인공보다 먼저 이 섬에 온 사람들은 누구인가?
3. **섬의 에너지**: 섬 중심부에서 느껴지는 이상한 에너지의 정체는?
4. **창조주의 유산**: 이 모든 것을 만든 존재는 누구인가?

---

## 3.2 챕터별 상세 시놉시스

### 📖 프롤로그: 표류

**플레이 타임**: 약 10분 (튜토리얼)

#### 스토리

```
[오프닝 시네마틱]
거친 파도, 번개가 치는 밤바다.
연구선이 요동친다.

주인공(나레이션):
"태평양 심해 생태계 조사... 평범한 탐사가 될 줄 알았다.
그날 밤, 해도에도 없는 폭풍을 만나기 전까지는."

[암전]

[눈을 뜨는 장면]
따스한 햇살, 파도 소리.
하얀 모래사장에 쓰러진 주인공.

주인공: "...여기가 어디지?"

일어나서 주변을 둘러본다.
열대 정글이 우거진 해변.
그런데 저 멀리 숲에서—

[땅이 울린다]

거대한 그림자가 나무 사이로 지나간다.
길고 긴 목... 거대한 몸집...

주인공: "...브라키오사우루스?"

[타이틀 등장]
🦕 다이노 파크 타이쿤
```

#### 게임플레이

- 기본 조작 튜토리얼
- 해변가에 임시 캠프 건설
- 첫 공룡(브라키오사우루스) 관찰
- 섬 선택 화면으로 이동

---

### 📖 챕터 1: 생존

**플레이 타임**: 약 2~3일  
**구역**: 해변가 ~ 해안 숲

#### 스토리 요약

표류 후 생존이 급선무. 해변가에 기지를 세우고 주변을 탐색한다. 초식공룡들이 평화롭게 풀을 뜯는 모습을 발견하고, 주인공은 이들과 공존하며 살아남기로 결심한다. 탐험 중 낡은 연구 노트 조각을 발견 — 누군가 먼저 이 섬에 왔었다.

#### 주요 이벤트

| 순서 | 이벤트 | 내용 |
|------|--------|------|
| 1-1 | 첫 번째 밤 | 안전한 잠자리 확보, 횃불 제작 |
| 1-2 | 풀뜯는 거인들 | 초식공룡 무리 발견, 관찰 시작 |
| 1-3 | 식량 문제 | 농장 시스템 해금, 자원 채집 |
| 1-4 | 의문의 노트 | 해안 동굴에서 연구 노트 발견 |
| 1-5 | 첫 손님 | 표류자 NPC 등장 (조력자) |

#### 해금 콘텐츠

- **건물**: 임시 캠프, 기초 울타리, 관찰 초소
- **시설**: 벌목장, 채석장, 농장
- **공룡**: 브라키오사우루스, 트리케라톱스, 파라사우롤로푸스
- **시스템**: 탐험, 자원 수집, 기초 건설

#### 챕터 1 엔딩

```
[연구 노트를 읽는 주인공]

노트 내용:
"...믿을 수 없다. 이 섬은 단순한 자연이 아니다.
누군가 의도적으로 만들어낸 것이다.
DNA 복원 기술... 가능할 리가 없는데..."

[마지막 페이지는 찢겨 있다]

주인공: "이 노트의 주인은 대체 누구지?
그리고... 그는 지금 어디에 있는 거야?"

[숲 깊은 곳에서 울리는 으르렁거리는 소리]

주인공: "...저건 초식공룡 소리가 아닌데."
```

### 📖 챕터 2: 공존

**플레이 타임**: 약 5~7일  
**구역**: 숲 지대 ~ 계곡 입구

#### 스토리 요약

숲 깊은 곳에서 소형 육식공룡들을 발견한다. 처음엔 위협적이었지만, 주인공은 그들의 행동 패턴을 분석하고 안전한 공존 방법을 찾아낸다. 그러던 중 숲 속에서 버려진 연구 시설의 잔해를 발견한다. 이곳에서 "프로젝트 제네시스"라는 문서를 찾게 된다.

#### 주요 이벤트

| 순서 | 이벤트 | 내용 |
|------|--------|------|
| 2-1 | 사냥꾼들 | 벨로시랩터 무리 조우, 도주 |
| 2-2 | 행동 분석 | 육식공룡 패턴 학습, 회피 전략 |
| 2-3 | 울타리의 중요성 | 보안 시스템 해금 |
| 2-4 | 폐허의 연구소 | 버려진 시설 발견 |
| 2-5 | 프로젝트 제네시스 | DNA 복원 기술 문서 획득 |
| 2-6 | 두 번째 표류자 | 자칭 "과학자" NPC 등장 |

#### 해금 콘텐츠

- **건물**: 보안 울타리, 육식공룡 우리, 관람 데크
- **시설**: 기초 연구소, 부화장
- **공룡**: 벨로시랩터, 딜로포사우루스, 코엘로피시스
- **시스템**: 보안 시스템, DNA 추출 기초, 관람객 시스템 시작
- **위인**: 헬렌 박사 (고생물학자) 영입 가능

#### 핵심 대화

```
[연구소 폐허에서]

자칭 과학자 (새 NPC):
"프로젝트 제네시스... 들어본 적 있어요.
20년 전, 천재 유전공학자가 시작한 프로젝트.
멸종된 생물을 되살리겠다는..."

주인공: "그럼 이 공룡들은 자연적인 게 아니라..."

과학자: "누군가 만들어낸 거죠. 의도적으로.
문제는... 왜? 그리고 그 사람은 지금 어디에?"
```

#### 챕터 2 엔딩

```
[연구소 지하에서 발견한 대형 스크린]

[스크린이 깜빡이며 켜진다]
오래된 영상 기록.

영상 속 인물:
"기록 #147. 실험은 성공적이다.
첫 번째 복원 개체... 브라키오사우루스가 깨어났다.
하지만 이건 시작에 불과해.
진정한 목표는 '그것'의 복원이다..."

[영상이 끊긴다]

주인공: "'그것'? 뭘 복원하려던 거지?"

[지도 화면에 새로운 구역 표시: 계곡 지대]

주인공: "저 계곡... 뭔가 있어."
```

### 📖 챕터 3: 발견

**플레이 타임**: 약 7~10일  
**구역**: 계곡 ~ 절벽 지대

#### 스토리 요약

계곡 탐험을 시작한다. 이곳에서 하늘을 나는 공룡 — 익룡을 발견한다. 또한 계곡 깊은 곳에서 거대한 화석 발굴 현장의 흔적을 찾는다. 누군가 체계적으로 공룡 화석을 발굴하고 있었다. 그리고 절벽 위에서 의문의 인물을 목격한다.

#### 주요 이벤트

| 순서 | 이벤트 | 내용 |
|------|--------|------|
| 3-1 | 하늘의 지배자 | 프테라노돈 무리 발견 |
| 3-2 | 비행 관측소 | 익룡 돔 건설 시작 |
| 3-3 | 화석 발굴장 | 대규모 발굴 현장 발견 |
| 3-4 | 그림자 인물 | 절벽 위 의문의 인물 목격 |
| 3-5 | 첫 번째 관광객 | 구조 요청이 닿음? 관광객 시스템 본격화 |
| 3-6 | 파크의 시작 | 정식 테마파크 선언 |

#### 해금 콘텐츠

- **건물**: 익룡 돔, 사파리 투어, 매표소, 편의시설
- **시설**: 화석 복원실, 발전소
- **공룡**: 프테라노돈, 디모르포돈, 케찰코아틀루스
- **시스템**: 정식 관광객 유치, 쇼 프로그램
- **위인**: 다니엘 (탐험가), 소피아 (마케터) 영입 가능

#### 핵심 대화

```
[화석 발굴장에서]

주인공: "이건... 전문 장비잖아.
취미로 할 수 있는 규모가 아니야."

[거대한 발자국 화석 발견]

주인공: "이 크기는... 티라노사우루스?
아직 살아있는 티라노를 본 적은 없는데..."

[절벽 위, 망원경으로 관찰하는 그림자]

그림자: "...드디어 여기까지 왔군."

[그림자가 사라진다]
```

#### 챕터 3 엔딩

```
[파크 개장식]

주인공: "오늘부터 이곳은 '다이노 파크'입니다.
전 세계에서 유일하게 살아있는 공룡을 만날 수 있는 곳."

[관광객들의 환호]

하지만 축제 분위기 속에서—

[섬 깊은 곳에서 들려오는 거대한 포효]

ROOOOOAAAARRRR!!!

모든 관광객이 얼어붙는다.

주인공: "...저건 뭐지?"

헬렌 박사: "저 소리... 티라노사우루스예요.
그것도 엄청나게 큰 개체."

[지도에 새로운 구역 표시: 화산 지대]

주인공: "화산 지대에 뭐가 있는 거야?"

## 5.2 기믹 카테고리

| 카테고리 | 효과 유형 | 예시 |
|----------|-----------|------|
| **자원** | 자원 생산량 증가 | 광산, 수맥, 희귀 식물 군락 |
| **시설** | 특수 건물 해금 | 온천 스파, 전망대, 비밀 연구소 |
| **공룡** | 희귀 공룡 해금/버프 | 둥지 발견, DNA 샘플, 변이체 |
| **수익** | 입장료/매출 증가 | 포토스팟, 자연 경관, 유적지 |
| **편의** | 플레이 편의성 | 빠른 이동, 자동 수집, 저장고 |

## 5.4 기믹 발견 시스템

```
탐험 출발 (에너지 소모)
    ↓
탐험 구역 선택 (해금된 구역 중)
    ↓
[탐험 결과] - 랜덤
├── 일반: 자원, 경험치
├── 기믹 발견! (확률)
└── 스토리 이벤트 (확률)
    ↓
기믹 발견 시
→ 컷신 + 도감 등록
→ 효과 즉시 적용 or 건설 필요
```

- Lv.10: 최종 강화 + 궁극 스킬 해금
```

## 10.5 위인 조합 시너지

| 조합 | 시너지 이름 | 효과 |
|------|-------------|------|
| 닥터 진 + 헬렌 박사 | **황금 연구팀** | DNA 연구 시간 -50% |
| 다니엘 + 나탈리 | **트레저 헌터** | 희귀 기믹 발견 확률 2배 |
| 소피아 + 민지 | **바이럴 마스터** | 주간 관광객 이벤트 상시 발동 |
| 올리버 + 유나 | **공룡의 수호자** | 공룡 관리 완전 자동화 |
| 마르코 + 빅터 | **미래 건설** | 특수 시설 건설 비용 -40% |

# 11. 소셜 시스템

## 11.1 파크 방문

**"다른 섬의 공룡도 만나보세요"**

### 방문 시스템

```
[파크 방문 메뉴]
├── 랜덤 방문 (하루 3회 무료)
├── 친구 파크 (친구 목록에서)
└── 추천 파크 (인기/테마별)
    ↓
[방문 중]
- 구경 모드 (터치로 돌아다니기)
- 공룡 도감 미리보기
- 좋아요 / 응원 메시지 남기기
    ↓
[방문 보상]
- 방문자: 위인 포인트 획득
- 파크 주인: 방문자 수에 따른 보너스
```

### 상호 이익 구조

| 행동 | 방문자 보상 | 주인 보상 |
|------|-------------|-----------|
| 방문 완료 | 위인 포인트 +10 | 명성 +5 |
| 좋아요 | 위인 포인트 +5 | 명성 +10, 골드 보너스 |
| 공룡 사진 찍기 | 도감 스탬프 | - |
| 응원 메시지 | - | 다음 접속 시 버프 |

## 11.2 협동 이벤트

```
[대륙 연결 프로젝트]
- 전체 유저 기여도 합산 → 공동 보상

[선물 시스템]
- 하루 1회 친구에게 자원 선물
- 받은 선물함 → 광고 시청으로 2배
```

# 12. 엔드게임 콘텐츠

## 12.1 콘텐츠 총정리

| 콘텐츠 | 해금 조건 | 갱신 주기 |
|--------|-----------|-----------|
| 🌊 시즌 시스템 | 아무나 | 3개월 |
| 🏆 프레스티지 | 주요 건물 5개 Lv.25 | 영구 |
| 🌋 월드 보스 | 챕터 5 클리어 | 주간 |
| 🏝️ 신규 섬 확장 | 현재 섬 완료 | 분기별 |
| 🎪 시즌 이벤트 | 상시 | 2~4주 |
| ⚔️ 파크 리그 | 파크 점수 10,000+ | 주간 |
| 🗺️ 무한 탐험 | 모든 구역 해금 | 상시 |
| 🧬 DNA 마스터리 | DNA 연구소 Lv.25 | 상시 |
| 👑 전설 퀘스트 | 전 시설 Lv.20+ | 상시 |

## 12.2 시즌 시스템

**3개월마다 새로운 시즌, 새로운 목표**

```
[시즌 1: 빙하기의 귀환]
기간: 90일

- 시즌 한정 공룡 5종
- 시즌 한정 장식 20종
- 시즌 스토리 챕터 3개

시즌 패스:
├── 무료 트랙: 30단계
└── 프리미엄 트랙: 30단계 (💎500 또는 ₩9,900)
```

## 12.3 프레스티지 (환생)

**"모든 것을 내려놓고, 더 강하게 다시 시작"**

### 해금 조건
- 주요 건물 5개 이상 Lv.25 달성
- 메인 스토리 완료
- 공룡 50종 이상 보유

### 유지/초기화

| 유지 | 초기화 |
|------|--------|
| 위인 (레벨 유지) | 건물 레벨 → Lv.1 |
| 공룡 도감 (해금 기록) | 보유 공룡 → 초기 1마리 |
| 프레스티지 포인트 | 자원 → 0 |
| 업적/칭호 | 스토리 진행 → 챕터 1 |

### 프레스티지 보너스

| 프레스티지 | 영구 보너스 |
|------------|-------------|
| 1회차 | 모든 자원 생산 +10% |
| 2회차 | 건설 시간 -10% |
| 3회차 | 공룡 부화 속도 +15% |
| 4회차 | 관광 수익 +20% |
| 5회차 | 위인 포인트 획득 +25% |
| 6회차+ | 프레스티지 전용 건물/공룡 해금 |

# 13. 수익화 모델

## 13.1 개요

**하이브리드 모델**: 광고 + 인앱 결제

**핵심 원칙**: 과금 = 시간 단축, 편의성. **절대 Pay-to-Win 아님**.

## 13.2 광고 (비강제)

| 상황 | 리워드 |
|------|--------|
| 오프라인 수익 2배 | 접속 시 선택 |
| 부화 시간 50% 단축 | 알 부화 시 |
| 무료 탐험 +1회 | 탐험 에너지 소진 시 |
| 일일 보너스 2배 | 미션 완료 시 |
| 업그레이드 1시간 단축 | 건설 중 |

## 13.3 인앱 결제

| 상품 | 가격대 | 내용 |
|------|--------|------|
| **스타터 팩** | ₩3,900 | 프리미엄 공룡 1 + 자원 |
| **월간 패스** | ₩9,900 | 매일 보너스 + 광고 제거 + 건설 슬롯 |
| **시즌 패스** | ₩9,900 | 프리미엄 시즌 보상 트랙 |
| **프리미엄 공룡** | ₩1,900~4,900 | 희귀 공룡 즉시 획득 |
| **다이아 팩** | ₩1,100~109,000 | 다이아몬드 충전 |
| **확장팩** | ₩6,900 | 신규 챕터 조기 해금 |
| **추가 슬롯** | ₩4,900 | 세이브 슬롯 +1 |

## 13.4 무료 플레이 보장

| 요소 | 무료 유저 | 과금 유저 |
|------|-----------|-----------|
| 섬 선택 | 5개 모두 가능 | 동일 |
| 공룡 해금 | 시간 투자로 전부 가능 | 즉시 획득 옵션 |
| 스토리 | 전체 플레이 가능 | 동일 |
| Lv.25 달성 | 가능 (9~12개월) | 빠름 (2~3개월) |
| 탐험 | 1일 에너지 제한 | 에너지 구매 가능 |
| 소셜 방문 | 1일 3회 | 무제한 패스 |

# 14. 기술 스펙
