# 1. 게임 개요

## 1.1 컨셉

**"버려진 공룡 파크를 되살리고, 섬의 비밀을 밝히는 재건 이야기"**

15년 전 폐쇄된 공룡 파크의 후계자가 되어 시설을 재건하고 공룡과 공존하는 미래를 만든다. 짧은 세션마다 섬의 비밀을 하나씩 발견하고, 조각조각 이어지면서 거대한 파크와 스토리가 완성되는 구조. 마치 매일 한 편씩 보는 드라마처럼.

## 1.2 장르

- 타이쿤 / 경영 시뮬레이션
- 방치형 + 능동형 하이브리드
- 스토리 드리븐

## 1.3 타겟 플랫폼

- **앱인토스** (토스 앱 내 미니앱)
- 추후 스탠드얼론 앱 확장 고려

## 1.4 타겟 유저

- 캐주얼 게이머 (20~40대)
- 타이쿤/경영 시뮬 팬
- 공룡/자연 콘텐츠 선호층

## 1.5 핵심 가치

| 요소       | 설명                            |
| ---------- | ------------------------------- |
| **접근성** | 라이트하게, 누구나 무료로 시작  |
| **수집욕** | 공룡, 위인, 기믹, 장식 수집     |
| **성장감** | Lv.25까지 장기 성장 목표        |
| **스토리** | 섬의 비밀을 파헤치는 서사       |
| **소셜**   | 다른 플레이어 파크 방문 및 교류 |

## 1.6 콘텐츠 규모

| 콘텐츠          | 수량  | 비고                                                                                     |
| --------------- | ----- | ---------------------------------------------------------------------------------------- |
| **스토리 챕터** | 6개   | 프롤로그 + 챕터 1~6 + 에필로그                                                                      |
| **엔딩**        | 4가지 | 희망의 새벽, 새장 속 평화, 필요악 + 히든 엔딩                                            |
| **공룡**        | 82종  | 초식 25, 육식 25, 익룡 12, 해양 10, 하이브리드 10                                        |
| **위인**        | 50명  | 8개 카테고리 (과학자, 건축가, 경영인, 탐험가, 조련사, 수의사, 보안, 특수)                |
| **건물**        | 50종  | 공룡시설 9, 관람시설 6, 쇼시설 4, 편의시설 7, 생산시설 8, 연구시설 5, 운영시설 6, 장식 5 |

- 3초 내 로딩 (최적화된 2.5D 아트, 점진적 로딩)

- 토스 로그인 연동
- 토스페이 결제
- 푸시 알림 활용

# 2. 핵심 게임 루프

## 2.0 현재 로컬 프로토타입의 첫 플레이

2026-11-15에 추가했던 구현 현황과 다음 구현 기준은 [최신 게임 기획](current/game-design.md)로 옮겼다. 실제 완료·검증 상태는 [TASK](../TASK.md)를 따른다. 이 구버전 GDD에 최신 사양을 추가하지 않는다.

## 2.1 5분 세션 (Daily Loop)

```
접속
  ↓
오프라인 수익 수집 (방문객 입장료)
  ↓
공룡 상태 체크 (배고픔, 기분)
  ↓
오늘의 미션 1~2개 수행
  ↓
보상 획득 → 다음 접속 예고 (떡밥)
```

## 2.2 장기 루프 (Story Progression)

```
탐험 → 기믹 발견 → 파크 발전 → 관광객 증가
  ↓                              ↓
  ↓                           수익 증가
  ↓                              ↓
  └──── 위인 영입 ◄── 위인 포인트 ◄┘
              │
              ▼
      ┌──────┴──────┐
      │             │
   DNA 연구      시설 강화
      │             │
      ▼             ▼
하이브리드 공룡   특수 건물
      │             │
      └──────┬──────┘
             │
             ▼
      관광객 폭발 증가
             │
             ▼
       소셜 방문 유입
             │
             ▼
      위인 포인트 획득
             │
             ▼
         (루프 반복)
```

## 2.3 세션 플레이 패턴

- **짧은 세션**: 5~10분 (일일 관리, 수익 수집)
- **중간 세션**: 20~30분 (탐험, 건설, 미션)
- **긴 세션**: 1시간+ (스토리 진행, 이벤트)

짧은 세션이 이어지면서 결국 긴 이야기를 완성해가는 구조.

## 2.4 첫 성장 루프 기획 초안 (2026-11-15)

이 초안은 [최신 게임 기획](current/game-design.md), [초반 밸런스](current/balance.md), [공룡 획득·DNA 연구](current/dna-and-collection.md)로 이전·구체화했다. 여기의 이전 수치 예시는 더 이상 구현 기준이 아니다.

# 3. 스토리 & 챕터 시놉시스

> 스토리의 정본은 [스토리 시나리오](dino_park_story_scenario.md)이며, 이 장은 해당 문서의 요약이다. 실제 대사·선택지 데이터는 [`packages/game-data/src/stories/index.ts`](../packages/game-data/src/stories/index.ts)에 관리한다. 스토리 변경 시 정본과 데이터를 먼저 맞추고 이 요약을 갱신한다.

## 3.1 메인 스토리 개요

### 배경 설정

주인공은 생물학을 전공한 전직 동물원 큐레이터다. 플레이어가 이름을 정하며, 기본 이름은 **알렉스**다. 어린 시절 동경했던 공룡 파크의 창립자 **아서 해먼드**에게서 한 통의 편지를 받고, 그의 꿈을 이어가기 위해 **이슬라 소르나**로 향한다.

섬에는 15년 전 폐쇄된 파크와 살아남은 공룡들이 있다. 주인공은 유전공학자 닥터 진, 건축가 마르코, 조련사 올리비아와 함께 시설을 재건하고 파크를 다시 연다. 탐험과 재건이 진행될수록 과거의 하이브리드 실험과 사고의 진실이 드러난다.

**"폐허가 된 공룡 파크를 되살리고, 인간과 공룡이 공존하는 미래를 만든다."**

### 핵심 미스터리와 테마

1. **15년 전의 사고**: 자연재해로 알려진 파크 폐쇄 뒤에 무엇이 숨겨져 있는가?
2. **동료들의 과거**: 닥터 진과 올리비아는 그 사건과 어떻게 연결되는가?
3. **금지된 실험**: 지하 연구소의 하이브리드 기술을 어떻게 다룰 것인가?
4. **창립자의 유산**: 선대의 꿈과 실수를 이어받은 주인공은 어떤 선택을 할 것인가?

희망적이고 따뜻한 모험을 기본으로, 생명에 대한 책임과 과학의 양면성을 다룬다. 공룡 탈출, 배신, 폭풍 같은 위기가 파크 운영 및 캐릭터 관계와 연결된다.

## 3.2 챕터별 시놉시스

상세 씬, 대사, 미션 및 선택 결과는 [스토리 시나리오](dino_park_story_scenario.md)를 따른다.

| 구간 | 제목 | 주요 사건과 플레이 흐름 |
| ---- | ---- | ----------------------- |
| 프롤로그 | 유산 | 아서의 편지를 받고 섬에 도착한다. 닥터 진과 폐허를 둘러보고 살아 있는 공룡을 만나 파크 재건을 결심한다. |
| 챕터 1 | 새로운 시작 | 마르코와 기본 시설을 재건하고 첫 공룡을 부화시킨다. 파크를 개장하며 건설과 사육의 기초를 익힌다. |
| 챕터 2 | 포식자의 귀환 | 올리비아, 로버트, 다니엘이 합류한다. 육식공룡 도입과 벨로시랩터 탈출 사건을 통해 보안, 조련, 공존의 책임을 배운다. |
| 챕터 3 | 금지된 실험 | 지하 연구소에서 과거의 흔적과 하이브리드 기술을 발견한다. 루이스의 제안과 닥터 진의 과거를 마주하며 연구 방향을 선택한다. |
| 챕터 4 | 심연의 비밀 | 해양관을 건설하고 해저 동굴을 탐험한다. 모사사우루스와 해저 연구소를 발견하며 올리비아의 과거에 다가간다. |
| 챕터 5 | 폭풍 전야 | 태풍과 루이스의 음모가 동시에 파크를 위협한다. 시설 복구와 대피를 진행하고, 닥터 진의 고백을 계기로 동료들이 다시 힘을 모은다. |
| 챕터 6 | 인도미누스 | 인도미누스 렉스와 대면한다. 화산 지대에서 동료들과 최종 작전을 수행하고 공존·격리·제거 중 하나를 선택한다. |
| 에필로그 | 선택의 결과 | 최종 선택에 따라 파크와 동료들의 미래를 확인한다. 이후 시즌 스토리로 이어진다. |

### 엔딩

| 엔딩 | 방향 | 결과 |
| ---- | ---- | ---- |
| 희망의 새벽 | 공존 | 인도미누스와 공존하며 파크를 다시 연다. |
| 새장 속 평화 | 격리 | 인도미누스를 특수 시설에 격리하고 파크의 안전을 확보한다. |
| 필요악 | 제거 | 인도미누스를 제거하고, 그 선택이 남긴 상실을 마주한다. |
| 진정한 계승자 | 히든 | 모든 캐릭터 호감도 MAX, 공존 선택, 루이스 완전 퇴치, 인도미누스 공존 성공 조건을 충족하면 존 해먼드 주니어가 합류하는 추가 결말을 본다. |

히든 엔딩은 시나리오에 정의된 기획이다. 현재 스토리 데이터의 에필로그에는 일반 엔딩 세 가지가 있으며, 히든 엔딩의 구현 여부와 조건 검증은 별도로 확인해야 한다.

## 3.3 주요 인물

| 인물 | 역할 | 스토리에서의 위치 |
| ---- | ---- | ----------------- |
| 알렉스 (기본 이름) | 플레이어, 전직 동물원 큐레이터 | 창립자의 편지를 받고 파크 재건을 이끄는 후계자 |
| 아서 해먼드 | 파크 창립자 | 주인공에게 꿈을 맡기고, 유산의 의미를 전달하는 인물 |
| 닥터 진 | 유전공학자 | 프롤로그부터 함께하며, 과거 실험에 대한 책임과 마주하는 파트너 |
| 마르코 | 건축가 | 챕터 1에서 재건을 돕는 과거 파크의 설계자 |
| 올리비아 | 조련사 | 챕터 2에서 합류하는 공룡 전문가이자 과거 사고의 생존자 |
| 루이스 | 적대자 | 하이브리드 기술을 노리고 파크를 위협하는 인물 |

# 4. 섬 선택 시스템

## 4.1 개요

**"당신의 이야기는 어디서 시작되나요?"**

게임 시작 시 5개 섬 중 하나 선택. 각 섬마다 환경, 발견 가능한 기믹, 초기 공룡이 다름. **모든 섬 무료 시작**.

> **연결 설계 미정**: 아래 5개 섬 선택은 기존 시스템 기획이다. 현행 스토리 정본은 이슬라 소르나의 파크 재건을 배경으로 하므로, 섬 선택을 이 서사에 연결하는 방식은 별도 확정이 필요하다. 확정 전에는 섬별 도입 스토리를 새로 만들지 않고 3장의 재건 설정을 따른다.

## 4.2 5개 섬 상세

### 🌴 에메랄드 섬

| 항목             | 내용                                                  |
| ---------------- | ----------------------------------------------------- |
| **테마**         | 열대 정글                                             |
| **환경**         | 울창한 숲, 폭포, 습지                                 |
| **초기 공룡**    | 브라키오사우루스                                      |
| **풍부 자원**    | 목재, 풀                                              |
| **희귀 자원**    | 금속                                                  |
| **특수 자원**    | 고대 수액                                             |
| **고유 기믹 풀** | 고대 수액, 치유 온천, 밀림 터널, 거대 폭포, 고대 거목 |
| **난이도**       | ★☆☆☆☆ (입문자 추천)                                   |

### ❄️ 화이트록 섬

# 5. 기믹 시스템

## 5.1 개요

**"탐험할수록 섬이 당신을 돕습니다"**

기믹 = 섬 곳곳에 숨겨진 발견물. 파크 운영에 영구적 또는 일시적 버프 제공.

## 5.2 기믹 카테고리

| 카테고리 | 효과 유형           | 예시                           |
| -------- | ------------------- | ------------------------------ |
| **자원** | 자원 생산량 증가    | 광산, 수맥, 희귀 식물 군락     |
| **시설** | 특수 건물 해금      | 온천 스파, 전망대, 비밀 연구소 |
| **공룡** | 희귀 공룡 해금/버프 | 둥지 발견, DNA 샘플, 변이체    |
| **수익** | 입장료/매출 증가    | 포토스팟, 자연 경관, 유적지    |
| **편의** | 플레이 편의성       | 빠른 이동, 자동 수집, 저장고   |

## 5.3 기믹 상세 예시

### 🌴 에메랄드 섬 기믹 풀

| 기믹                 | 발견 확률 | 효과                                  | 스토리 힌트                     |
| -------------------- | --------- | ------------------------------------- | ------------------------------- |
| **고대 수액 웅덩이** | 15%       | 공룡 부화 시간 -20% (영구)            | "호박 속 DNA... 이게 가능해?"   |
| **치유 온천**        | 10%       | 공룡 컨디션 자동 회복, 온천 시설 해금 | "이 물에는 특별한 성분이..."    |
| **밀림 터널**        | 12%       | 섬 일부 구역 빠른 이동                | "자연이 만든 지름길"            |
| **거대 폭포**        | 8%        | 관람 명소, 수익 +15%                  | "장관이야..."                   |
| **잃어버린 연구소**  | 5% (레어) | DNA 조합 시스템 해금                  | "15년 전 실험 기록이 남아 있어..." |

### 🌋 스톰 섬 기믹 풀

| 기믹                 | 발견 확률 | 효과                                          | 스토리 힌트                         |
| -------------------- | --------- | --------------------------------------------- | ----------------------------------- |

## 5.4 기믹 발견 시스템

```
탐험 출발 (에너지 소모)
    ↓
탐험 구역 선택 (해금된 구역 중)
    ↓
[탐험 결과] - 랜덤
├── 일반: 자원, 경험치
├── 기믹 발견! (확률)
└── 스토리 이벤트 (확률)
    ↓
기믹 발견 시
→ 컷신 + 도감 등록
→ 효과 즉시 적용 or 건설 필요
```

**"다른 섬의 공룡도 만나보세요"**

```
[파크 방문 메뉴]
├── 랜덤 방문 (하루 3회 무료)
├── 친구 파크 (친구 목록에서)
└── 추천 파크 (인기/테마별)
    ↓
[방문 중]
- 구경 모드 (터치로 돌아다니기)
- 공룡 도감 미리보기
- 좋아요 / 응원 메시지 남기기
    ↓
[방문 보상]
- 방문자: 위인 포인트 획득
- 파크 주인: 방문자 수에 따른 보너스
```

### 상호 이익 구조

| 행동           | 방문자 보상     | 주인 보상             |

| 공룡 사진 찍기 | 도감 스탬프     | -                     |
