# 첫 합성까지의 스토리와 플레이 진행 0.6

기준일: 2026-11-17 · 프롤로그부터 챕터3까지의 대본과 플레이 진행 정본. · [문서 안내](../README.md)

이 문서는 버려진 파크를 재건하는 본편의 첫18장면을 최신 시작 방식과 연결한다. 창립자의 편지, 닥터 진의 죄책감, 올리비아의 과거, 루이스의 제안, 첫 스테고케라톱스라는 사건과 인물 관계를 유지한다. 기존 장면ID·순서와 선택지ID·문구를 보존하고, 그 사이에 실제 운영·탐험·부화·시설 준비 목표를 배치한다.

대본과 장면의 진입·완료·전환은 이 문서가 소유한다. [게임 기획](game-design.md)은 전체 흐름, [밸런스](balance.md)는 비용·시간·목표 경험치, [DNA 기획](dna-and-collection.md)은 실제 원종 보유·재료·레시피·합성 수령, [탐험가 파견 지도](exploration-spots.md)는 스팟의 파견 조건과 보고서 보상을 안내한다. 세계관·본편 후반·동료와 시즌은 [스토리와 인물 통합 기획](story-and-characters.md), GP 영입과 인물 효과는 [위인 기획](great-figures.md)을 따른다. 대화 합류와 실제 영입·보유 효과를 구별하고 이 문서에서 별도 GP 가격이나 보상을 정하지 않는다.

## 1. 이야기를 통해 배우는 플레이

첫 목표는 파크를 다시 열고 두 번째 공룡을 맞는 것이다. 다음에는 원종을 찾아 돌보며 시설을 준비하고, 안전을 책임진 뒤 과거의 연구를 마주한다. 첫 합성은 과거의 비밀 실험을 그대로 반복하는 일이 아니라, 보유한 공룡과 검증된 재료로 책임 있게 새 생명을 맞는 첫 성취로 연출한다.

| 이야기 구간 | 플레이 목표 | 완료 후 이어질 것 |
| --- | --- | --- |
| 프롤로그 유산 | 편지·도착·폐허·야생 공룡을 통해 재건의 이유 이해 | 시작 파라와 파크 조작 |
| 1장 새로운 시작 | 파라 돌봄·개장·입장료·첫 관람대·이구아노돈 조사와 부화 | 원종 두 종의 탐색과 시설 확장 |
| 1장 뒤 재건 목표 | 트리케라·스테고 알 회수·부화·돌봄, 자재 수급과 연구 준비 | 2장의 육식 구역과 안전 절차 |
| 2장 포식자의 귀환 | 올리비아와 랩터를 만나고 육식 서식지·보안센터·대응 절차 준비 | 첫 연구 재료 조사와 지하 연구소 |
| 3장 금지된 실험 | DNA·배양액·촉매 회수, 과거 기록과 동료의 고백 확인 | 첫 합성·영웅 수령·도감 등록·전시 |

첫 영웅까지 **경과4~6시간**은 초반 성장 속도를 검토할 기존 설계 기준안이다. 접속 시간·주기를 정하는 목표와 구별하고 연속 플레이와 중간에 쉬었다 이어 하는 플레이를 각각 확인한다. 아래 대본의 분량이나 장면 순서를 실제 완료 시간으로 환산하지 않는다. 최신 시작10,000골드·금고·수급을 함께 적용한 시간 검산과 플레이 실측은 별도 작업이다. 극중 시간 표현은 실제 접속일·강제 대기를 만들지 않는다.

### 먼저 재개장하고 첫 부화를 맞는다

실제 플레이는 **파라 배치·급식 → 개장·첫 유료 입장 → 관람대 완공 → 초원 정찰 → 이구아노돈 부화·수령·배치** 순서다. 장면ID의 순서는 기존과 같이 `ch1-scene-1 → ch1-scene-2 → ch1-scene-3`을 유지한다.

`ch1-scene-3` ‘다시 찾아온 관람객’은 **이미 운영을 시작한 파크에 한 가족이 찾아와 재개장의 의미를 확인하는 장면**이다. 실제 유료 개장은 앞선 플레이에서 시작하며 가족 방문 장면이 새 개장 조건이나 추가 공룡 수 조건이 되지 않는다.

## 2. 공통 진행과 보상 규칙

스토리 화면은 대화를 접고 현재 목표로 돌아갈 수 있게 한다. 본 대본의 사건 순서는 유지하되, 먼저 달성한 실제 목표는 기록으로 인정한다. 대화를 늦게 읽었다는 이유로 이미 완공한 시설을 다시 짓거나 공룡을 다시 부화시키게 하지 않는다. 대사 생략은 장면 읽기 처리이며 탐험·부화·합성의 실제 완료를 대신하지 않는다. 선택이 있는 장면에서는 생략으로 답을 임의 결정하지 않고 기존 선택ID 중 하나를 플레이어가 확정한 뒤 다음 장면으로 전환한다. 생략한 장면과 선택 기록은 다시 읽을 수 있게 한다.

목표 카드는 한 번에 현재 핵심 행동 하나를 제시하고, 별도 보기에서 다음 준비를 확인할 수 있게 한다. 생산·부화·공사·합성 타이머는 각각 자기 작업 상태를 따른다. 탐험은 무료 재개하며 자동 성공시키지 않는다. 무료 기본 부화 자리·건설자1명·연구원1명으로 첫 영웅까지 갈 수 있게 하고 추가 연구원·기술 연구·고레벨 시설·금속을 새 필수조건으로 넣지 않는다.

| 기존 목표ID | 완료 기록과 경험치 | 대본에서 연결하는 위치 |
| --- | --- | --- |
| visitors | 실제 유료 입장객10명·XP200 | `ch1-scene-1`의 재개장 안내 뒤 |
| iguanodon | 실제 부화·건강 확인·XP700 | `ch1-scene-2` |
| triceratops | 실제 부화·건강 확인·XP800 | 1장 뒤 재건 목표 |
| stegosaurus | 실제 부화·건강 확인·XP800 | 1장 뒤 재건 목표 |
| safety | 2장 안전 목표·대화 완료·XP2300 | `ch2-scene-5` |

위 값은 [밸런스의 초반 목표 앵커](balance.md#10-초반-목표-앵커)를 표시한 것이다. 이 문서가 별도 보상 설정을 소유하지 않는다. 각 목표의 기존 수령 기록과 같은 기록을 사용하며 장면·챕터를 다시 읽어도 XP·알·개체·재료를 더 지급하지 않는다. 이구아노돈의 건강한 첫 부화는 돌봄 완료로 인정하고 추가 급식을 보상 선행으로 강제하지 않는다.

스토리의 보상은 위 목표 경험치와 해당 탐험·부화·합성의 실제 수령 기록을 사용한다. 장이나 대화를 마쳤다는 이유로 골드·다이아·시설·같은 공룡을 별도로 더 지급하지 않는다. 인물의 출현은 조력과 이야기 진행이며 실제 영입·보유·배치는 위인 정본을 따른다. 일반 연구원/건설자 수와 인물의 영입·능력도 구별한다. 기존 계정의 정상 자산·개체·관계·선택·해금은 보존한다.

## 3. 프롤로그 유산

### prologue-scene-1 편지

**진입과 목표:** 새 스토리 시작. 플레이어가 창립자의 편지를 열어 재건 요청을 읽는다. 플레이어 기본 이름은 알렉스이며 실제 표시에는 지정한 플레이어 이름을 사용한다. 편지를 전달할 열쇠·지도 등을 새로운 상시 재료로 지급하지 않는다.

**대본:**

아서의 편지: 자네는 어릴 적 우리 파크 영상을 보며 공룡을 만나고 싶어 했다지.

아서의 편지: 생물학을 공부하고, 동물원에서 생명을 돌보는 일도 배웠다고 들었네.

아서의 편지: 내가 세운 파크는 오래전에 문을 닫았어. 하지만 그곳의 생명까지 끝난 것은 아니네.

아서의 편지: 이슬라 소르나로 가 주게. 이번에는 공룡에게도 집이 되는 파크를 만들어 줬으면 하네.

플레이어: 폐허를 다시 파크로…… 내가 할 수 있을까.

**완료와 다음:** 편지 읽기 또는 생략 확인 → `prologue-scene-2`. 별도 재화·경험치 보상은 없다. 편지 재열람은 신규 계정이나 시작 파라를 만들지 않는다.

### prologue-scene-2 도착

**진입과 목표:** 편지 다음. 부두에서 닥터 진을 만나 첫 대화 태도를 선택한다. 과거 질문은 진의 주저함을 보여주되 이 자리에서 3장의 비밀을 모두 공개하지 않는다.

**대본:**

내레이션: 안개가 걷히자, 숲 사이로 낡은 파크 간판이 드러난다.

닥터 진: 와 줬군. 나는 진이야. 예전에는 이곳의 유전공학을 맡았지.

플레이어: 아서 회장님의 편지를 받았어요. 정말 다시 열 수 있을까요?

닥터 진: 한 번에 전부는 어려울 거야. 오늘은 돌볼 수 있는 작은 구역부터 시작하자.

닥터 진: 과거에 관한 이야기도 해야겠지. 다만 먼저 직접 보여주고 싶은 게 있어.

**선택과 다음:** 아래 기존 선택지 중 하나를 저장하고 모두 `prologue-scene-3`으로 간다. 선택ID와 문구의 의미를 보존하며, 아래 선택은 파라·시설·첫 합성을 잠그지 않는다.

| 선택ID | 표시 문구 | 당장 보이는 응답 |
| --- | --- | --- |
| prologue-choice-1a | 반갑습니다. 잘 부탁드려요. | 진이 함께 시작하자며 안내한다. |
| prologue-choice-1b | 15년 전... 무슨 일이 있었죠? | 진이 대답을 망설이며 기록을 함께 보자고 한다. |
| prologue-choice-1c | (묵묵히 악수만 한다) | 진이 악수를 받고 먼저 길을 연다. |

호감도 수치와 장기 엔딩 자격은 이 문서에서 확정하지 않는다. 질문 이력은 대화 재열람·후속 응답을 위한 기존 선택 기록으로 남긴다. 별도 영입비·보상은 없다.

### prologue-scene-3 폐허

**진입과 목표:** 진과 본관을 둘러보며 입구·외곽 경계·관람길·서식지를 구별한다. 스토리의 폐허 전체를 철거하거나 조사 물품을 모아야 시작하는 구조는 넣지 않는다.

**대본:**

닥터 진: 저 바깥 울타리가 파크의 경계야. 안쪽 울타리는 공룡이 사는 서식지를 나누고.

플레이어: 길도 거의 숲에 묻혔네요.

닥터 진: 우선 입구에서 초원까지 이어지는 길을 쓰자. 손님과 공룡의 공간은 분리해야 해.

내레이션: 풀잎 너머로 낮고 긴 울음소리가 들린다.

닥터 진: 잠깐. 저 소리는…….

**완료와 다음:** 파크의 공간 안내 확인 → `prologue-scene-4`. 기존 시작 경계·입구·길·초원 데이터를 사용하며 조사 대사로 목재·석재나 별도 건설자재를 지급하지 않는다.

### prologue-scene-4 첫 만남

**진입과 목표:** 숲 너머 야생 브라키오사우루스를 목격한다. 시선·울음·실루엣 연출로 생명이 남았음을 보여준다. 이 장면은 브라키오 소유·도감 등록·무료 지급이 아니다.

**대본:**

내레이션: 나무 위로 긴 목이 올라온다. 브라키오사우루스가 천천히 고개를 돌린다.

닥터 진: 살아 있었구나. 그 긴 시간을 버티고.

플레이어: 우리가 돌아오기 전에도, 이 섬은 계속 살아 있었네요.

닥터 진: 맞아. 우리가 되찾을 것은 건물만이 아니야.

플레이어: 그럼 작은 곳부터 시작하죠. 우리가 끝까지 돌볼 수 있는 곳부터.

**완료와 다음:** 프롤로그 읽기 완료 → `ch1-scene-1`과 시작 파라 안내. 정상 시작 콘텐츠의 한 번 지급·기존 계정 인정은 현재 게임 규칙을 따른다. 여기서 두 번째 시작 보상이나 무료 대형 서식지를 만들지 않는다.

## 4. 챕터1 새로운 시작

### ch1-scene-1 설계자의 귀환

**진입과 목표:** 프롤로그 완료. 마르코가 합류해 파라 배치·급식, 길 확인, 개장, 첫 입장료, 관람대 건설을 순서대로 안내한다. 초반 조작 안내는 대사 사이의 목표 카드로 나누고 긴 대화를 다 읽어야 조작할 수 있게 하지 않는다.

**대본:**

마르코: 마르코 로시, 건축가야. 아서의 부탁을 받고 왔어. 이 파크, 나도 처음부터 함께 설계했지.

닥터 진: 초원에서 보호하던 파라 한 마리가 있어. 먼저 자리를 정하고 먹이를 챙겨 주자.

마르코: 공룡은 안쪽에, 손님은 길 위에. 입구에서 관람 지점까지 이어지는지 확인해 봐.

플레이어: 문을 열어도 될까요?

닥터 진: 파라를 돌봤고 안전하게 볼 수 있다면 시작해도 좋아. 공룡 수를 채우려고 기다릴 필요는 없어.

마르코: 손님이 내는 입장료를 모아 관람대를 짓자. 더 편하게 공룡을 볼 자리가 필요하니까.

**완료와 다음:** 시작 파라의 배치·돌봄 인정, 실제 유료 입장 기록, 첫 관람대 완공을 확인하면 초원 정찰을 안내하며 `ch1-scene-2`로 간다. 첫 유료 입장객10명의 XP200은 기존 `visitors` 목표에서 한 번 처리한다. 파크 Lv.2 관람대와 벌목장·채석장 접근은 기존 해금을 사용한다. 목재·석재 시설 건설을 첫 정찰의 추가 필수조건으로 삼지 않는다.

관람대의 배치·확정·완공은 별개다. 미리보기 취소나 대화 반복으로 비용을 받지 않는다. 수익은 방문객 입장료이며 파라나 관람대가 골드를 별도 생산하지 않는다.

**대본:**

플레이어: 이 둥지가 두 흔적이 이어지는 곳이네요.

닥터 진: 이구아노돈의 알이야. 안전하게 회수해서 기본 부화 자리에 놓자.

닥터 진: 환영해, 꼬마야. 네가 지낼 초원을 함께 준비했어.

**대본:**

내레이션: 관람대에 도착한 가족이 초원을 바라본다. 아이가 파라와 이구아노돈을 번갈아 가리킨다.

닥터 진: 저 표정은 예전과 같네. 이 파크를 다시 열고 싶었던 이유가 생각나.

## 5. 1장 뒤 재건과 원종 준비

이 구간은 새 장면ID를 추가하지 않는 **기존 장면 사이의 플레이 목표**다. `ch1-scene-3` 뒤에 목표를 보여주고 완료하면 `ch2-scene-1`을 연다. 탐험·부화·생산·건설을 병행할 수 있으며, 같은 종류의 작업 한도는 각 담당 시스템을 따른다.

| 순서 | 현재 목표 | 완료 기록 | 다음 준비 |
| --- | --- | --- | --- |
| 1 | 트리케라 흔적과 스테고 흔적 조사 | `trike`·`stego` 최초 목표를 직접 완료하고 지정 알 수령 | 실제 부화 시작 |
| 2 | 원종 두 종 부화·돌봄 | 트리케라·스테고 실제 부화와 건강 목표 인정 | 안전시설을 준비할 파크 성장 |
| 병행 | 일반 자원 마련 | 골드 구매 또는 벌목장·채석장 생산 수령 | 관람대·부화/연구시설 준비 |
| 병행 | 파크 Lv.3의 시설 준비 | 부화장·DNA 연구소를 기존 비용·시간으로 건설할 수 있음 | 부화 대기·재료 조사 준비 |
| 3 | 다음 구역 확인 | 원종 두 종의 첫 건강 목표까지 완료 | 2장 밀림의 소리 |

트리케라·스테고의 첫 알은 각 지정 탐험 보상이며 대사만으로 주지 않는다. 각 원종의 XP800은 기존 목표에서 한 번 지급한다. 건강한 수령 상태가 목표 조건을 충족하면 추가 급식을 강제로 시키지 않고, 실제 현재 상태가 부족할 때만 돌봄을 안내한다. 배치 대기 개체도 실제 보유이므로 두 원종을 모두 전시하거나 재배치해야 건강 목표·합성 자격을 인정하는 조건을 추가하지 않는다. 기존 부화 한 자리로 순서대로 진행해도 된다. 부화장 확장은 병렬 부화를 원하는 선택이며 원종 목표 출발의 새 선행이 아니다.

초반 기존XP를 순서대로 반영하면 유료 입장객 목표 뒤 파크Lv.2, 이구아노돈 뒤Lv.3, 원종 두 종의 건강 목표 뒤Lv.4가 된다. **파크Lv.4 → 육식 서식지·보안센터 → 안전 목표XP2300 → 파크Lv.5 → 초식 하이브리드 서식지** 순서를 지킨다. 안전 완료를 위해 파크Lv.5를 먼저 요구하지 않는다. 이 진행 확인은 기존 공유XP 공식의 산술이며 실제 수급·접속 시간을 검증한 결과는 아니다.

파크 Lv.3의 관람대 Lv.2·부화장·DNA 연구소는 기존 해금과 건설값을 따른다. 시설 구매/생산/강화 중 하나를 했다는 이유로 별도 XP를 지급하지 않는다. 시설 준비가 먼저 끝났다면 완료 기록을 인정한다. 트리케라·스테고를 모두 도감에 등록했더라도 현재 개체를 방생했다면 이후 합성 전 실제 부모 재입수가 필요하다.

**짧은 목표 대사:**

닥터 진: 트리케라와 스테고의 흔적을 각각 찾았어. 조사 목표를 골라 알을 회수해 보자.

마르코: 부화를 기다리는 동안 관람 공간과 재료를 준비할 수 있어. 필요한 목재와 석재는 구매하거나 직접 생산하면 돼.

닥터 진: 도감에 이름을 올리는 것과 지금 돌보고 있는 것은 달라. 두 원종을 잘 보살펴 줘.

## 7. 2장 뒤 연구 재료와 지하 연구소 준비

화석 계곡과 원시 습지의 **첫 지정 중급 재료 목표**는 안전 준비 구간에서 병행 안내할 수 있다. 2장 후에는 아직 완료하지 않은 목표만 이어서 보여준다. 첫 지정 DNA 조사2회와 배양 시료 목표의 보상·준비비는 밸런스의 `dna1`·`dna2`·`culture`를 사용한다. 대화로 재료를 주거나 이미 수령한 최초 보상을 다시 열지 않는다.

| 목표 | 플레이어가 하는 일 | 완료 후 |
| --- | --- | --- |
| 중급 DNA 확보 | 화석 계곡의 첫 DNA 조사1·2 직접 완료·수령 | 합성 재료함에서 보유량 확인 |
| 중급 배양액 확보 | 원시 습지 배양 시료 목표 직접 완료·수령 | DNA와 별개 품질·수량 확인 |

| 새 집 준비 | 파크 Lv.5의 초식 하이브리드 서식지 건설 준비 | 첫 결과를 전시할 공간 마련 |

이 목표들은 새 기술 연구의 선행으로 잠그지 않는다. 원종 준비·2장 안전 완료와 `dna1`·`dna2`·`culture`의 최초 조사/수령 이력을 확인하고 다니엘의 지하 입구 발견 `ch3-scene-1`을 진행한다. 이때 확인하는 재료 조사 이력은 위 세 목표뿐이며 촉매 보유·촉매 회수를 진입 조건으로 요구하지 않는다. 촉매는 `ch3-scene-2`의 실제 탐험에서 회수한다. 최초 재료를 이미 소비한 계정의 조사 이력은 인정하고 실제 합성 시작 때 필요한 재고를 다시 검사한다. 초식 하이브리드 서식지는 합성 시작 전 부족 조건으로 안내하되 공룡 수령과 실제 전시의 조건을 구별한다. 첫 영웅의 최종 전시 목표를 끝내려면 호환 서식지·동선·빈 수용공간이 필요하다.

**짧은 목표 대사:**

닥터 진: 화석 계곡에서는 DNA 시료를, 원시 습지에서는 배양 시료를 확인할 수 있어. 각각의 조사 목표를 직접 끝내자.

**분기 응답:** 거절 기록이면 진이 ‘거절한 결정을 지키겠다’고, 협상 기록이면 ‘검토하되 자료를 넘기지 않겠다’고, 조사 기록이면 ‘용도를 확인할 때까지 공유하지 않겠다’고 한 문장 덧붙인다. 새 선택지나 새 점수는 추가하지 않는다.

**완료와 다음:** 대화 완료 → `ch3-scene-6`의 합성 준비. DNA 연구소Lv.1·실제 부모·재료·골드·기존 합성 자리의 부족 조건을 한 화면에서 안내한다. 원종 보유·품질·시설이 부족하면 해당 준비로 이동하며 대사를 반복해서 보상을 얻을 수 없다. 별도의 기술 연구·추가 연구원 구매·도덕 점수 조건은 없다.

### ch3-scene-6 첫 하이브리드

**진입과 목표:** 3장 앞선 대화 완료. 레시피와 실제 보유 원종을 확인해 합성을 시작한다. 확인 대사는 시작 전, 탄생 대사는 서버 작업 완료 후 결과를 실제 수령할 때 보여준다. 이 장면은 준비·진행·수령·전시의 네 상태를 가지며 대사 진행만으로 합성 작업을 완료하지 않는다.

**합성 준비:** 첫 지정 스테고케라톱스는 영웅이며 **실제 스테고1마리+트리케라1마리, 중급 DNA20·촉매1·배양액2, 4,000골드, 30분, 100%**의 기존 레시피를 사용한다. 부모의 행복도30 이상·배고픔80 이하, DNA 연구소Lv.1·기본 합성 자리와 기존 챕터 권한을 검사한다. 배치 대기 중인 보유 부모도 사용할 수 있고 원종은 소모하지 않는다. 이 수치는 [DNA 정본](dna-and-collection.md#6-결과-등급별-실패와-보호)의 규칙과 [우선 레시피](dna-and-collection.md#7-우선-레시피)를 읽는 표시값이며 별도 설정으로 관리하지 않는다.

**진입 해금:** `ch3-scene-6` 진입과 준비 조건 충족으로 첫 레시피를 시작할 수 있다. 챕터3 전체 완료를 합성 시작의 선행으로 요구하지 않는다. `3-6 진입 → 합성 시작 → 실제 결과 수령 → 전시 안내 → 3장 완료`로 연결해 첫 합성을 끝내야 그 합성이 열리는 순환을 막는다.

**대본:**

닥터 진: 스테고사우루스와 트리케라톱스. 두 원종을 확인했어. 함께 돌봐 온 그 개체들이야.

플레이어: 두 공룡은 연구가 끝나도 그대로 지내는 거죠?

닥터 진: 물론이지. 시료와 조건을 모두 확인했고, 이번 첫 합성은 성공이 보장돼. 배양을 시작하자.

마르코: 그동안 새 서식지와 관람길을 확인해 둘게. 탄생한 뒤 살 곳도 준비돼야 하니까.

내레이션: 배양을 마친 연구실. 스테고의 골판과 트리케라의 뿔을 가진 작은 공룡이 몸을 일으킨다.

닥터 진: 스테고케라톱스. 환영해. 너를 끝까지 돌보겠다고 약속할게.

올리비아: 우리가 무엇을 만들었는지만큼, 이제 어떻게 함께 살지도 중요해요.

플레이어: 새집으로 가자. 손님들에게도 제대로 소개해야겠어.

**완료와 다음:** 결과 수령에서 영웅 스테고케라톱스1마리를 배치 대기로 받고 영구 도감에 등록한다. 첫 지정 보장 사용 확정·부모 잠금 해제·기본 합성 자리 반환·무료 건설자 총2명 해금을 같은 첫 성취 이력에 연결한다. 첫 지정 보장은 재접속·버튼 중복·챕터 재열람으로 반복되지 않는다. 이미 정상 보유한 건설자가2명 이상이면 줄이거나 매번1명을 더하지 않는다.

초식 하이브리드 서식지의 완공·호환·동선·빈칸/수용량을 확인해 파크 배치로 이어진다. 결과 수령과 전시는 별개이며 전시 준비가 부족해도 수령한 개체를 삭제하거나 합성을 다시 시키지 않는다. 챕터3의 대화 완료·첫 합성 수령·첫 전시 기록을 함께 확인한 뒤 3장 진행을 마치고 다음 탐험/확장 안내를 연다. 기존 계정은 정상 완료 이력을 인정하며 이미 수령한 개체를 챕터 보상으로 또 주지 않는다.

합성의30분에는 배양과 탄생이 포함된다. 결과를 알로 바꾸어 부화 시간을 한 번 더 붙이지 않는다. 연구원은 합성에 배정하지 않으며 기술 연구의1분·7일·14일 이상 하한을 이 타이머에 적용하지 않는다. 반복 스테고케라톱스 합성은 첫100%와 구별하여 영웅 기본 확률·반환·실패 보호를 따른다.

## 9. 선택의 즉시 결과와 후속 범위

이번 범위에는 기존18장면과 그 안의 선택지18개가 있다. 선택지는 태도와 대응을 기록하고 해당 장면·직후 대사의 응답을 바꾼다. 세 선택지가 있는 장면은 도착, 올리비아의 과거, 첫 위기, 반성과 교훈, 진의 고백, 찾아온 유혹의6개다. 새로운 선택지나 누적 윤리 재화를 추가하지 않는다.

본편 전체의35장면·27선택지·3엔딩 수록 범위는 유지한다. 최종 제거·격리·공존 선택은 각 엔딩에 직접 연결된다. 초반 선택과 관계가 이후 대사·사이드 이야기·엔딩 자격에 미칠 영구 효과, 호감도 숫자와 선택 보상, 되돌려 선택하는 정책은 후속 정본에서 확정한다. 그 결정 전에는 이번 첫 합성에 숨은 호감도·윤리 점수·특정 선택 필수조건을 만들지 않는다.

4~6장과 에필로그, 사이드6편·시즌의 사건·인물 관계는 [스토리와 인물 통합 기획](story-and-characters.md)으로 통일한다. 아서는 창립자로서 시즌1의 마지막 여정을 마치고 유산을 남기며, 토마스는 생물공학 박사, 엘리자베스는60대의 진의 스승, 리바이어던은 전설 자연종이다.

4~6장·에필로그의 장면별 진입·완료와 시설·연구·탐험 연결은 아래11절을 따른다. [파크 성장 정본](park-progression.md)은 첫 합성 이후의 성장 목표와XP를 소유하고, 이 문서는 장면·선택·결말의 전환을 소유한다. 사이드·시즌의 세부 해금 목표와 장기 관계 수치는 여전히 후속 범위이며, 첫 영웅의 선행으로 상위 공룡·위인 보유·새 자원을 추가하지 않는다.

## 10. 적용 상태와 완료 기준

현재 게임에는 이구아노돈 이후의 원종 준비, 2장 안전 점검 대화와 완료 이력, 3장 마지막 실험 대화, 첫 지정 합성·전시가 연결돼 있다. 원종 알과 재료는 해당 스팟으로 탐험가를 보내 귀환 보고서에서 받는다. 전체 초반 18장면의 대사·선택과 후속 본편은 기획 정본에 남아 있다. 실행 검증 범위는 [작업 기록](../../TASK.md)에서 확인한다.

- 장면ID18개와 순서를 유지하고 선택ID18개·문구 의미·다음 장면을 대조한다. 대본·목표 조건·실제 수령 처리가 같은 규칙을 사용하게 한다.
- 첫10분의 파라·급식·개장·첫 입장료·관람대·이구아노돈 목표가 기존 완료 이력을 사용한다. ‘다시 찾아온 관람객’ 장면이 최초 개장이나 추가 유료 입장객을 생성하지 않는다.
- 1장 뒤 원종 두 목표와 기존XP, 2장 안전 절차와XP, 3장의 세 재료 목표와 합성이 같은 수령 기록을 참조한다. 늦게 읽기·대사 생략·중복 요청·재접속에도 보상을 중복 지급하지 않는다.
- 트리케라·스테고 실제 보유와 상태를 합성 시작에서 다시 확인한다. 알·도감·과거 튜토리얼 인정만으로 현재 부모를 대신하지 않는다.
- 랩터 위기를 재화 손실·시설 파괴·사상자·일반 탈출 확률로 구현하지 않는다. 첫 벨로시랩터와 첫 스테고케라톱스는 기존 정상 개체/챕터 수령 이력과 중복되지 않는다.
- 연구 재료가 부족하면 해당 장소의 실제 미션으로 이동한다. 편지·열쇠·일지·진정제·울타리 부품은 서사와 연출의 소품으로 다루고 상시 재고로 추가하지 않는다.
- 첫 합성100%·30분·기존 레시피·원종 보존·한 번 수령·도감·무료 총2건설자·실제 전시까지 확인한다. 기술 연구·다이아 구매·두 번째 부화 타이머를 새 조건으로 만들지 않는다.
- 이미 완료한 기존 계정은 정상 자산·관계·선택·해금을 보존한다. 통합 기획 적용 때 기존 자산을 회수하거나 튜토리얼 보상을 재지급하지 않는다.
- 실제 구현 후 장면 길이·목표 탐색·재접속·반복 피로와 최신 전체4~6시간 목표를 별도로 측정한다. 문서 검산을 실플레이 검증으로 기록하지 않는다.

## 11. 첫 합성 이후 본편의 성장 연결

4~6장과 에필로그의 기존17장면을 시설·연구·탐험의 실제 완료 기록에 연결한다. 사건·대사·선택ID는 [스토리와 등장인물](story-and-characters.md)이 소유한다. 아래 표의 **권장Park는 목표를 소개할 성장 구간이며 새 필수 해금 레벨이 아니다.** 앞선 장면과 실제 능력·준비 조건을 충족했다면 권장 구간 전에도 진행할 수 있다. 밤·태풍·며칠 뒤 같은 극중 표현은 실제 접속 시각·달력·대기 일수 조건이 아니다.

이미 정상 완료한 시설·연구·탐험 수령·관람·장면·선택 이력을 인정한다. 일찍 끝낸 준비는 성장 목표가 표시될 때도 정상 선완료로 인정하며, 스토리를 늦게 읽었다는 이유로 재건설·재연구·미션 재결제·재부화·재배치를 강제하지 않는다. 이미 합법적으로 진행한 장과 권한을 새 권장Park로 소급 차단하지 않는다. 대사 생략은 읽기 처리를 대신하지만 실제 준비를 대신하지 않고, 선택은 플레이어가 기존ID 중 하나를 확정한다.

목표 카드는 현재 부족한 행동 하나와 담당 화면을 안내한다. 탐험의 성공과 실제 수령은 기존 미션 기록을 확인하며, 미수령 성공은 그 결과를 먼저 수령하게 한다. 연구는 권한을 열고 알·개체·재료를 즉시 지급하지 않는다. 종별 실제 획득·부화·합성은 [83종 획득 정본](dinosaur-acquisition.md), 전시는 [시설 호환 정본](buildings.md#83-호환-판정격리거대종)을 따른다.

### 완료 기록과 보상 소유

초반18장면·18선택과 기존 목표 경험치, 첫 지정 스테고케라톱스의100%·30분·기존 연구비·실제 원종 보존은 변경하지 않는다. 첫 합성 이후의 목표ID·완료 증거·XP·정상 선완료 인정은 [파크 성장 정본](park-progression.md)이 소유하며 이 장면표에는XP값을 복제하지 않는다. 스토리는 장면·선택·장 완료·결말을 기록하고 성장 목표는 같은 실제 성취 기록을 참조한다.

알·재료는 해당 탐험 성공 수령, 개체·도감은 실제 부화/합성 결과 수령에서 각각 한 번 처리한다. 장면·장 완료·대사 재열람으로 골드·다이아·시설·알·개체를 별도로 더 지급하지 않는다. 미션이나 합성 결과를 먼저 받은 정상 이력도 인정하며, 이미 지급한 보상은 다시 만들지 않는다. 연구원·건설자 수와 이름 있는 인물 영입은 각 담당 규칙을 따르고 동료의 출현으로 임의 증가시키지 않는다.

3장 완료 뒤 **4장 심연의 비밀**을 시작하면 바다의 부름에서 해양관 프로젝트로 이어진다. 해양관 프로젝트에 필요한 연구, 공사, 관람 상태는 이야기 화면에서 확인할 수 있다. 해양관의 건설 조건은 파크 Lv.20이며, 파크 성장은 현재 Lv.15까지 이어진다. 후속 장과 에필로그는 앞선 장의 선택과 완료 기록을 사용한다.
