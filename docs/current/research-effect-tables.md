# 연구 효과 한눈에 보기 0.6

**상세 57개 기술·189개 레벨의 생성표입니다.** [효과 기획 원천](research-effects.md)과 [연구트리](research-trees.md)를 읽어 만들며 별도 수정 원천으로 사용하지 않습니다. 효과값을 바꿀 때는 원천을 수정하고 이 표를 다시 생성합니다.

후속 레시피의 부모·재료·비용·시간은 [DNA 정본](dna-and-collection.md)을 읽어 표시합니다. 실행 카탈로그 83종에서 원종을 찾고, 합성 가능 여부는 해당 레시피의 공개 상태에서 확인합니다.

기본 12개 기술·50개 레벨은 [연구트리 효과표](research-trees.md#5-기본-연구-효과-수치)를 따릅니다. 두 범위를 합하면 69개 기술·239회 연구입니다. 아래 내용은 기획이며 게임에 적용됐다는 뜻이 아닙니다.

- 각 행은 해당 완료레벨의 총효과입니다. 이전 레벨의 수치를 더하지 않습니다. ‘이번 레벨 해금’에는 이번에 새로 열린 권한만 적고 이전 권한은 유지합니다.
- 연구소·선행 조건 외에 실제 시설·미션·레시피가 준비돼야 합니다. 후속 콘텐츠가 준비되지 않은 단계는 연구 시작도 활성화하지 않습니다.
- 연구로 탐험 목표나 합성 설계를 엽니다. 탐험 보상은 귀환 보고서에서 받고, 공룡은 부화 또는 합성으로 얻습니다. 첫 부화와 첫 지정 합성에는 각각 정해진 조건이 있습니다.
- 비용과 연구시간은 [239회 비용표](research-cost-tables.md)를, 정확한 전체 중첩·보존 규칙은 [공통 계산과 상한](research-effects.md#3-공통-계산과-상한)을 따릅니다.

| 사육 | 15 | 51 |

### 일반 초식 원종 조사 · 최대 Lv.3

**적용·중첩:** 연구 완료는 지정 목표/레시피 권한만 열며 공룡·알·재료를 즉시 지급하지 않는다. 파라 시작 지급·첫 이구아노돈·스테고/트리케라·첫 벨로시랩터와 기존 획득/스토리/이벤트/보유 이력은 소급 잠그지 않는다. 해당 기술의 이전 단계와 정본 선행/연구소 조건을 유지하며 관련 없는 계열의 최대레벨을 일괄 요구하지 않는다. 종 조사/레시피 권한·지역/미션·사육 환경의 담당을 구별한다. 해금 목록는 현재 레벨에서 열린 목표 종의 누적 목록, 이번 추가 해금는 이번 단계에 추가되는 종이다. 각 종마다 추적→알 회수 목표미션1개를 열고, 그 목표의 최초 검증 완료 때 종 지정 알1개를 한 번 수령한다. 알은 수동 부화를 거쳐 실제 개체를 얻으며 도감 등록/파크 배치는 각각 기존 규칙을 따른다. 최초 보상을 기술 완료/알 보유/재접속으로 다시 주지 않는다. 재입수는 일반 반복 탐험 보상 계약으로 별도 구현하며 기술로 추가 지급률·보상량을 만들지 않는다. 지정 목표는 그 기술 레벨에서 이용 가능한 기본 조사 경로에 연결한다. Lab20 목표에 Lab25 최상위 추적을 일괄 필수로 붙이지 않는다. 별도 자연종 DNA 합성·등급 승급·성공률 보너스는 없다.

### 확장 하이브리드 설계 · 최대 Lv.3

선행: 고급 유전자 분석 Lv.1 · [상세 원천](research-effects.md#gene-combination-foundation)

**적용·중첩:** 연구 완료는 지정 목표/레시피 권한만 열며 공룡·알·재료를 즉시 지급하지 않는다. 파라 시작 지급·첫 이구아노돈·스테고/트리케라·첫 벨로시랩터와 기존 획득/스토리/이벤트/보유 이력은 소급 잠그지 않는다. 해당 기술의 이전 단계와 정본 선행/연구소 조건을 유지하며 관련 없는 계열의 최대레벨을 일괄 요구하지 않는다. 종 조사/레시피 권한·지역/미션·사육 환경의 담당을 구별한다. 해금 목록는 해당 단계까지의 결과종/레시피 권한 누적 목록이다. 실제 합성 레시피가 등록됐다는 뜻은 아니다. 고급 유전자 분석의 계통 자격과 해당 개별 조합 설계를 구별한다. 실제 보유 부모를 모두 선택하고 기존 상태/작업 잠금 규칙을 통과해야 하며 부모는 성공/실패 모두 보존한다. 부모 미보유를 DNA 재료만으로 대체하거나 부모 요구를 낮추지 않는다. 후속 레시피의 필수재료는 기존5종/3품질 안에서 정의하고 영웅 최소 중급·전설 최소 상급을 유지한다. 기본 영웅50%/전설10% 및 레시피별 최대5/8번째 확정 보호·안정제/시료 보존 규칙은 그대로다. 신규 세부 조합 기술을 공개4종(스테고케라톱스·스피노랩터·파라 룩스·인도미누스 렉스)에 소급 필수로 넣지 않는다. 새 성공률 버프·형질·희귀도·품질·합성 병렬은 추가하지 않는다.
