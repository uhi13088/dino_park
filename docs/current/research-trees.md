# 기술 연구트리 기획 0.6

기준일 2026-11-23. 운영·사육·유전 각 18개, 탐험 15개 기술과 전체 239단계의 기획은 [단계별 비용과 시간](research-cost-tables.md)에서 확인한다. 게임 연구 화면에서는 탐험가 파견에 필요한 기술과 선행 조건, 시설 고도화와 초반 성장 목표 연구를 진행할 수 있다. 기본 12개 기술의 효과는 이 문서, 나머지 57개는 [효과 상세](research-effects.md)가 소유한다.

나머지 57개 연구는 **[레벨별 효과표](research-effect-tables.md)**에서 한 번에 읽을 수 있다. 정확한 대상·중첩 계약은 [효과 상세 정본](research-effects.md)을 따른다.

## 1. 연구가 여는 성장

**방문객 입장료 → 시설·연구소 투자 → 기술 완료 → 부지/시설 구간/새 탐험/공룡 목표 개방 → 플레이·자원 소비·공룡 전시 → 다음 투자**로 연결한다. 연구소는 기술 범위, 기술은 실제 권한과 운영 능력을 담당한다. 연구를 완료했다는 이유만으로 공룡·탐험 재료·골드를 지급하지 않는다.

| 정보 | 역할 |
| --- | --- |
| 파크 레벨 | 기존 경험치로 쌓는 진행 실적·스토리 자격. 기술 연구를 별도 XP 생산원으로 만들지 않음 |
| 연구소 Lv.1~25 | 연구 가능한 기술/단계를 넓히며 고레벨 기술과 다음 시설 강화 구간의 기반이 됨 |
| 4계열 | 운영·사육·탐험·유전. 계열 자체는 레벨업하지 않음 |
| 계열별 연구 분야 | 화면을 정리하는 묶음. 별도 업그레이드나 재료를 요구하지 않음 |
| 기술 69개 | 분야마다3개, 각 기술최대3또는5레벨. Lv.1최초 연구까지 모두 합한 총 239회 연구. 선형 진행를 뜻하지 않음. 괄호의3/5는 최대레벨 |
| 연구원 | 게임 시작 무료1명, 추가인원은 다이아로 영구 구매. 서로 다른 기술을 병렬 연구 |
| DNA 합성 | 별도 기본1작업. 원종·탐험 재료로 새 개체를 얻으며 연구원 슬롯과 공유하지 않음 |

기술은100%완료·영구 효과다. 한 기술의 다음 단계는 직전 단계 완료 후 진행하고, 여러 연구원이 같은 단계나 한 기술의 여러 단계를 동시에 진행하지 않는다. 완료 시 서버가 효과를 적용하고 연구원을 자동 반환한다. 고용 조건/통화는 [밸런스](balance.md#12-건설자와-연구원-고용), 기술 작업비는 골드·목재·석재·필요시금속이다. 새 과학 재화·재료 품질·직원 장비는 추가하지 않는다.

현재 게임에서는 기본 연구원 1명이 연구 한 건을 맡는다. 파크의 DNA 연구소나 탐험의 잠긴 스팟에서 연구 화면으로 이동한다. 비용·시간과 선행 단계가 맞으면 연구를 시작한다. 앱을 닫아도 연구 시간은 흐르며, 완료된 단계의 파견 권한은 스팟에 자동 반영된다. 시설 고도화는 연구소·금고·창고의 다음 강화 구간을 연다. 추가 연구원과 기타 시설·레시피의 연구 효과는 해당 게임 기능을 이용할 수 있는 단계에 맞춰 적용된다.

첫 파라·관람대·이구아노돈·초기 목재/석재 생산·첫 지정 스테고케라톱스는 기존 짧은 흐름을 보존한다. **첫 스테고케라톱스는 기술 연구 없이** 기초 연구소와 기존 원종/중급 재료/챕터 조건으로100%합성하며30분을 유지한다. 첫 원종과 연구 재료3종의 지정 목표를 후기 해금 연구로 잠그지 않는다.

### 항목 수·연구 횟수·선행 깊이의 구분

기술은 병렬로 분기한다. 각 항목의 최초 연구 69회와 후기 강화 170회를 합해 239회다. 계열과 분야는 화면에서 찾아보기 위한 묶음이다.

선행 깊이는 기술 간 의존관계로 따로 본다. 현재초안은 기술항목만 보면 최장5항목 연쇄, 항목내 다음레벨까지 포함하면 최장11회연구의 의존 연쇄다. 이 값은연구소건물강화/스토리조건/경과시간을제외한기술선행구조만계산한것이며실제성장전체단계수나플레이기간이아니다. 최종기술배치에따라다시계산한다.

## 2. 연구소가 다음 단계를 여는 방식

연구소도 시설 고도화의 대상이다. 기본 상한5 → 연구소5에서고도화1 → 상한10 → 연구소10에서고도화2 → 상한20 → 연구소20에서고도화3 → 상한25 순서여서 자기 잠금이 없다. 후반 목표XP 공급과 단계별 권장 준비는 [성장 정본](park-progression.md)을 따른다. 기술/건물의 실제 비용·시간·자원 공급을 함께 검산하기 전에는 전체 도달 일수를 제시하지 않는다. 성장목표는 기술의 정상 완료를 확인할 수 있지만 기술 작업 자체에 반복Park XP 보상을 붙이지 않는다.

해금의 담당을 나눈다. 운영은 토지/시설 구간, 사육은 종별 환경·돌봄, 탐험은 지역/미션, 유전은 원종 목표·레시피를 담당한다. 한 권한을 여러 기술에서 중복 판매하지 않는다. 개별 탐험/레시피의 필수 기술과 실제 안전·원종 조건을 명시하며 관련 없는 계열 전체 최대레벨을 요구하지 않는다.

## 3. 69개 기술의 목적과 연결

각 표의 ‘연구소 단계’는 기술Lv.1부터 각 단계에 필요한 완공 연구소 레벨이다. 선행은 기술ID:완료레벨이며 비용군A/B/C/U는기존기술표,N은신규공통산식이다. 수치는밸런스원천을따른다. 준비 열은 현재 코드에 구현됐다는 표시가 아니라 필요한 기능/콘텐츠 범위다. 69기술의 모든 레벨에 자원·시간·효과를 설정했다. 각 신규 항목의 [레벨별 효과와 해금 대상](research-effects.md)을 함께 읽는다. 연결할 콘텐츠가 준비되지 않은 기술레벨은 게임에서 연구 시작을 활성화하지 않는다.

## 4. 권한과 콘텐츠의 실제 적용

- **토지 개발:** 연구를 마치면 다음 정형 부지 공사 권한이 열린다. 정형 공사는 20×20에서 단계별로 40×40까지 제공하고, 미리보기에서 비용·새 테두리·정문과 관람길 연결을 확인한 뒤 시작한다. 중반에 인접 필지 구매가 열리면 파크 레벨을 다시 올리거나 연구를 추가할 필요 없이 보유 부지에 붙은 곳을 직접 선택해 산다. 필지 구매는 정형 공사 5단계 완공과 별개로 열리고, 이미 확보한 부지·개체·시설은 보존한다. 공사비와 시공 시간은 [밸런스 16절](balance.md#16-실제-부지-확장과-특수-사육시설)을 따른다.
- **시설 고도화:** 연구소와 서식지를 포함한 주요 시설의 25레벨 강화 구간을 개방한다. 건물의 단계별 효과·외형·종 호환은 건물 기획을 읽는다. [서식지 블록과 익룡 돔 공간](buildings.md#서식지-블록과-익룡-돔-공간)은 별도 공간 기준을 따른다. 이미 완공한 고레벨 건물은 보존한다.
- **특수 환경 사육:** 사막/화산/빙하·익룡/해양/거대종의 사육 허가와 호환 환경을 담당한다. 그에 맞는 실제 시설/종 목록이 준비돼야 이용한다. 초반 원종과 첫 영웅은 새 환경 허가로 다시 잠그지 않는다.
- **지역과 임무:** 첫 초원·초기3재료의 지정 중급 목표는 보존한다. 기본 장소와 심층/특수지형 임무를 구별한다. 기존5재료↔장소 대응을 유지하고 한 지역에서 여섯 번째 재료를 만들지 않는다. 상급 직접 조사는3:1승급과 병행 가능한 선택 경로다. 기초 변이 분화구/광물 동굴의 실제 입장과 상위 경로는 미션 권한표로 구별하며, 파라 룩스의 기존 조건을 설명 없이 추가 연구로 잠그지 않는다.
- **공룡 연구:** 원종 연구는 알을 얻을 조사 목표, 레시피 연구는 합성할 결과를 연다. 탐험을 실제 완료하고 알을 부화해 원종을 보유해야 한다. 기존4레시피에 신규 세부 조합 기술을 소급 필수로 넣지 않는다. 신규 레시피는 원종/재료/품질/골드/시간 확정 전까지 연구 가능으로 표시하지 않는다.
- **단체 돌봄/급식 계획:** 사용자가 대상을 고르고 비용을 확인해 실행하는 수동 행동이다. 저장한 계획이 자동 급식/구매/재료 소모를 일으키지 않는다. 개체별 적격·실제 재고·상한·총비용을 실행 때 서버가 확인한다.

비율은 마지막에 한 번 적용한다. 작업 시간은 마지막에 초 단위로 올림하되 공사는 기존15초 단위 올림을 유지한다. 기존 입장료 정산의 소수 잔여는 보존한다.

기술의 효과는 파크당 한 번만 적용한다. 같은 연구소를 여러 개 짓거나 연구원 수를 늘려 효과를 곱하지 않는다. 기술 완료 시각까지 이전 효과로 입장료·유지비·돌봄을 정산하고 그 이후 새 효과를 적용한다. 장기 오프라인 중 여러 완료가 있으면 시간순으로 정산한다.

이미 시작한 기술 연구·DNA 합성·탐험의 시간/확률/보상 버전은 고정한다. 나중의 연구소 강화·새 기술·추가 고용이 진행 중 작업의 완료 시각이나 실패 반환율을 소급 변경하지 않는다. 현재 태스크가 끝난 뒤 시작하는 작업부터 새 보너스를 사용한다.

신규 공사 공법·물자 조달·관람 동선·부재중 운영·합성 예산 등의 효과·상한은 [효과 상세](research-effects.md)의 레벨표와 중첩 규칙을 적용한다. 연구예산관리와실험절차는각2/4/6/8/10%로설정했고,필요자원/시간은밸런스14~15절에따른다. 건설 시간의 최종24→25와 후기 기술의 지정 단계는 모든 일반 시간 보정 후에도최소7일이다. 일반 부화/합성 추가 단축은첫60초 부화/첫30분 합성을 제외한다. 생산 공정은일반4자원 작업 시간만, 물자 조달은일반4자원 구매 단가만 담당한다. 재료 할인·골드 할인·회분 상한·창고 여유를 같은 수치로 혼용하지 않는다.

## 8. 단계별 노출과 남은 수치 설계

첫 화면은4계열과계열별 연구 분야다. 분야를 열면3개 기술과선행선/현재레벨/최대레벨/다음효과/비용/완료시각을 보여준다. 계열/분야 자체에는업그레이드비용이 없다.69개를한꺼번에선택하도록강요하지않고다음목표에필요한해금과선택효율을구별한다. 기본도움말/미션재개/개체상태·부족자원안내는연구없이항상제공한다.

69기술239회 연구의 효과·중첩과 신규 부지 면적은 정의했다. 별도 확장비·특수시설5종의125레벨·미션 준비비/조작·후속9레시피와 추가부모2종 기획을 [후속 상세표](followup-content-tables.md)에 연결했다. 무료 다이아 수급과 연구원 가격 접근성·전체 성장 수급/플레이 기간/재미는 후속 검증이다. 개방할기술의실제미션은그연구소구간에맞춰배치하며Lab20원종기본목표에Lab25최상위추적을일괄중복요구하지않는다. 현재서버/클라이언트에는이기술트리가구현돼있지않다.
