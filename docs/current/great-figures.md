# 위인·보유 효과·GP 영입 통합 기획 0.6

기준일: 2026-11-17 · 상태: 기획·수치 기준안. 런타임 적용 및 실제 수급/효과 검증 전.

## 1. 소유 범위와 정본

이 문서는 위인50명의 역할·GP 영입·보유 효과·시설 배정·Lv.1~10 성장·컬렉션 시너지의 현행 기획을 소유한다. 인물 서사·등장 시점·시즌 결말은 [스토리와 인물](story-and-characters.md), 초반 실제 목표는 [스토리 진행](story-progression.md), 시간·자원·입장료의 기본 규칙은 [밸런스](balance.md)와 [자원·생산](resources-and-production.md)을 따른다. 가이드북 JSON은 이 정본을 출처 지문과 함께 요약하며 실행 설정이 아니다.

50명은 과학자10·건축/엔지니어7·경영7·탐험6·조련/사육7·의료5·보안4·특수4다. 카탈로그 등급을 유지해 일반16·희귀22·영웅8·전설4명이다. 보유 인물을 복제하거나 같은 인물을 시즌 위인으로 다시 합산하지 않는다.

기본 소모품은 일반4종+연구5종=9종, 연구재료만3품질이다. GP는 위인 영입용 별도 재화이며 기본 소모품에 포함하지 않는다. 새로운 증서·별가루·종별 DNA·선물 재료를 만들지 않는다. 연구원은 시작 무료1명/추가 다이아, 건설자는 별도 골드 고용이다. 위인이 인원·병렬 합성·연구 권한을 대신하지 않는다.

## 2. 등장·영입·GP 수급

스토리에 등장해 돕는 것과 컬렉션으로 소유해 수치 효과를 얻는 것은 구별한다. 닥터 진·마르코·올리비아 등 핵심 조력자는 GP 미보유여도 정해진 장면에서 돕는다. 인물별 출현 자격은 선택 영입을 여는 조건이며, 기존 초반18장면·첫 연구·첫 합성에 새 위인 보유 조건을 추가하지 않는다. 출현 자격과 가격을 모두 충족했을 때 GP를 차감하고1레벨 인물을 소유한다. 가챠·중복 인물·GP의 다이아 환전·구독/광고 전용 필수 공급은 두지 않는다.

| 등급 | 인원 | 인물당 영입 GP | 전원 정가 GP |
| --- | ---: | ---: | ---: |
| 일반 | 16 | 100 | 1,600 |
| 희귀 | 22 | 300 | 6,600 |
| 영웅 | 8 | 1,200 | 9,600 |

영입 GP는 등급별 표 하나를 사용한다. 특수 인물의 시즌·이벤트 자격은 별도로 충족하며, 아서는 살아 있는 직원의 채용이 아닌 유산 기록 컬렉션 등록이다. 기존에 적법하게 보유한 인물/레벨은 보존하고 GP로 다시 구매시키지 않는다. 이미 지출한 다이아의 임의 환급·재차감은 이 문서에서 수행하지 않으며 이관 계약으로 검증한다.

| GP 공급 | GP | 반복과 중복 방지 |
| --- | ---: | --- |
| 프롤로그 유산 최초 완료 | 100 | 파크당 최초1회. 프롤로그 완료 이력으로 한 번 지급 |

누적 유료 입장은 실제 입장료가 정산된 방문 기록을 사용한다. 무료 구경·거절된 입장·금고가 가득 차 중단된 입장·입장료 미수금에는 GP를 주지 않는다. GP는 별도 방문객 카운터를 다시 만들지 않고 기존 누적 입장 기록의 미수령 구간을 읽는다. 한 번의 정산에서 영입·GP 잔액·소유/수령 이력을 함께 갱신하고 재요청은 같은 결과를 반환한다. 실제 공개 종만 최초 등록 GP 대상으로 쓰며 계획상83종을 선지급하지 않는다. 본편/종 보상과 장기 방문 반복을 합친 실제 영입 기간은 아직 실측하지 않았다.

## 3. 위인 성장과 비용

모든 등급은 최대10레벨이며 아래 누적XP표 하나를 사용한다. GP는 영입에만 쓰고 성장에 다시 청구하지 않는다. 자연XP는 유효 지원 작업·교감·개인 목표에서 얻는다. 골드 훈련을 선택하면 다음 레벨에 부족한 XP만1XP당10골드로 채운다. 자연XP가 누적되면 그만큼 훈련비가 줄며, 0XP→Lv.10을 전부 골드로 채울 때 총45,000골드다. 성장 비용은 방문객 입장료로 번 골드의 사용처이며 별도 직접 수익을 만들지 않는다.

| ---: | ---: | ---: | ---: |
| 1 | 0 | 100 | 1,000 |
| 2 | 100 | 200 | 2,000 |

Lv.1에 기본 보유·배정 효과와 첫 지원 목표, Lv.5에 운영 지침과 숙련 지원 목표, Lv.10에 최종 수치와 개인 이야기를 연다. Lv.1 목표는 영입 후 해당 전문 지원 작업1회 완료, Lv.5 목표는5레벨 이후 해당 지원 작업5회 완료이며 각각100XP를 한 번 받는다. 아서는 기록 확인/정리 목표를 같은 단계로 진행하며 현장 지원 작업으로 세지 않는다. Lv.10 개인 이야기는 최종 연출이므로 추가XP를 주지 않는다. 개인 목표는 해당 인물의 전문성을 보여 주는 목표·대사·칭호/연출이다. 이미 기술이 소유한 원종 조사·레시피·시설 권한을 우회하거나 공룡/알/재료를 즉시 지급하지 않는다. 같은 표를 아서에게는 훈련이 아니라 유산 기록 정리·복원으로 표현한다.

| 자연XP 계기 | XP | 수령 대상·이력 |
| --- | ---: | --- |
| Lv.1·Lv.5 연계 운영 목표 검증 완료 | 100 | 그 인물. 각 단계 목표별1회. Lv.10 최종 연출에는 추가XP 없음 |
| 배정한 인물이 실제 지원한 건설·기술·합성·부화·조사·치료·정비·대응 작업 검증 완료 | 20 | 그 작업의 시작 시 고정된 지원 인물1명. 작업ID별1회. 실패·취소·수령 재호출에는 지급하지 않음 |

공룡 개체XP·파크XP·위인XP는 서로 다른 누적치다. XP 보상을 GP나 골드로 환전하지 않고 단순 화면 조회·재접속·무효 돌봄·작업 취소로 얻지 않는다. 작업 시작에 정한 지원자와 작업ID를 보상 소유자가 사용한다. 같은 입장1000명 구간으로 운영 위인XP를 여러 명에게 돌려 지급하지 않는다.

## 4. 보유·배정·중첩과 최종 하한

같은 효과·같은 대상마다 보유한 인물의 값 중 최고1개, 적합하게 배정된 인물의 값 중 최고1개, 조건을 만족한 관계/분류 시너지 중 최고1개를 선택한다. 합계에 아래 최종 상한을 적용한다. 보유는 배정하지 않은 인물/아서 기록도 포함한다. 50명의 보유값을 전부 더하지 않는다. 한 사람의 보유값과 배정값은 서로 다른 슬롯의 보너스이며 함께 적용할 수 있다.

`위인효과 = min(효과상한, 보유최고값 + 유효배정최고값 + 시너지최고값)`

대상은 프로필의 적용 범위로 제한한다. 해양·익룡·야간 전용 값은 해당 조건에서만 후보가 된다. 관람 수요와 파크 공통 유지비처럼 전역 효과는 여러 시설의 배정값도 최고1개만 고른다. 다른 이름의 관람·경관·공연·홍보 보너스를 별도 곱으로 다시 추가하지 않고 같은 visitor_demand 항목에 모은다. 조사 단서는 해당 미션 안에서 최대4개이며 한 단서를 다시 열어 새 보상으로 세지 않는다. 도움은 정답 자동 선택·미션 생략·추가 알·재료량·품질·확률 보너스를 제공하지 않는다.

시설당 지원 위인1명, 인물당 시설1곳이다. 기술 연구원·건설자의 실제 인원 점유는 원래 규칙을 따른다. 자신을 지원자로 기록한 작업이 하나라도 진행 중이면 그 위인을 다른 시설에 재배정할 수 없다. 모든 지원 작업의 완료·취소 후 이동하며 이미 시작한 작업의 비용·완료시각·XP 수령자는 소급 변경하지 않는다. 아서의 유산 기록은 배정 후보에 표시하지 않는다. 관계는 두 인물을 같은 시설에 넣는 대신 보유 컬렉션으로 판정한다.

시간은 원천의 건물·기술 계산 이후 위인 단축을 곱하고, 원천의 올림 단위와 최종 하한을 마지막에 적용한다. 24→25 건설은 모든 일반 단축 후에도 최소7일, 기술은 밸런스15절의 유효 연구소15~19 최소7일·20~24 최소14일·25 역할별14/21/28일과 더 긴 개별 지정 하한을 유지한다. 위인이 진행 작업을 즉시 완료하거나 연구원을 늘리지 않는다. 첫 지정 스테고케라톱스는30분·4,000골드·100%·정해진 재료를 그대로 사용하고 위인 할인을 제외한다.

일반 합성은 영웅50%·전설10%와 최대5/8번째 보호를 그대로 유지한다. 등급 상향·쌍둥이·DNA 자동 채취/복제·무료 재료·즉시 전설화·원종 보유 면제는 위인 효과에 없다. 재료 종류·품질·수량, 기술의 기존 비용 할인 상한·실패 반환 규칙도 바꾸지 않는다.

위인 유지비 할인은 기존 운영 유지비에만 적용한다. 기본 물자 구매·생산 배치비·입장료·건설비·기술비·합성비·직원 고용비를 할인하지 않는다. 기존 원천에 총할인 상한이 있으면 위인까지 포함해 그 상한을 넘지 않으며, 위인5% 상한은 별도로 지킨다. 감소할 비용/시간은0미만이 되지 않는다. 회복/교감은 원래 상태 상한까지만 증가한다. 치료·정비·대응의 기본 작업이 실제 연결되기 전에는 배정 수치가 있다는 이유로 완료 동작을 활성화하지 않는다.

관람 수요가 늘면 입구 처리량과 전시 구역 수용량이 허용하는 범위에서 손님이 더 들어온다. 실제 매출은 금고에 받은 유료 입장료로 기록한다. 후원·상점·공연 전문가는 관람 경험과 수요를 돕는다.
