# 공룡 83종 최초·반복 획득표 0.6

**담당 정본에서 생성한 읽기용 표입니다. 실제 게임 적용을 뜻하지 않습니다.** [획득 정본](dinosaur-acquisition.md)은 전체 연결과 보완17목표·첫 랩터를, [DNA](dna-and-collection.md)는15레시피를, [밸런스](balance.md)는 기존 알 밴드를 소유합니다.

아래 비용과 시간은 한 회차의 기본값입니다. 일반 부화·합성의 완료 연구/시설 보정은 해당 정본을 따릅니다. 첫 부화 예외와 첫 지정 스테고100%·30분은 고정입니다. 합성 재료·부모 상세는 같은 문서의15레시피 표에서 확인합니다.
