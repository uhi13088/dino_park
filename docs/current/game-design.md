# 다이노 파크 타이쿤 — 게임 기획 0.6

기준일 2026-11-19 · 첫 스테고케라톱스 전시·반복 합성, 금속 구매와 관람대 Lv.5까지 구현 · [문서 안내](../README.md)


72개 기술의 모든 레벨에 필요한 자원·기본시간·최종하한은 [전체 비용표](research-cost-tables.md), 레벨별 효과는 기존14개의 [연구트리 효과표](research-trees.md#5-기본-연구-효과-수치)와 나머지58개의 [효과 상세](research-effects.md)에 정리했다. 252회 연구의 효과 정의를 마쳤으며 후속 시설·미션·레시피와 실제 게임 적용은 별도 작업이다.


## 1. 어떤 게임인가

**버려진 공룡 파크를 재건하고, 방문객의 입장료로 시설과 연구에 투자하는 수집·경영 게임.** 탐험으로 자연종을 만나고, 수집한 DNA를 합성해 변종과 하이브리드를 만든다. 새로운 공룡을 안전하게 전시하면 방문 수요가 늘고 다음 구역·연구에 투자할 수 있다.

장기간 파크를 계속 운영하고 확장하는 게임을 목표로 한다. 처음에는 파크를 재개장하고, 이후 운영·생산·탐험·연구·공룡 수집을 병행하며 파크를 성장시킨다. 자원 종류·품질·생산/사용처는 [자원·생산 기획](resources-and-production.md), 운영·생산 수치는 [밸런스](balance.md), 공룡 획득과 개별 합성 레시피는 [DNA 기획](dna-and-collection.md), 기술 항목·선행·영구 효과는 [기술 연구트리](research-trees.md)가 관리한다. 주요 건물25레벨·5레벨마다 큰 변화·전체 골드 금고·탐험 연료 통합은 이번 확정 방향이다. [건물 기획](buildings.md)과 [전 단계 표](building-upgrade-tables.md)의 상세 수치는 설계 기준안이며 이번 첫 영웅 전시까지 적용한 시설과 구별한다. 시설은 건물 기획의 역할 분류와 기능 통합 기준을 따른다.

### 사용자 확정 요구

- 스토리·인물·위인·시즌은 일관된 현재 설정으로 통합한다. 아서는 창립자로서 마지막 여정을 마치고 유산을 남기며, 위인 영입에는 전용 포인트GP를 사용한다. 위인의 보유·시설 배정 효과와 레벨 성장은 [위인 기획](great-figures.md)을 따른다.

- 현재 목표는 장기간 파크를 지속적으로 운영·확장하는 게임이다. 앱인토스는 초기 플랫폼 검토 배경이며 현재의 플레이 시간·접속 주기·행동 수를 정하는 근거가 아니다. 후반 건설·연구가 진행되는 동안 운영·탐험·공룡 수집을 병행한다.

- 연구 계열은 운영·사육·탐험·유전4개를 유지하고 **계열당최소18개** 기술을 둔다. 연구소 강화와 기술을 통해 부지/시설 구간·새 공룡 목표·넓은 탐험 지역을 개방하며 모든 건물/재료/연구의 목적을 명확히 한다.

- 연구소의 기술 연구 항목은 각각3~5레벨이며 연구원 여러 명으로 서로 다른 항목을 병렬 진행한다. 연구원 역할은 DNA 합성과 구별한다. 시작부터 연구원1명 무료, 추가 인원은 다이아로 영구 구매한다. 극초반 연구는1분부터, 후반 개별 연구 단계는 시간 보정 후최소7일로 설계한다.

- 도입은 창립자의 편지를 받고 15년간 버려진 파크를 재건하는 설정이다.
- 파크 외곽 경계와 입구가 보여야 한다. 서식지 울타리와 공원 테두리를 구분한다.
- 매출은 방문객 입장료다. 공룡을 골드 생산기로 취급하지 않는다.
- 배치·돌봄 → 입장료 → 시설 투자 → 두 번째 공룡을 짧은 튜토리얼로 잇는다.
- 탐험뿐 아니라 DNA 합성으로 변종·하이브리드를 얻는다. 레시피의 원종을 실제 보유해야 하며 결과 등급이 높을수록 실패율이 높아진다.
- 변종·하이브리드는 영웅 또는 전설 등급만 사용한다. 파라 한 마리로 시작하고 첫 지정 합성은 100% 성공해 모두 영웅 스테고케라톱스 한 마리를 획득한다.
- 첫 전시 이후 반복 합성에 성향 선택을 연결한다. 합성 전 매력도·속도·체력·공격성의 예상 수치와 확률을 보고, 성공한 개체에는 결과 수치를 저장한다. 전시 공룡의 매력도는 방문 수요에 반영한다.
- 합성 재료는 탐험으로 모은다. 연구소의 정기 채취나 자동 재료 생산은 추가하지 않는다.
- 탐험 장소를 선택하고 미션을 수행해 그 장소의 연구 재료를 얻는다. 구체적인 미션 조작과 재미는 검증 중이며, 대기 시간만 지난 것을 플레이 완료로 취급하지 않는다.
- 기본 운영 자원의 필요성·획득처·사용처를 먼저 연결하고 복잡도를 억제한다. 스토리·이벤트 아이템은 필요할 때 이후 추가한다.
- 초기 에셋의 실루엣과 배치 기준을 참고해 현재 만드는 기능에 필요한 2.5D 게임 이미지를 제작한다. 파일과 시점은 [제작 명세](production-and-services.md#3-에셋-제작과-파일-기준)를 따른다.
- 주요 시설은25레벨까지 성장하며5·10·15·20·25에서 외형이나 기능이 크게 바뀐다. 건물 레벨 하나만 표시하고 별도 승급 등급을 더하지 않는다.
- 금고 강화가 전체 보유 골드 한도를 늘린다. 누적 입장료 실적은 별도 기록하고 기존 초과 잔액은 보존한다.
- 탐험 에너지를 연료로 통일하고 자동 회복과 연료 보급소를 함께 사용한다. 두 번 차감하는 별도 재고는 만들지 않는다.

이번 기본 자원 설계는 일반 자원 4종과 연구 재료 5종, 총 9종이다. 품질은 연구 재료에만 적용한다. 이 구조와 공식·가격·연구 시간은 설계 기준안이며, 미정 수치와 실제 구현 상태를 담당 문서에서 구분한다.

## 2. 핵심 루프

```text
공룡 배치·돌봄 → 안전한 관람 환경 → 방문객 유료 입장 → 금고 한도 안의 골드
       ↑                                             ↓
새 공룡 전시 ← 탐험 미션·알 부화 / DNA 합성 ← 시설·탐험·연구 투자

입장료 골드 → 일반 자원 구매·생산 → 자재로 건설 / 사료로 돌봄 → 운영 확장
```

탐험은 새로운 원종과 합성 재료를 찾는 경로다. 합성은 보유 원종과 탐험 재료를 사용해 원하는 결과를 연구하는 경로이며 등급별 실패와 재도전이 있다. 원종은 성공·실패 모두 소모하지 않는다.

일반 자원은 목재·석재·금속·공용 사료다. 이들의 생산은 골드와 시간을 사용하며, 탐험 에너지나 별도 미니게임을 요구하지 않는다. 전력·물·연료는 유지비로 처리하고 생산 건물이 직접 골드를 만들지 않는다.

## 3. 먼저 완성할 플레이 범위

계정마다 한 파크를 운영한다. 같은 서버에 접속한 계정의 파크·공룡·재료·진행은 따로 저장된다. 첫 제작 범위는 파라로 파크를 열고 이구아노돈을 부화한 뒤, 원종 알과 재료를 모아 첫 스테고케라톱스를 합성하고 관람객이 볼 수 있는 서식지에 배치하는 데까지다.

그 전시를 마친 파크에서는 중급 재료를 다시 모아 스테고케라톱스를 반복 합성할 수 있다. 관람형·질주형·균형형을 고른 뒤 새 개체의 실제 능력치를 비교하고, 관람 수요와 예상 입장객 수를 확인해 대표 전시 개체를 교체한다.

전체 수집 기획은 공룡83종과 위인50명이며 시즌·교류·상점도 파크의 장기 콘텐츠로 연결한다. 초기 제작은 첫 성장 루프부터 진행하고 이후 지역·종·시스템을 단계별로 확장한다. 육식·격리·해양·야간 관람은 필요한 서식지와 동선이 준비된 뒤 확장한다.

## 4. 공간과 파크 운영

| 요소 | 동작 기준 |
| --- | --- |
| 외곽 경계 | 저장된 `Park.gridSizeX/gridSizeY`의 바깥선을 사용. 초기 경계는 무료이며 이후 토지 확장은 기술 권한·확장 비용·공사로 진행. 레벨업으로 자동 확장하지 않음 |
| 입구 | 경계와 이어진 출입구. 개장/폐장, 누적 유료 입장객, 입장료 매출 표시 |
| 기본 길 | 입구에서 초원 관람 지점으로 연결. 손님은 길과 관람 지점에서만 이동 |
| 서식지 | 공룡의 생활 공간. 방문객 길과 분리. 호환 종·수용량을 검증 |
| 관람대 | 길에 연결된 관람 지점과 동시 관람 정원 추가. 건물 자체의 자동 골드 생산은 없음 |
| 연구소 | 탐험 재료·보유 원종·성공률을 확인해 합성. 완성한 공룡은 전시해야 방문 수요에 기여 |

개장에는 입구와 길, 관람 가능한 공룡, 돌봄 완료가 필요하다. 폐장·동선 단절·전시 공룡 없음이면 새 유료 입장은 없다. 손님이 입장할 때 한 번 결제하고, 관람·퇴장 때 다시 매출을 만들지 않는다.

신규 파크는 입구와 기본 길이 경계에 맞는 배치를 제공한다. 기존 계정의 배치·골드는 보존하고, 경계 도입으로 출입구 이동이 필요한 경우 무료 이동을 제공한다. 과거 저장 좌표를 일괄 덮어쓰지 않는다.

서버가 입장 인원·골드·정산 시각을 확정한다. 화면의 손님 수는 혼잡을 보여주는 연출이며 서버의 실제 정산 인원과 구별한다. 온라인·오프라인을 같은 규칙으로 정산하고, 예전 공룡 직접 수익을 함께 지급하지 않는다.

### 금고와 탐험 연료

기본 금고는 무료 제공하며 전체 골드 한도를 관리한다. 금고가 차면 새 유료 입장만 멈추고 기존 관람·시설·탐험·지출은 이어진다. 돈을 쓰면 입장이 재개된다. 미수금이나 숨은 별도 예금으로 한도를 우회하지 않는다. 화면은 보유/한도, 예상 적립 중단과 금고 강화 비용을 함께 보여준다. 누적 입장료는 실제 받은 총매출 기록으로 유지한다.

연료는 현재 탐험 에너지와 같은 재고다. 자동 회복으로 탐험을 계속할 수 있고 보급소에서 추가 생산하거나 급한 물량을 구매한다. 생산품 수령 전에는 사용할 수 없고 탱크가 차면 완료 생산품을 보존한다. 금고·탱크·작업비/시간은 밸런스 원천을 따른다. 첫 합성에 높은 금고/보급소 레벨을 요구하지 않는다.

## 5. 첫 10분

| 순서 | 플레이와 목적 | 완료 조건 |
| --- | --- | --- |
| 파크 보기 | 닥터 진의 짧은 안내, 외곽 경계·입구·첫 서식지 확인 | 안내를 접어도 조작 가능 |
| 첫 친구 | 지급된 파라 배치·급식 | 서버의 배치·급식 기록 인정 |
| 재개장 | 길을 확인하고 개장, 손님과 첫 입장료 확인 | 검증된 유료 입장 실적 |
| 첫 투자 | 번 입장료로 관람대 선택·배치·건설 | 취소 시 무차감, 완공 후 관람 정원 증가 |
| 첫 탐험 | 완공된 첫 관람대 뒤 초원 정찰에서 단서 세 개를 직접 조사 | 순서에 맞게 단서를 확인한 뒤 이구아노돈 지정 알 한 개 수령 |
| 두 번째 친구 | 받은 알을 보관 → 기본 슬롯에서 수동 부화 시작 → 수령 → 파크 배치 | 부화 시간 경과와 개체 수령을 구분하고 새 개체·도감·목표 XP 한 번 처리 |
| 선택 확장 | 파크 Lv.2부터 벌목장·채석장과 목재·석재 구매/생산을 탐험과 병행 | 생산 시설은 첫 탐험의 필수 조건이 아니며, 재료를 모아 파크 Lv.3에서 관람대 Lv.2 확장 |
| 다음 목표 | 종 다양성에 따른 수요 변화, DNA 연구 예고 | 주행 목표에서 트리케라톱스·스테고사우루스 알을 회수 |

첫 튜토리얼에서 별도 부화장 선구매를 요구하지 않는다. 기본 부화 자리 한 칸을 사용하며 부화장을 완공하면 세 칸으로 늘어난다. 첫 급식은 현재 직접 급식 흐름을 유지하고 사료 재고/생산 전환은 후속으로 둔다. 첫 관람대는 골드만 사용한다. 탐험 미션의 조작 시간과 부화·건설의 서버 타이머를 구별하며 상세 가격·시간은 밸런스 문서에서 관리한다.

튜토리얼은 목표 카드 하나와 닥터 진의 짧은 단서 안내로 구성한다. 초원 정찰에서는 발자국·먹이 흔적·둥지를 구별하는 세 번의 선택을 서버가 순서대로 확인한다. 강제90초 대기나 타이머 자동 성공은 없고, 오답·재접속·같은 단계 재전송에 준비비를 다시 받지 않는다. 알은 직접 수령해 보관하고, 수동 부화 시작 후 정해진 시간이 지나야 새 개체를 수령한다.

튜토리얼 표시 진행은 기존 `User.tutorialStep`, 미션 조사 체크포인트는 해당 탐험의 단계가 소유하며 실제 보상은 알·부화·수령 이력으로 검증한다. 클라이언트의 튜토리얼 숫자만 올려 보상을 건너뛰지 못한다. 보유 골드 총액을 매출로 보거나, 이미 배치·급식한 유저에게 같은 행동과 시작 보상을 다시 요구하지 않는다.

관람대는 기존 Lv.2 해금을 유지한다. 첫 입장료 목표의 파크 경험치 보상으로 그 레벨에 도달하게 한다. 시설 해금은 `Park.level`을 기준으로 하며 `User.level`을 별도 시설 해금값으로 병행하지 않는다. 현재 서버의 파크 경험치 공식은 공유 함수를 사용한다. 이전 돌봄 이력(관람 가능한 공룡의 친밀도 양수)도 인정해, 오래 쉰 기존 계정에 첫 급식을 다시 강제하거나 낮은 행복도 때문에 개장을 영구 차단하지 않는다. 현재 돌봄 상태는 방문 수요에 계속 반영한다. 새 첫 이구아노돈은 건강한 부화 상태를 돌봄 완료로 인정해 목표 XP700을 한 번 받고, 추가 급식을 강제하지 않는다. 기존 이구아노돈 보유·도감 이력도 인정하며, 첫 돌봄 경험치는 같은 계정에 한 번만 반영한다. 트리케라톱스와 스테고사우루스의 기존 보유나 부화 중인 알도 인정한다. 전시에 쓰던 원종을 방생했다면 탐험에서 유료 재입수할 수 있다.

## 6. 첫 합성까지의 진행

첫 스테고케라톱스까지의 **경과4~6시간**은 초반 성장 속도를 검토할 설계 기준안이다. 연속 플레이와 중간에 쉬었다 이어 하는 플레이를 각각 검산하며, 접속 시간·주기와 접속당 행동 수는 고정하지 않는다. 실제 소요 시간은 현재 시작 자금·금고·연료·탐험·시설·대본을 함께 연결해 검증한다. 미션과 대사의 조작 시간은 구현 후 측정하며, 비용과 검산 기준은 [밸런스](balance.md)를 따른다.

| 진행 구간 | 공룡·탐험 | 시설·운영·스토리 |
| --- | --- | --- |
| 첫 10분 | 파라 돌봄 → 첫 정찰 → 이구아노돈 | 재개장 → 첫 관람대. 기존 첫 플레이 유지 |
| 원종 탐색 | 육상 주행의 목표를 채우고 귀환해 트리케라·스테고 알 수령 | 목재·석재의 구매/생산 소개, 부화장·관람대 확장과 챕터 1 재건 |
| 부화·돌봄 | 원종 두 알을 실제 부화·보유 | 부화 대기 동안 일반 자원 생산·시설 정리·연구소 준비 |
| 첫 연구 재료 | 화석 계곡·원시 습지에서 DNA·배양액 확보 | 육식 서식지·보안센터와 챕터 2 안전 절차. 금속은 아직 필수 아님 |
| 연구 준비 | 버려진 연구소의 미션으로 촉매 확보 | 챕터 3의 지하 연구소·과거 사건·연구 방향 선택, 초식 하이브리드 서식지 준비 |

| 이후 확장 | 금속·안정제·승급, 이후 변이세포·상급 연구 | 상위 시설과 변종 연구로 확장 |

이 표는 진행 순서다. 비용·필수 해금·타이머·목표 미션 보상량과 검산 결과는 [밸런스](balance.md)가 소유한다. 생산·건설·부화·합성의 시작한 타이머는 앱을 꺼도 진행하고, 탐험 미션은 플레이 진행 상태를 보존해 돌아와 이어 한다. 앱을 껐다는 이유로 미션을 자동 성공시키지 않는다.

첫 원종 알과 핵심 연구 재료는 각 목표 탐험의 첫 완료 보상으로 보장한다. 대화만으로 재료를 즉시 지급하지 않는다. 원종 알을 받았다는 이유로 합성을 허용하지 않으며 부화한 실제 개체를 보유해야 한다.

첫 스테고케라톱스의 장면과 챕터 순서는 통합 스토리를 따른다. 프롤로그부터3-6까지18장면의 최신 대본·진입/완료 조건·플레이 목표·보상 연결은 [초반 스토리 진행과 대본](story-progression.md)이 소유한다. 첫 합성4~6시간은 초반 성장 속도의 설계 기준안이며 최신 대본의 실제 소요시간은 아직 측정하지 않았다. 대본과 조건의 실제 게임 적용 상태는 구현 현황에서 확인한다.

첫 관람대 해금은 파크 Lv.2, 관람대 건물 Lv.2 강화와 부화장·연구소 준비는 파크 Lv.3, 원종 두 종 돌봄 후 안전 시설은 파크 Lv.4, 챕터 2 안전 완료 후 첫 하이브리드 전시는 파크 Lv.5를 목표로 한다. 골드 총액만으로 스토리와 합성을 건너뛰지 않는다.

첫 합성 이후에는 원종 수집·탐험·재료 승급·연구를 반복하며 변종과 상위 하이브리드를 해금한다. 상위 레시피는 결과 등급에 따른 실패율과 재도전 규칙을 사용한다. 첫 합성 이후Park5~50의 목표·경험치·시설/기술/탐험·본편 연결은 [파크 성장 정본](park-progression.md)과 [레벨별 공급표](park-progression-tables.md)를 따른다. 표의 권장 준비와 실제 기술/시설 해금을 구별하며 야간·해양·전설급의 실제 전체 진행 일수는 후속 검증 대상이다.

## 7. 연구를 통한 확장과 시설 조작

0.6의 성장 중심은 **입장료 → 연구소 강화 → 기술 완료 → 새 부지·시설 단계·탐험/공룡 목표 → 실제 플레이·건설·수집·전시**다. 계열별6분야×3기술=18개,총72개 기술·총252회 연구의 목적안은 [연구트리](research-trees.md)가 소유한다. 분야는 화면 묶음이며 별도 강화 대상이 아니다.

기본 시설 상한5에서 연구소5/10/20의 시설 고도화1/2/3을 통해 주요 시설 상한10/20/25를 연다. 연구소도 이 순서를 따라 자기 잠금이 없게 한다. 토지 기술은 확장 권한을 열고, 실제 확장은 미리보기·비용 확인을 거친 별도 행동이다. 사육 기술은 호환 환경, 탐험 기술은 지역/임무, 유전 기술은 원종 조사/레시피를 담당한다. 첫 이구아노돈과 첫 지정 영웅까지는 기존 기초 흐름을 보존한다.

기존14개 효과를 유지하고 나머지58개의 레벨별 효과·해금 대상·중첩을 정의했다. 부지5확장·특수5시설의125레벨·기초/연구 재료미션46개·자연종별 반복 알목표68개·첫 랩터 예외1개·합성15레시피를 [후속 상세표](followup-content-tables.md)에 연결했다. 시노케라톱스·메갈로돈2종은 추가 기획으로 계획83종이며 현재 실행81종과 구별한다. 83종의 최초/반복 획득·해금·준비비·부화/합성은 [전체 획득표](dinosaur-acquisition-tables.md)를 따른다. 효과 정의 완료를 전체 경제·실제 플레이 검증 완료로 보지 않는다.


최종24→25 한 번은 일반 강화/관리사무소 보정 후에도 최소7일의 장기 목표다. 기본 기능·첫 부화/합성은 낮은 레벨부터 제공하고 대기 중 다른 운영/탐험/연구를 이어가게 한다. 건설자 한 명이 공사 한 건을 맡고 추가 고용으로 여러 공사를 병렬 진행한다. 장기 강화가 다른 공사를 모두 막지 않도록 무료 초반 인원과 고용 기준을 밸런스에 연결한다. 연구원은 게임 시작부터무료1명이며 추가인원은다이아로영구구매한다. 각각3~5레벨인 기술 항목을 담당하며 인원수만큼 서로 다른 기술을 병렬 연구한다. DNA 합성은 별도 기본1개 작업으로 연구원 슬롯을 공유하지 않는다. [기술 연구트리](research-trees.md)의4계열72항목·효과/선행은 상세 설계안이다.

주요 시설21종의1~25레벨 성능·자재·비용·기본 시간은 [밸런스](balance.md)와 그 원천에서 생성한 [상세표](building-upgrade-tables.md)를 따른다. 건물 레벨과 파크 레벨을 구별하고 첫 연구는 기초 시설만으로 가능하게 한다. 같은 부지에서 외형/성능을 강화하며 장식은 무강화 배치로 둔다. 강화 중에는 기존 완공 레벨로 운영하고 다음 시간 할인/한도 증가는 완료 뒤 적용한다.

건설은 `선택 → 골드·자재·효과 → 배치 미리보기 → 확정 → 완공`으로 진행한다. 전체 점유 면적·경계·동선·공룡/건물 점유와 비용을 서버에서 함께 검사/차감한다. 첫 관람대와 초기 생산 시설의 골드 전용 예외·이후 자재 구분은 자원 기획을 따른다.

생산은 `일반 자원 선택 → 골드·수량·완료 시각 → 시작 → 완료 수령`이다. 급한 기본 물자는 골드로 구매할 수 있다. 사료 재고가 있으면 급식 때 골드를 다시 차감하지 않는다. 연구 재료는 이 구매/생산 경로에 포함하지 않는다.

DNA 합성은 `결과 공룡 선택 → 부족 재료 확인 → 탐험·재료 승급 → 합성 → 완료 수령 → 배치`다. 결과 종의 등급에 따라 실패율과 최대 시도 횟수를 표시하고, 실패 시 필수 재료 일부를 돌려준다. 원종 공룡은 유지하며 재료를 탐험으로 보충해 재도전한다. 변종과 하이브리드도 전시 수요에 기여하며 직접 골드를 주지 않는다.

현재 반복 합성은 스테고케라톱스에 적용하며 기본 성공률은 50%다. 네 번 연속 실패하면 다섯 번째 시도가 확정 성공한다. 세 성향의 능력치 추첨 범위와 확률은 [DNA 기획](dna-and-collection.md)을 따른다. 대표 전시를 바꾸기 전에는 후보의 매력도를 반영한 분당 관람 수요와 관람 정원에 따른 분당 예상 입장객을 확인할 수 있다.

기술 연구는 `계열 선택 → 다음 기술 단계·선행·비용 확인 → 연구원1명 배정 → 시간 경과 → 100% 완료·영구 효과 적용·연구원 자동 반환`이다. 기술 연구는 기존 골드/건설 자재를 쓰며 공룡 배정·합성용 연구 재료·새 과학 재화는 요구하지 않는다. 첫 스테고케라톱스는 기술 연구 없이 가능하다.

## 10. 구현 순서와 완료 기준

1. **BAL-01 — 0.4 당시 설계 검산 완료:** 일반 자원 구매/생산·자재 건설·직접 미션의 초반 수치안과 5경로 모델. 아래 구현 묶음에서 실제 연결·검증한 뒤 적용.
2. **PLAY-02/03 — 구현 완료:** 경계·입장료·첫 관람대. 첫 관람대는 골드 전용이며 기존 계정·배치를 보존. 첫 탐험/두 번째 공룡은 PLAY-04 연결 범위다.
3. **PLAY-04/RES-01A — 구현·검증 완료:** 첫 초원 조사·이구아노돈 부화/배치와 선택 목재/석재 생산·관람대 Lv.2 확장. 실제 종합 판정은 TASK의 최종 실행 기록을 따른다.
4. **PLAY-05 및 DNA-01/02의 첫 전시 범위 구현.** 두 원종의 알 회수와 부화, 안전 시설과 안전 목표, 중급 재료 수령, 첫 영웅 합성과 전시를 연결했다. 첫 전시와 도감은 재접속 뒤에도 보존된다.
5. **첫 전시 이후 반복 합성.** 중급 재료를 다시 모으고 스테고케라톱스의 성향을 선택한다. 합성 결과를 받아 능력치를 비교하고 예상 입장을 확인한 뒤 대표 전시를 바꾼다.
6. **첫 전시 뒤 Lv.5→6 성장.** [성장 목표](park-progression.md#첫-전시-뒤-파크-lv6까지)의 네 조건을 완료하고 각각 897 XP를 받아 레벨을 올린다.
7. **후속 운영 확장.** BUILD-01/ECON-02/FUEL-01 및 RES-01 후속은 25레벨 강화·금고·연료 보급·누적 카운터·금속·사료·창고를 연결한다.
8. **후속 수집과 본편.** 품질 승급, 추가 종 레시피, 야간·해양 관람, 상위 연구와 나머지 이야기 장면을 연결한다. 파라 룩스의 도감·카탈로그·예정 레시피는 CODEX-01에서 완료했다.
