## 1. 수치 원천과 현재 게임

이 문서가 건물별 효과·골드·자재·작업비·시간·저장 한도와 기술 연구의 비용/기본 시간을 소유한다. 기술 항목·선행 조건·완료 효과는 [기술 연구트리](research-trees.md)가 소유한다. [건물 기획](buildings.md)은 역할·외형·도입 순서, [자원 기획](resources-and-production.md)은 자원의 의미와 수급/사용 규칙, [DNA 기획](dna-and-collection.md)은 레시피·연구비·기본 연구 시간을 소유한다. 아래 표를 읽는 [검산 도구](../models/check_building_progression_v06.py)가 [건물별 전 레벨 표](building-upgrade-tables.md)를 생성한다. 파생표를 별도로 수정하지 않는다.

위인 영입 전용재화GP의 수급·인물별 영입비·성장 경험치/골드·보유/배정 효과·시너지 상한은 [위인 통합 기획](great-figures.md)이 소유한다. 일반 연구원 다이아 구매와 건설자 골드 고용은 이 문서의 인력 표를 따른다.

사용자 확정 방향은 주요 시설25레벨·5/10/15/20/25에서 큰 외형/기능 변화, 전체 보유 골드의 금고 한도, 탐험 에너지와 연료의 단일 재고다. 개별 수치는 이번 설계 기준값이며 실제 접속/수집 속도에 따라 후속 조정한다. 장식은 강화 없이 배치한다.

현재 게임은 시작10,000골드, 입장료20, 첫 조사100골드/에너지5·수동60초 부화, 목재/석재 생산, 관람대Lv.1~2까지만 연결했다. 이번 변경은 문서·설계 모델이다. 기존 계정의 돈·에너지·공룡·시설·좌표와 실행 코드는 변경하지 않는다. 과거5레벨 제안과 0.4 전체 모델은 [0.4 보관본](../archive/0.4/balance.md)에 남긴다.

## 3. 최초 건설과 도입

아래 park는 최초 건설 해금에 필요한 파크 레벨이다. 기본 입구·초원·금고는 Lv.1을 무료 제공하고 기존 계정에도 기본 금고 효과를 보장한다. 금고의 무료 배치는 기존 시설을 옮기거나 삭제하지 않는 유효 위치 미리보기로 진행하며, 배치 안내가 끝날 때까지 기본 한도가 사라지지 않는다. 추가 초원 건설만 grassland 행의 비용을 쓴다.

wood/stone/metal은 일반 자원 개수, seconds는 건설 기본 초, upkeep은 Lv.1 시간당 유지비다. after_hero=1은 첫 지정 영웅 합성 완료 이후다. 연구 재료·사료·연료는 건설 자재로 쓰지 않는다.

```text
일반 강화 골드 = gold2 × gold_factor(L)를50골드 단위 올림
금고 강화 골드 = 직전 레벨의 금고 한도 × vault_upgrade_ratio를50골드 단위 올림
자재 계수 M(L) = (1 + material_level_growth × (L-2)) × (1 + material_milestone_growth × floor(L/5))
목재/석재/금속 = 해당 자재 기준 계수 × M(L)를 각각 개수 올림(최근 고정 앵커의 해당 자재보다 낮추지 않음)
Lv.2~24 기본 강화 초 = seconds(L) × time_factor를15초 단위 올림(최근 고정 앵커 시간보다 낮추지 않음)
Lv.25 기본 강화 초 = final_days × 86400
실제 강화 초 = 기본 강화 초 × (1-착공 시점 관리사무소 단축률)를15초 단위 올림
Lv.25 실제 강화 초 = max(final_upgrade_min_seconds, 위 실제 강화 초)
유지비/시간 = 기준 앵커 upkeep × (1 + upkeep_growth × (L-앵커 레벨))를1골드 단위 올림
기준 앵커 = 목표 레벨 이하의 마지막 유지비 예외; 없으면 최초 건설 Lv.1
```

최종 강화가7일인 시설은 하한 때문에 마지막 단계의 관리사무소 단축이 적용되지 않는다. 미리보기에서 기본 시간·적용 단축·최종 최소7일을 구분해 표시한다. 광고/유료 즉시 완료·시간 단축 아이템은 이 일반 강화 시간과 별도 미확정 정책이며 과거 예시를 자동 승계하지 않는다.

관리사무소 할인은 착공 시점의 완공 레벨로 결정해 위 기본 시간을 줄이고15초 단위 올림한다. 진행 중 소급 단축·철거로 완료 시각 변경·자기 목표 레벨의 선적용은 없다. 건설/강화는 건설자 인원만큼의 공용 슬롯을 사용하고 각 작업은 수동 시작한다. 건설자1명이 공사1건을 맡으며 여러 명을 한 작업에 붙여 시간을 중첩 단축하지 않는다. 강화 중 기존 레벨의 성능으로 운영하며 완료 뒤 새 성능으로 교체한다.

다음 예외는 현재 구현/기존 초반 계획을 보존하는 고정 앵커다. 숫자를 위 일반식으로 다시 덮어쓰지 않는다.

0.6의 기본 주요시설 상한5와 시설 고도화1/2/3의 상한10/20/25는 [연구트리의 권한 원천](research-trees.md#2-연구소가-다음-단계를-여는-방식)을 따른다. 일반 강화는 최초 건설 해금과 파크Lv.3 이상·이전 고정 앵커의 파크 레벨·직전 레벨 완공·비용을 요구한다. 별도 예외 행은 해당 park를 따른다. 금속이 필요한 강화·금속 공방 건설·추가 관람대는 첫 영웅 이후다. 일반 자원의 수급/저장 조건을 표시하며 첫 합성은 부화장/DNA연구소/안전/초식하이브리드 시설의 Lv.1로 가능하다. 높은 건물 레벨을 새 파크 경험치의 우회 해금으로 사용하지 않는다.

## 5. 건물별 성능

열 L1/L5/L10/L15/L20/L25는 해당 레벨의 **총 성능**이다. 중간 레벨은 인접 앵커 사이를 선형 보간하며 개수는 내림, 비율은 소수 둘째 자리까지 표시한다. 관람대2/3·창고2는 예외 앵커를 우선한다. 실제 계산은 분수 정밀도를 유지하고 표시는 반올림한다. 서식지 부지는 기존3×3을 유지하므로9칸을 넘는 수용량을 적지 않는다.

연료는 일반4종/연구5종 재료함의 열 번째 재료가 아니라 기존 탐험 에너지의 표시·공급 통합이다. 기존 `explorationEnergy`와 회복 시각을 보존하고 별도 연료 잔액을 만들지 않는다. 기본한도/자동회복/출발소비는 공통 값에 따른다. 보급소가 없어도 자연 회복과 기본 물자 구매로 탐험할 수 있고 첫 합성에 보급소 구매를 강제하지 않는다.

생산 시작 시 선택한 전체 수량이 현재 보관 한도를 넘으면 비용 차감 없이 거절하고 창고/탱크 확장을 안내한다. 시작 후 다른 구매나 자연 회복으로 공간이 줄어든 경우 완료 배치를 온전히 보존한다. 모든 일반 생산시설25의 최대3회분은 창고Lv.2 이상이면 빈 창고에 전량 수령할 수 있다.

연료는1개 단위 구매가 가능하며 탱크 여유가 없으면 구매 전 거절한다. 자동 회복과 수령은 같은 최대 연료 원천을 읽는다. 가득 찬 시점 이전의 회복 시간을 무제한 저축하지 않는다. 생산품은 탱크 공간이 부족하면 온전히 미수령 보존하고 연료를 쓴 뒤 수령한다. 보급소 철거/이관으로 한도가 줄어도 기존 연료는 보존하며 한도 아래가 될 때까지 새 회복/수령만 멈춘다. 연료를 다시 시설 운영용 재고·원유·가공유로 분리하지 않는다.

## 7. 입장료와 전체 금고 한도

```text
A = 전시 중 종별 개체 매력도의 기여 합(첫 개체1,둘째0.25,셋째0.10)
Q = 기존 행복/배고픔 상태 계수의 기여 가중 평균
D = (8 + 4×A + 4×max(0,고유종수-1)) × Q × (1+최고 푸드코트 비율+파크 홍보 비율+활성 테마 전시 비율)
G = 완공 입구 분당 한도×(1+입장 수속 기술 비율)
V = 기본 관람 정원 + 관람대 정원 합 + floor(최고 화장실 정원×(1+편의시설 개선 비율))
T = 관람 동선의 평균 관람 초(미연구60)
R = min(D,G,V×60/T)  # 명/분; 입구 처리량 G에는 관람 회전율을 다시 곱하지 않음
잠재 입장료/시간 = R×ticket×60
```

반복 합성으로 얻은 스테고케라톱스는 저장된 매력도를 사용하고, 기존 개체는 종별 인기도를 기본값으로 사용한다. 관람객이 접근할 수 있는 서식지에서 같은 종의 전시 개체를 교체할 때 관람 수요와 정원이 반영된 분당 예상 입장을 보여준다. 실제 입장료는 입장한 관람객 기준으로 쌓인다.

기술0이면 기술 비율은0이다. 효과별 범위/중첩/완료 시각 전후의 정산은 [기술 연구트리](research-trees.md#6-기존-효과의-중첩과-새-효과의-경계)를 따른다. 건물 검산 모델과 파생표의 후기 수익은 추가 효율기술0·필수 시설 해금 권한 확보 가정이며 효율기술 최대를 포함한 전체 플레이 수익 상한은 별도다.

수요가 부족하면 정원을 늘려도 매출이 늘지 않는다. 금고 한도는 돈의 사용처를 대신하지 않으며, 수요·공급·업그레이드/탐험/연구 지출을 함께 조정한다. 후기 수익 예시는 현재 카탈로그 종 인기도를 읽은 상한 계산이며 실제 수집·맵·후반 플레이 완료 결과가 아니다.

금고 규칙은 다음과 같다.

1. 잔액에 입장료 한 명분의 여유가 있을 때만 유료 입장을 확정하고 골드와 유료 인원/누적 매출을 함께 증가시킨다. 부분 수납·한도 초과 청구를 하지 않는다.
2. 금고가 차면 추가 유료 입장만 중단한다. 기존 공룡 전시·관람·생산·탐험·출금/지출은 계속 가능하고 공간이 생기면 유료 입장을 자동 재개한다. 이 상태는 수동 휴장과 구별한다.
3. 받지 않은 대금·대기 손님을 숨은 재고나 방문 소수 잔여에 쌓지 않는다. 소비 직후 밀린 수입을 한꺼번에 받지 않는다. 누적 입장료에는 실제 받은 돈만 기록한다.
4. 오프라인도 같은 전체 잔액 한도와 최대8시간을 적용한다. 접속 전후 수입을 따로 복제하지 않는다. 유지비는 운영 가능한 같은 시간 구간에서 계산하고 수익 시간 상한 이후의 유지비만 추가 청구하지 않는다.
5. 기존 한도 초과 잔액·정상 취소/환불은 전액 보존한다. 초과 상태에서는 소비/환불을 허용하고 새 적립만 중지한다. 유료 골드 구매는 담을 여유가 있을 때만 결제하며 새 골드 보상은 수령 전에 공간을 확인한다.
6. 정산은 서버의 같은 park/currency 잠금 안에서 시간순의 유지비·입장·지출·한도 변경을 처리한다. 폴링 횟수/재접속으로 적립액이나 유료 인원이 달라지지 않아야 한다. 금고 강화를 완료하면 직전 한도 구간을 먼저 정산하고 새 한도를 적용한다.

현재 두 건강한 종의 수요31.2명/분·20골드이면 잠재 총매출은624골드/분이다. 초기 금고25,000에 시작10,000이 남아 있고 지출/유지비가 없다면 여유15,000은 약24분에 채워진다. 실제 시간은 돌봄·정원·유지비·소비에 따라 달라진다. 최초 한도는 첫 보안센터와 자재 전량 구매21,600을 담을 수 있어 첫 합성에 금고 강화가 필수는 아니다.

## 8. 진행 목표와 보존 계약

초반 건설/급식/첫 미션·원종 부화·첫 합성의 기존 수치와 레시피는 유지한다. 시작10,000과 금고 한도 반영으로 0.4의500골드 모델 시간을 그대로 쓰지 않는다. 첫 영웅4~6시간은 초반 성장 속도의 설계 기준안이며 새 금고/연료/25레벨 전체 경로의 검증 완료 시간은 아니다.

5레벨마다 외형을 크게 바꾸고 슬롯·수용량·효율 변화가 보이게 한다. 일반 레벨은 표의 성능 증가를 제공하며 별도 건물 등급/승급 재료를 만들지 않는다. 최소7일은 24회 강화 누적이 아니라 **24→25 단일 강화 한 번**의 시간이다. 중요도별 마지막 기본 강화는7·10·14·21일이며 관리사무소 보정 뒤에도 공통 하한을 지킨다. 21~24 역시 며칠 단위로 이어져 최종 단계에만 시간이 급증하지 않도록 한다. 모든 주요 시설25는 장기 선택 목표다. 이 합계는 골드/자재/접속 대기·동시 작업을 제외한 순수 건설자 점유 시간이다. 첫 영웅·첫 변종에 모두25레벨을 요구하지 않는다.

긴 후반 강화가 다른 공사까지 막지 않도록 기본 건설자와 첫 영웅 완료의 무료 추가 건설자를 제공하고, 추가 인원은 아래 고용 기준으로 확장한다. 연구원도 같은 방식으로 병렬 작업 수를 늘린다. 공사/연구 하나의 시간은 개별 작업과 시설 효과가 결정한다. 탐험·생산·부화·합성과 기존 레벨 시설 운영은 공사 중에도 이어진다.

구현 시 단일 원천은 기존 shared/game-data로 이관한다. 이 문서 표를 UI에 복사하지 않는다. 같은 부지의 성능/외형을 개선하며 기존 건물을 자동 재배치하거나 고레벨을 낮추지 않는다. 신규 후보의 종별 호환 태그·입구/길·수용·격리, 기존 연구 해금의 버전 매핑도 함께 적용한다.

누적 입장료/방문객 카운터는 현재 Prisma32비트 Int다. 장기 누적값은64비트로 보존 이관하고 API는 정밀도가 손실되지 않는 버전화된10진 문자열을 사용하도록 후속 작업에 포함한다. 골드 금고 한도를 도입해도 누적 통계의 정수 범위 문제는 사라지지 않는다. 기존 금액·내역을 반올림하거나 초기화하지 않는다.

## 9. 검산 범위

검산 도구는525행(21건물×25레벨), 앵커/성능/가격·시간 단조성, 금고 다음 강화의 자기 한도, 창고 자기 자재·생산 배치 수령, 연료 탱크/자연 회복·생산 동시 수령, 한도 초과 기존 데이터 보존, 금속의 첫 영웅 이후 규칙, 정산 분할·수요와 정원 상한을 확인한다. 계산 결과와 정확한 범위는 실행 후 TASK와 파생표 하단에 남긴다.

실제 고레벨 게임·DB 동시성·새 연료 API·후반 연구/장소 미션 재미·전체 수집 속도·장기 인플레이션은 아직 검증하지 않았다. 0.4 첫 성장 모델은 보관된 입력을 읽도록 고정하며 현재0.5 실행 증거로 사용하지 않는다.

## 11. 연구 재료 승급 비용

같은 재료 하위 품질을 공통 quality_upgrade_ratio만큼 소비해 다음 품질1개를 즉시100%로 만든다. 하급→중급은 quality_mid_gold, 중급→상급은 quality_high_gold를 결과1개마다 사용한다. 따라서 하급9개와300골드가 상급1개가 된다. 승급에 탐험 연료·공룡·시설 작업 시간을 더하지 않는다. 품질3등급·레시피별 최소 품질은 DNA 기획을 따른다.

## 12. 건설자와 연구원 고용

**역할 확정:** 건설자는 건설/강화, 연구원은 연구트리의 개별 기술 항목을 담당한다. DNA 합성은 별도 기본1개 작업이며 연구원을 배정하지 않는다. 인원별 고용 조건/비용은 설계 기준안이다.

건설자1명은 건설 또는 강화1건, 연구원1명은 기술의 다음1단계 연구를 맡는다. 인원 증가는 **병렬 작업 수**를 늘리며 한 작업의 소요 시간을 인원수로 나누지 않는다. 건물 레벨의 시간 단축과 직원 수를 구별한다. 직원의 별도 등급·장비·가챠·승급 재료·개별 급여 재고는 추가하지 않는다.

게임 시작부터 건설자1명과 연구원1명을 무료 보유한다. 연구소 완공 후 기술 연구를 시작할 수 있으며, 완공 때 연구원을 추가 지급하지 않는다. 첫 지정 영웅 수령 때 건설자2명까지 무료 해금한다. 따라서 금속이 필요한 후기 강화·24→25 장기 작업을 도입할 때에는 다른 작업을 맡길 건설자를 확보할 수 있다. 첫 합성은 기본 인원으로 가능하며 추가 채용·고레벨 관리사무소·다이아를 요구하지 않는다. 추가 건설자는 골드, 추가 연구원은 다이아로 영구 구매한다. 연구원 가격500/1,000/2,000/4,000다이아는 이번 제안값이며 무료 다이아 보상·적립 속도·유료 상품과의 실제 접근성은 후속 검산한다. 첫 연구·첫 합성·개별 기술 해금은 추가 구매를 요구하지 않는다. 기존 다이아500의 공사 슬롯 예시는 이 고용 계획에 자동 적용하지 않는다.

건설자는 서버 완공 시각에 작업이 끝나면 반환한다. 기술 연구도 서버 완료 시각에100% 완료·효과 활성화 후 연구원을 자동 반환한다. 완료 알림 확인을 기다리며 연구원을 점유하지 않는다. 기술은 공룡을 배정/잠그지 않으며 자동 재시작·별도 예약 대기열은 없다. DNA 합성의 결과 수령과 알 부화 자리는 각각 별도 작업 한도를 사용한다. 연구소 강화 중에도 이전 완공 레벨로 연구를 시작하고 진행 중 작업을 유지한다.

고용 인원은 파크의 영구 소유 수치 하나가 원천이다(계획 필드 builderCount/researcherCount). 무료 인원 부여·유료 채용은 대상 순번의 이력과 인원·해당 통화(건설자 골드/연구원 다이아)를 같은 거래에서 처리하고 중복 요청에 재지급/재차감을 하지 않는다. 가용 인원은 이 소유 수에서 실제 점유 작업을 빼 계산하며 독립 가용 인원 잔액을 저장하지 않는다. 공사 진행 중인 시설/작업과 연구 작업이 각각 역할의 슬롯을 예약한다. 기존 합법적 인원/진행 작업은 새 규칙으로 줄이거나 취소하지 않는다. 기존 연구원이0명인 계정은 초기 무료1명까지 보장하되 이미 보유한 인원에 매번1명을 더하지 않는다.

화면은 보유/작업 중/유휴 인원을 구분하고 다음 고용의 조건·비용을 보여준다. 모든 인원이 점유되면 해제될 작업과 완료 시각을 표시하고, 다른 인원이 비어 있으면 그 인원으로 바로 다른 작업을 시작할 수 있다. 기술의 선행·중복 방지·완료 규칙은 [기술 연구트리](research-trees.md), 합성의 실패 보호/수동 수령은 DNA 기획을 따른다.

## 13. 기술 연구 비용과 시간

**수치 적용 범위:** 0.6 [연구트리](research-trees.md)는72개 기술/총252회 연구다. 아래 A/B/C/U18행은0.5에서승계한12기술총48회 연구의 비용 원천이다. 신규60기술총204회 연구의 비용군N은14~15절을따른다. 자원/시간은모두설정했고효과수치는별도소유한다. 전체72기술의 실제수급/도달일수는후속검증이다.

연구 항목·최대 레벨·비용군·선행·단계별 효과는 [기술 연구트리](research-trees.md)가 소유한다. 아래 표는 비용군/목표 기술 레벨에 대한 **해당 단계 한 번의 비용**이며 누적 비용이 아니다. 최대3레벨 기술은 비용군의1~3행만 사용한다. 첫영웅후 여부·선행 기술·직전 단계·아래 연구소 최소 레벨을 모두 확인한다.

골드/목재/석재/금속만 사용하며 새 과학 재화·합성 재료·연료는 소비하지 않는다. 연구소와이미완료한실험절차의시간단축을기술연구시간에적용하고 마지막 초 단위로 올림한다. 배양 공정은 DNA 합성에만 적용한다. 시작한 작업의 완료 시각은 고정한다. 후반 연구의 지정 장기 단계에는 아래 min_seconds 하한을 시간 보정 후 적용한다. 연구소25의 시간 단축을 받아도 해당 연구 한 번이 최소7일 걸린다. 건물과 기술은 각각의 하한을 갖고 연구원 추가 구매는 시간 단축을 제공하지 않는다.

## 15. 최종 연구시간·할인·도달 가능성

최종시간은 `max(지정하한, ceil(기본시간×(1-완공연구소단축률)×(1-이미완료한실험절차단축률)))`이다. 초단위로올림한다. 같은역할의연속레벨은비용/시간이감소하지않게하되해금→효율로역할이변하면작은효율강화의비용/시간을내릴수있고역할변경을표시한다. 이미시작한연구의완료시각은고정한다. 연구원추가구매는병렬수만늘리며한작업시간을나누지않는다.

- 유효연구소15~19의한번연구는최소7일,20~24는최소14일이다.
- 유효연구소25는역할별최소시간: 선택효율/운용14일,콘텐츠해금21일,최상위핵심28일이다.
- 신규기술의최대레벨연구는첫영웅이후기술인경우최소7일이며,위의더긴하한이있으면그하한을쓴다. 기초입장수속/환경적응/연료저장등기존초반12의빠른곡선은승계한다.
- 기존12도각비용행의min_seconds와유효연구소별하한중큰값을쓴다. 예를들어시료보존5는기본14일을유지하지만유효연구소20의14일하한으로단축후에도14일이다.

기술연구예산관리/기술실험절차개선의완료레벨별효과는 [연구트리](research-trees.md#5-기본-연구-효과-수치)의수치표가소유한다. 예산관리는연구골드만감소시키며자재/건물/합성비/직원다이아구매비는줄이지않는다. 실험절차는기술연구시간만줄이고일반DNA합성시간은배양공정이담당한다. 이두연구의다음레벨을시작할때는자기목표레벨이아닌현재완료레벨효과만쓴다. 첫입장수속1은신규정상경로에서할인없음/1분500골드·목재5석재5앵커다.

모든행은기본비용·시간과최종하한을표시한다. 미리보기에표시할실제골드/시간은그계정의이미완료한효과로계산한다. 미래에얻을최고할인을초반부터소급적용하거나필수해금의지불능력으로미리사용하지않는다. 목표연구의선행및이미완료한할인기술/연구소의선행폐쇄에현재미완료목표가포함되는스냅샷도거부한다. 예를들어실험절차1이예산관리2를필요로하므로미완료예산관리1/2에그단축을쓸수없다. 신규진행기준의검산과이전계정이관권한보존은구별한다. 골드는최종골드를1단위올림하고일반자재는할인하지않는다.

시설고도화1/2/3 직전의주요시설상한은5/10/20이다. 이번연구가완료된후의새금고·창고나새할인을미리계산하지않고각직전상한내에서연구골드와각자재를준비할수있어야한다. 연구골드+자재전량골드구매환산까지직전금고에들어가는조건은편의가드이며실제시작API의추가제한으로쓰지않는다. 자재를먼저준비한뒤골드를다시모을수있다.

72기술252회 연구의 자원·시간은 이 문서가, 레벨별 효과는 연구트리와 [효과 상세](research-effects.md)가 소유한다. 신규58개의194레벨 효과·부지 면적·해금 대상과 중첩을 정의했다. 별도 토지 확장비·특수5시설 건설/안전·미션 준비비/조작·후속9레시피 부모/비용을16~17절과 DNA/탐험 정본에 연결했다. 실제 실행 콘텐츠와 전체 기간 검증은 별도다. 준비되지않은콘텐츠를연구권한만으로실행가능하게표시하지않는다. 총골드·자재합/연구원점유시간합은전체모든항목을최대연구했을때의투자량이며실제플레이완료일수나트리깊이가아니다.

### 16.3. 전시 안전과 보유의 분리

위험 점수는 기존 자연 육식1점·위험 하이브리드3점을 사용한다. 새 익룡/해양 전시는 자연종·변종1점, 위험 하이브리드3점으로 같은 보안센터 예산에 포함한다. 초식/관리형 초식 하이브리드는0점이다. 거대 크기만으로 점수를 추가하지 않는다. 최고 완공 보안센터의 허용 점수 이내인 경우에만 새 전시 배치를 허용하며 기존 합법 배치는 보존한다.

시설 한 동에는 호환되는 같은 안전/생태 그룹만 입주시킨다. 그룹은 현재 입주종에서 계산하고 독립적인 시설 모드/등급/직원 입력을 추가하지 않는다. 육식·초식·위험 하이브리드를 같은 동에 섞지 않으며, 돔·해양관도 자연/변종 그룹과 위험 하이브리드는 별도 동을 사용한다. 종별 경로와 최소 완공레벨은 [건물 호환표](buildings.md#83-호환-판정격리거대종)를 따른다. 거대종 전용 새 건물을 만들지 않는다.

원종 알 회수·부화·합성의 성공 결과는 배치 대기 상태로 보유할 수 있다. 해당종 사육·거대종·안전 권한은 전시할 때 확인한다. 단, 공개 레시피가 원래부터 명시한 격리·안전 선행(스피노랩터 등)은 합성 시작에도 보존한다. 보유/도감 등록을 허가받지 않은 환경에 전시 가능한 상태로 표시하지 않는다.

### 17.4. 수령·실패·시스템 오류

계정당 미정산 탐험은1건이다. 출발 때 골드/연료·필요권한·현재작업을 함께 검사해 전량 차감하고 미션/문제 배치/보상/효과 버전을 저장한다. 앱을 닫으면 현재 판단부터 무료 재개한다. 오답은 현재 구간에서 힌트를 받고 다시 판단하며 추가 연료·골드, 재료 파괴·품질 강등·전체 초기화는 없다. 같은 구간 오답2회에는 비용 없는 근거 강조를 제공한다. 세부 플레이는 [탐험 플레이](exploration-play.md)를 따른다.

모든 판단을 통과하면 결과를 고정하고 수동 수령 때 탐험회차ID/보상줄ID별로 한 번 지급한다. 같은 미션 템플릿의 새 유료 회차는 서로 다른 회차ID를 갖는다. 기본 보상과 추가 하급DNA를 같은 정산으로 처리한다. 수령 공간/버전 문제가 있으면 완료 결과를 미수령 상태로 보존하며 보상을 버리지 않는다. 일반 창고의100/5850 한도를 연구 재료에 임의 적용하지 않는다. 명시적 포기는 준비비/연료를 반환하지 않지만 오답·일시중지는 포기가 아니다. 영구적인 서버/콘텐츠 오류로 미션을 폐기해야 할 때는 지급 이력을 검사한 뒤 실제 지불한 준비비/연료를 한 번 전액 반환한다. 이미 진행 중인 탐험은 시작 때 고정한 규칙으로 마무리한다.
