# 장기 파크 운영과 수급 검산

## 검산 기준

첫 주는 새 파크에서 개장·원종 부화·첫 스테고케라톱스 합성에서 이어지는 투자 순서로 계산한다. 파크 Lv.15·25·35·50은 각 레벨에 이미 도달한 대표 파크를 따로 놓고 하루의 운영과 다음 작업을 비교한다. 시작 골드와 금고, 시설 비용, 생산량, 탐험 보상, 경험치와 스토리 조건은 기존 담당 기획을 참조한다.

두 계산 모두 추가 인력 구매 없이 기술 연구원 1명으로 시작한다. 첫 영웅 수령 뒤에는 무료 건설자 2명을 사용할 수 있다. 기술 연구와 DNA 합성은 서로 다른 작업 공간을 쓴다. 건설과 연구의 최소 시간은 기존 강화표를 적용한다. 24→25는 일반 단축을 적용해도 최소 7일이다.

입장료는 실제 수납분을 보고, 운영 순수입은 입장료에서 유지비를 뺀 값으로 표시한다. 자재와 연료의 구매·생산비는 작업 시작 때 지출한다. 운영 유지비와 작업비를 각각 집계한다. 검산에서 정한 접속 일정, 전시 구성과 수행 순서는 사례의 입력이다. 사용자의 진행 기간을 확정하려면 실제 배치·동선, 돌봄 빈도, 자원 선택과 미션 플레이를 추가로 확인해야 한다.

## 첫 7일 운영표

첫날 개장 준비부터 시작해 0~60분, 240~330분, 720~740분에 접속한다. 2~7일은 0~20분과 720~740분에 접속한다.

비접속 1회당 처음 8시간만 수입과 유지비를 같은 오프라인 계수로 정산한다. 돌봄 상태와 착수 작업의 시간은 비접속 때도 흐른다.

입장과 유지비를 15초 단위로 상태를 갱신하고, 구간 안에서는 사건 발생 순서대로 정산한다. 유료 입장 하나마다 금고 여유를 확인한다.

기본 자재·사료 재고는 0이다. 시작 전시·호환 서식지·안전시설·방문객 길은 적법하게 배치됐다고 가정한다. 초원에는 파라와 이구아노돈을 전시하고 두 부모는 보유만 한다. 첫 영웅은 하이브리드 서식지에 전시한다.

원종과 합성 결과의 수령 시 건강 상태는 행복100·배고픔0 가정이다. 현행 급식 회복과 상태 악화 수치를 사용한다. 접속 중 허기50 이상 또는 출발과 합성에 조건이 필요한 때 급식한다.

초반 탐험과 반복 미션은 실제 단서를 모두 해결한다는 가정으로 조작 산술 시간을 적용한다. 프롤로그·개장 6분, 안전 대화·동선 점검 6분, 촉매 전후 대화 각각 1분과 3분을 예시 시간으로 둔다.

공사·부화·기술·합성·생산은 각자 타이머를 쓴다. 생산·탐험·부화·합성의 보상은 접속 시 수동 수령한다. 건설과 기술 결과는 오프라인에서도 완료된다.

금속과 부족한 자재는 구매한다. Lv.1 생산시설 1~3회분은 수동 착수·수령하고 한 번에 들어갈 공간을 확인한다. 연료는 자연 회복만 사용한다.

역할별 기본 1명과 첫 영웅으로 해금하는 무료 건설자 2번째를 쓴다. 유료 가속·다이아·위인·시즌 보상은 사용하지 않는다.

정산의 유지비 부족분은 추적하고 현행처럼 잔액을 넘겨 걷지 않는다. 미납에 따른 새 벌칙이나 무료 구제는 이 계산에 넣지 않는다.

첫 영웅 이후 표에 명시한 Park5→11 목표만 선택한다. Park11 이후는 정해진 금고·생산 투자를 마치고 돌봄 위주로 운영하는 사례다. 상황에 따른 클리어 보장, 필수 접속 시간, 실제 지도 배치나 경제 운영의 검증 결과로 쓰지 않는다.

이 일정에서 첫 영웅을 수령한 시점은 시작 후 5시간 4분 45초이다.

같은 초반 목표를 첫날 연속 접속으로 진행하면 2시간 27분 45초에 수령했다. 첫 영웅의 4~6시간 목표를 맞추려면 접속 간격의 영향과 플레이에 필요한 시간을 따로 확인해야 한다.

## 성장 시점별 하루 운영표

이미 첫 영웅을 수령한 4개 독립 파크의 하루를 계산했다. 해당 파크까지 성장한 기간을 합산하지 않았다.

12시간 간격으로 30분 접속한다. 각 11시간30분 비접속 구간의 첫8시간에 해당 정보센터·연구의 적립 계수를 적용한다.

전시 목록은 호환 서식지에서 정상 관람할 수 있다고 가정한다. 돌봄이 유지된 상태에서 시작해 12시간마다 영양 급식 2의 사료 1개로 행복 최대24와 허기 최대100을 회복한다. 매 회차 행복100·허기0 회복 가능 여부를 확인했으며 비전시 보유종은 골드 유지비를 계산한다.

분 단위로 정산하며 같은 분의 유지비를 먼저 차감한다. 금고가 작거나 잔액이 많으면 입장을 거절하고 미수입 및 미납 유지비를 쌓지 않는다.

기준 수입일은 골드 잔액 0에서 시작하고 지출 없이 유지비만 정산한다. 급식 사료는 미리 확보했다고 가정한다. 당일 사료 보충비를 다음 투자 여력에서 별도로 뺀다.

건설자2명과 연구원1명을 사용한다. 유료 고용·광고·가속·위인·테마 전시·별도 보너스 수입은 계산에서 제외한다.

## 잔액이 부족할 때 복구

**구현 검토안.** 먼저 미수령 사료와 재고를 찾고, 유효한 전시·관람길로 입장 수익을 낼 수 있는지 보여준다. 유지비 부족분은 부채로 넘기지 않는다. 정상 운영으로 다음 급식비가 모이는 상태라면 개장을 유지해 실제 입장료로 복구한다. 금고 만원과 사용자가 선택한 휴장은 각자의 기존 동작을 적용한다.

골드로 사료 한 단위를 살 수 없고 사료 재고와 수령 가능 배치가 비어 있으며, 현재 전시로 정상 개장했을 때 예상 순수입이 0 이하인 경우에 복구 운영을 제공한다. 기본 입구와 안전하게 공개할 수 있는 기존 전시 한 곳을 사용한다. 다른 시설과 전시는 관람을 쉬고 복구 기간의 경제 정산 대상에서 제외한다. 보유·배치와 안전 관리는 유지한다. 수동 휴장 상태라면 사용자가 복구 개장을 선택한 뒤 입장이 재개된다.

복구 운영은 사료 한 단위를 살 수 있는 잔액에 도달한 입장까지만 받는다. 그때 유료 입장과 유지비 정산을 멈추고 급식을 안내한다. 이미 결제한 공사·연구·부화·합성·생산은 완료하거나 수령할 수 있다. 새 유료 작업은 복구를 마칠 때까지 보류하고 사료 구매·급식은 허용한다. 최초 돌봄 기록이 없고 무료 급식 수단도 없다면 세이브당 한 번 기본 파라에게 바로 먹이는 지원을 적용한다. 지원은 재고나 골드를 지급하지 않으며 본편 보상은 기존 목표의 단일 수령 이력을 따른다.

일반 운영으로 돌아가기 전에는 급식, 관람길, 안전 전시와 예상 순수입을 다시 확인한다. 무료 기본 전시에 배치할 수 있는 마지막 개체의 방생은 미리 막고 복구에 필요한 이유를 안내하는 방향을 검토한다. 이미 해당 개체가 없는 복귀 계정은 보유 개체를 임의로 바꾸지 않고, 기본 전시를 재개하는 별도 이관 규칙을 정해 검증한다.

검증할 상태는 잔액 0에서 정상 수익으로 복구, 수동 휴장에서 복구 개장, 기본 파라 최초 급식, 안전하게 공개할 전시가 없는 복귀 계정, 미수령 배치 수령, 재접속·동시 요청이다. 지원 중 상태 전환과 급식은 서버 정산과 같은 거래에서 처리한다. 복구 상태를 오가며 입장료·지원·수령 보상이 중복 지급되는지 확인한다.

## 후속 플레이 검증

첫 영웅의 경과 목표 4~6시간과 각 장의 플레이 조건은 [스토리 진행](story-progression.md), 무료 연구원의 단계별 성장 목표는 [파크 성장](park-progression.md)을 따른다. 동일한 출발점에서 접속 빈도와 돌봄 수준을 바꿔 비교한 뒤 비용·공급을 조정한다. 무료 다이아의 지급처와 추가 연구원 시점, 실제 탐험의 문제 구성과 반복 피로는 별도 후속이다.
