## 1. 인증 시스템

### 1.1 토스 로그인
- [ ] 신규 유저 로그인 시 계정 생성 확인
- [ ] 기존 유저 재로그인 시 데이터 유지 확인
- [ ] 로그인 후 JWT 토큰 저장 확인
- [ ] 토큰 만료 시 자동 갱신 확인
- [ ] 로그아웃 시 토큰 삭제 및 상태 초기화

### 1.2 세션 관리
- [ ] 앱 재시작 시 로그인 상태 유지
- [ ] 장시간 미접속 후 재접속 처리
- [ ] 복수 기기 동시 접속 처리

## 2. 파크 시스템

### 2.1 파크 조회
- [ ] 파크 기본 정보 표시 (이름, 레벨, 경험치)
- [ ] 그리드 크기에 맞는 맵 렌더링
- [ ] 공룡/건물 위치 정확히 표시

### 2.2 파크 업그레이드

- [ ] 레벨업 시 그리드 확장
- [ ] 레벨업 보상 정상 지급

## 3. 공룡 시스템

### 3.1 공룡 조회
- [ ] 보유 공룡 목록 정상 표시
- [ ] 공룡 상세 정보 정확히 표시
- [ ] 행복도/배고픔 상태 시간에 따라 변화

### 3.2 공룡 생성/부화
- [ ] 탐험 후 공룡 알 획득
- [ ] 부화 대기열에 알 추가
- [ ] 부화 시간 정확히 계산
- [ ] 부화 완료 시 공룡 생성

### 3.3 공룡 관리
- [ ] 먹이주기 시 골드 차감
- [ ] 먹이주기 후 행복도 증가/배고픔 감소
- [ ] 닉네임 변경 (1~12자 제한)
- [ ] 공룡 위치 이동 (그리드 범위 내)
- [ ] 공룡 파크에서 제거/창고로 이동
- [ ] 공룡 방생 시 DNA 획득

### 3.4 상호작용
- [ ] 쓰다듬기 쿨타임 정상 작동
- [ ] 쓰다듬기 시 친밀도/경험치 증가
- [ ] 레벨업 조건 충족 시 자동 레벨업

### 3.5 수익 계산
- [ ] 시간당 수익 정확히 계산
- [ ] 행복도에 따른 수익 배율 적용
- [ ] 레벨에 따른 수익 배율 적용
- [ ] 희귀도에 따른 수익 배율 적용

## 16. 테스트 우선순위

### P0 (Critical) - 반드시 테스트
1. 로그인/로그아웃
2. 재화 획득/차감
3. 결제 처리
4. 데이터 저장/로드

### P1 (High) - 주요 테스트
1. 공룡 부화/관리
2. 건물 건설/업그레이드
3. 탐험 시스템
4. 스토리 진행

### P2 (Medium) - 일반 테스트
1. UI 표시
2. 애니메이션
3. 사운드
4. 시즌 시스템

### P3 (Low) - 선택 테스트
1. 엣지 케이스
2. 다양한 기기 호환성
3. 성능 최적화
