# 1. 수익 모델 개요

## 1.1 비즈니스 모델

**하이브리드 F2P (Free-to-Play)**

```
┌─────────────────────────────────────────────────────────┐
│                    수익 구조                              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   🎬 광고 수익 (30%)          💎 인앱 결제 (70%)         │
│   ├── 리워드 광고              ├── 월정액 패스           │
│   ├── 인터스티셜 (선택적)       ├── 시즌 패스            │
│   └── 배너 (최소화)            ├── 다이아 팩            │
│                                ├── 프리미엄 콘텐츠       │
│                                └── 스타터/확장팩         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 1.2 핵심 원칙

| 원칙                 | 설명                                 |
| -------------------- | ------------------------------------ |
| **No Pay-to-Win**    | 과금 = 시간 단축, 편의성만 제공      |
| **100% 클리어 가능** | 무과금으로 모든 콘텐츠 도달 가능     |
| **광고 비강제**      | 리워드 광고만, 강제 시청 없음        |
| **합리적 가격**      | 한국 모바일 게임 평균 대비 저가 정책 |

## 1.3 플랫폼 특성 (토스 앱스)

| 요소            | 특성                   | 수익 영향       |
| --------------- | ---------------------- | --------------- |
| **유저 베이스** | 토스 2,200만+ 사용자   | 높은 DAU 잠재력 |
| **결제 편의성** | 토스페이 원클릭        | 전환율 ↑        |
| **타겟 연령대** | 20~40대 경제활동 인구  | ARPU ↑          |
| **캐주얼 성향** | 짧은 세션, 라이트 유저 | LTV 중간        |

# 2. 핵심 지표 정의

## 2.1 KPI 정의

| 지표                | 정의                            | 목표                  |
| ------------------- | ------------------------------- | --------------------- |
| **MAU**             | Monthly Active Users            | 성장 목표             |
| **DAU**             | Daily Active Users              | MAU × 30~35%          |
| **ARPU**            | Average Revenue Per User        | 전체 유저 평균 매출   |
| **ARPPU**           | Average Revenue Per Paying User | 과금 유저 평균 매출   |
| **Conversion Rate** | 유료 전환율                     | 과금 유저 / 전체 유저 |
| **LTV**             | Life Time Value                 | 유저당 생애 가치      |
| **D1/D7/D30**       | Retention Rate                  | 1/7/30일 잔존율       |

## 2.2 벤치마크 (유사 게임 기준)

| 지표            | 업계 평균  | 우수     | 다이노 파크 목표 |
| --------------- | ---------- | -------- | ---------------- |
| D1 Retention    | 35%        | 45%+     | **40%**          |
| D7 Retention    | 15%        | 20%+     | **18%**          |
| D30 Retention   | 5%         | 10%+     | **8%**           |
| Conversion Rate | 2~3%       | 5%+      | **4%**           |
| ARPU            | ₩500~1,000 | ₩1,500+  | **₩1,200**       |
| ARPPU           | ₩15,000    | ₩25,000+ | **₩30,000**      |

## 2.3 Retention 목표 설정 근거

> 다이노 파크 타이쿤의 Retention 목표는 유사 장르 벤치마크와 플랫폼 특성을 고려하여 설정

### D1 Retention: 40% 목표

| 근거 요소            | 영향     | 상세                               |
| -------------------- | -------- | ---------------------------------- |
| **토스 앱 내장**     | +5~8%    | 별도 설치 불필요, 진입 장벽 최소화 |
| **튜토리얼 최적화**  | +3~5%    | 5분 내 첫 공룡 부화 성공 경험      |
| **푸시 알림 허용률** | +2~3%    | 토스 앱 기존 허용 상태 활용        |
| **벤치마크**         | 기준 35% | 타이쿤/방치형 장르 평균            |

```
D1 목표 산출:
업계 평균 35% + 토스 플랫폼 이점 5% = 40%

비교 레퍼런스:
- 쿠키런: 킹덤 (D1: 42%)
- 마이리틀팜 (D1: 38%)
- 에버머지 (D1: 36%)
```

### D7 Retention: 18% 목표

| 근거 요소             | 영향     | 상세                    |
| --------------------- | -------- | ----------------------- |
| **7일 출석 보상**     | +2~3%    | 7일차 희귀 공룡 알 지급 |
| **챕터 1 완료 보상**  | +1~2%    | 스토리 진행 동기 부여   |
| **첫 번째 위인 영입** | +1~2%    | 시스템 확장 체험        |
| **벤치마크**          | 기준 15% | 타이쿤/방치형 장르 평균 |

```
D7 목표 산출:
업계 평균 15% + 콘텐츠 후킹 3% = 18%

D1→D7 전환율: 45% (업계 평균 42%)
7일간 누적 플레이 시간 목표: 90분+
```

### D30 Retention: 8% 목표

| 근거 요소            | 영향    | 상세                    |
| -------------------- | ------- | ----------------------- |
| **시즌 패스 도입**   | +1~2%   | 장기 목표 제공          |
| **소셜 기능**        | +0.5~1% | 친구 방문, 랭킹 경쟁    |
| **주간 이벤트 순환** | +1%     | 지속적 신선함 유지      |
| **벤치마크**         | 기준 5% | 타이쿤/방치형 장르 평균 |

```
D30 목표 산출:
업계 평균 5% + 장기 콘텐츠 후킹 3% = 8%

D7→D30 전환율: 44% (업계 평균 33%)
30일간 누적 플레이 시간 목표: 8시간+
누적 결제 유저 비율 목표: 15%+
```

# 4. MAU별 매출 시뮬레이션

## 4.1 ARPU 계산

> **용어 정의 (혼동 방지)**
>
> - **가중 ARPU (Weighted ARPU)**: 세그먼트별 월 수익을 비율로 가중 평균한 이론적 수치
> - **실제 ARPU (Operational ARPU)**: 실제 운영에서 사용하는 MAU 기준 월 매출 / MAU
> - **ARPPU**: 과금 유저만의 평균 (Paying User 기준)

### 가중 ARPU 계산 (이론값)

```
가중 ARPU = Σ(세그먼트 비율 × 세그먼트 월 수익)

         = (0.70 × ₩600) + (0.20 × ₩12,100) + (0.08 × ₩43,200) + (0.02 × ₩167,200)
         = ₩420 + ₩2,420 + ₩3,456 + ₩3,344
         = ₩9,640 / 활성 유저

※ 이 값은 "월간 활성 유저가 평균적으로 창출하는 수익"의 이론값
```

### 실제 ARPU 계산 (운영값) - ★ 주요 지표

```
┌─────────────────────────────────────────────────────────────────┐
│                    실제 ARPU 산출 근거                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  MAU 중 활성 비율 조정:                                        │
│  - MAU의 약 30~35%만 월간 수익에 실제 기여 (DAU 기준)          │
│  - 나머지 65~70%는 비활성/저활성 유저                          │
│                                                                 │
│  실제 ARPU = 가중 ARPU × 활성화율 보정                         │
│           = ₩9,640 × 0.125 (보수적)                            │
│           = ₩1,205 ≒ ₩1,200                                   │
│                                                                 │
│  📌 공식 사용 ARPU: ₩1,200/월/MAU                              │
│                                                                 │
│  ※ 이 값이 매출 시뮬레이션, 손익분기점 등에 사용됨             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

활성화율 0.125 근거:
- 토스 앱 평균 주간 세션: 3.2회
- 게임 접속 중 수익 행동 비율: ~40%
- 종합 활성 기여율: 0.32 × 0.40 ≒ 0.125
```

### ARPU 용어 정리표

| 용어          | 값      | 사용처                  | 비고          |
| ------------- | ------- | ----------------------- | ------------- |
| **가중 ARPU** | ₩9,640  | 세그먼트 분석, LTV 계산 | 이론적 최대치 |
| **실제 ARPU** | ₩1,200  | 매출 예측, 손익분기점   | ★ 공식 지표   |
| **ARPPU**     | ₩30,000 | 과금 유저 분석          | 과금자만 대상 |

# 7. LTV 분석

## 7.1 세그먼트별 LTV 계산

### LTV 공식

```
LTV = ARPU × (1 / Churn Rate)
    = ARPU × 평균 생존 개월 수
```

### 세그먼트별 LTV

| 세그먼트  | 월 ARPU  | 평균 생존 | LTV        |
| --------- | -------- | --------- | ---------- |
| 🐟 무과금 | ₩600     | 2개월     | ₩1,200     |
| 🐬 소과금 | ₩12,100  | 4개월     | ₩48,400    |
| 🐋 과금   | ₩43,200  | 6개월     | ₩259,200   |
| 🦈 고래   | ₩167,200 | 12개월    | ₩2,006,400 |

### 가중 평균 LTV

```
가중 평균 LTV = Σ(세그먼트 비율 × 세그먼트 LTV)

= (0.70 × ₩1,200) + (0.20 × ₩48,400) + (0.08 × ₩259,200) + (0.02 × ₩2,006,400)
= ₩840 + ₩9,680 + ₩20,736 + ₩40,128
= ₩71,384 / 유저

📊 평균 LTV: 약 ₩71,400
```

## 7.2 LTV:CAC 비율

### CAC (Customer Acquisition Cost) 가정

| 채널              | CAC         | 비중 |
| ----------------- | ----------- | ---- |
| 토스 앱 내 피처링 | ₩0 (오가닉) | 40%  |
| 소셜 미디어 광고  | ₩3,000      | 30%  |
| 인플루언서        | ₩5,000      | 15%  |
| 검색 광고         | ₩4,000      | 15%  |

```
가중 평균 CAC = (0.4 × 0) + (0.3 × 3,000) + (0.15 × 5,000) + (0.15 × 4,000)
             = ₩0 + ₩900 + ₩750 + ₩600
             = ₩2,250
```

### LTV:CAC 비율

```
LTV:CAC = ₩71,400 / ₩2,250 = 31.7 : 1

✅ 건전한 비율 (일반적으로 3:1 이상이면 양호)
```

## 7.3 Payback Period

```
Payback Period = CAC / 월 ARPU
               = ₩2,250 / ₩1,200
               = 1.88개월

✅ 약 2개월 내 CAC 회수
```
