# 2. 시즌 1: 창립자의 귀환

## 2.1 시즌 개요

| 항목          | 내용                                   |
| ------------- | -------------------------------------- |
| **제목**      | 창립자의 귀환 (Return of the Founder)  |
| **기간**      | 90일 (1월 ~ 3월)                       |
| **테마**      | 아서 해먼드의 과거, 파크의 진정한 기원 |
| **분위기**    | 미스터리, 향수, 희망                   |
| **해금 조건** | 메인 스토리 챕터 4 완료                |

## 2.2 스토리 시놉시스

### 배경

메인 스토리에서 홀로그램으로만 등장했던 **아서 해먼드**. 그가 남긴 비밀 일지가 발견된다. 일지에는 파크의 진정한 설립 목적과, 아서가 아직 **살아있을지도 모른다**는 단서가 담겨 있다.

### 핵심 미스터리

1. 아서 해먼드는 정말 죽었는가?
2. 파크 설립의 진짜 목적은 무엇인가?
3. "프로젝트 에덴"이란 무엇인가?
4. 아서가 숨겨둔 "마지막 선물"은?
