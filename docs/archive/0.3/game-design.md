# 다이노 파크 타이쿤 — 게임 기획 0.3

> 0.3 보관본 · 2026-11-16 보관. 당시 기획·구현 상태를 기록한 원자료이며, 현재 기준은 [최신 문서 안내](../../README.md)와 [0.4 자원 기획](../../current/resources-and-production.md)이다.

기준일: 2026-11-16 · 상태: 재정비 기준안, 미구현 항목 포함 · [문서 안내](../../README.md)

## 1. 어떤 게임인가

**버려진 공룡 파크를 재건하고, 방문객의 입장료로 시설과 연구에 투자하는 수집·경영 게임.** 탐험으로 자연종을 만나고, 수집한 DNA를 합성해 변종과 하이브리드를 만든다. 새로운 공룡을 안전하게 전시하면 방문 수요가 늘고 다음 구역·연구에 투자할 수 있다.

앱인토스의 짧은 세션을 목표로 한다. 처음에는 파크를 열고 손님을 받는 경험을 완성하고, 이후 세션마다 시설·알·연구 중 하나의 진행 결과를 확인한다. 운영 경제의 원천은 [밸런스](balance.md), 공룡 획득과 레시피의 재료·제작비·시간은 [DNA 기획](dna-and-collection.md)이 관리한다.

### 사용자 확정 요구

- 도입은 창립자의 편지를 받고 15년간 버려진 파크를 재건하는 설정이다.
- 파크 외곽 경계와 입구가 보여야 한다. 서식지 울타리와 공원 테두리를 구분한다.
- 매출은 방문객 입장료다. 공룡을 골드 생산기로 취급하지 않는다.
- 배치·돌봄 → 입장료 → 시설 투자 → 두 번째 공룡을 짧은 튜토리얼로 잇는다.
- 탐험뿐 아니라 DNA 합성으로 변종·하이브리드를 얻는다. 레시피의 원종을 실제 보유해야 하며 결과 등급이 높을수록 실패율이 높아진다.
- 변종·하이브리드는 영웅 또는 전설 등급만 사용한다. 파라 한 마리로 시작하고 첫 지정 합성은 100% 성공해 모두 영웅 스테고케라톱스 한 마리를 획득한다.
- 합성 재료는 탐험으로 모은다. 연구소의 정기 채취나 자동 재료 생산은 추가하지 않는다.
- 이미 있는 에셋을 사용하고, 필요한 부분만 보충한다.

그 외 공식·가격·연구 시간은 이번에 정리한 설계값이며 플레이 검증 후 조정한다. 현재 게임에 모두 적용됐다는 뜻은 아니다.

## 2. 핵심 루프

```text
공룡 배치·돌봄 → 안전한 관람 환경 → 방문객 유료 입장 → 골드
       ↑                                             ↓
새 공룡 전시 ← 탐험·알 부화 / DNA 수집·합성 ← 시설·탐험·연구 투자
```

탐험은 새로운 원종과 합성 재료를 찾는 경로다. 합성은 보유 원종과 탐험 재료를 사용해 원하는 결과를 연구하는 경로이며 등급별 실패와 재도전이 있다. 원종은 성공·실패 모두 소모하지 않는다.

## 3. 먼저 완성할 플레이 범위

한 파크, 시작 초원 구역, 파라사우롤로푸스와 이구아노돈, 입구·길·관람대, 첫 탐험·부화, 목표 카드까지 먼저 완성한다. 이어서 재료 종류·품질별 인벤토리·연구소와 첫 하이브리드를 연결한다.

82종·50명 위인·다섯 섬·시즌·결제·소셜은 과거 문서의 장기 목표다. 콘텐츠 데이터가 있다는 이유로 이번 구현량에 포함하지 않는다. 육식·격리·해양·야간 관람은 필요한 서식지와 동선이 준비된 뒤 확장한다.

## 4. 공간과 파크 운영

| 요소 | 동작 기준 |
| --- | --- |
| 외곽 경계 | 저장된 `Park.gridSizeX/gridSizeY`의 바깥선을 사용. 별도 토지 크기 입력이나 구매는 없음 |
| 입구 | 경계와 이어진 출입구. 개장/폐장, 누적 유료 입장객, 입장료 매출 표시 |
| 기본 길 | 입구에서 초원 관람 지점으로 연결. 손님은 길과 관람 지점에서만 이동 |
| 서식지 | 공룡의 생활 공간. 방문객 길과 분리. 호환 종·수용량을 검증 |
| 관람대 | 길에 연결된 관람 지점과 동시 관람 정원 추가. 건물 자체의 자동 골드 생산은 없음 |
| 연구소 | 탐험 재료·보유 원종·성공률을 확인해 합성. 완성한 공룡은 전시해야 방문 수요에 기여 |

개장에는 입구와 길, 관람 가능한 공룡, 돌봄 완료가 필요하다. 폐장·동선 단절·전시 공룡 없음이면 새 유료 입장은 없다. 손님이 입장할 때 한 번 결제하고, 관람·퇴장 때 다시 매출을 만들지 않는다.

신규 파크는 입구와 기본 길이 경계에 맞는 배치를 제공한다. 기존 계정의 배치·골드는 보존하고, 경계 도입으로 출입구 이동이 필요한 경우 무료 이동을 제공한다. 과거 저장 좌표를 일괄 덮어쓰지 않는다.

서버가 입장 인원·골드·정산 시각을 확정한다. 화면의 손님 수는 혼잡을 보여주는 연출이며 서버의 실제 정산 인원과 구별한다. 온라인·오프라인을 같은 규칙으로 정산하고, 예전 공룡 직접 수익을 함께 지급하지 않는다.

## 5. 첫 10분

| 순서 | 플레이와 목적 | 완료 조건 |
| --- | --- | --- |
| 파크 보기 | 닥터 진의 짧은 안내, 외곽 경계·입구·첫 서식지 확인 | 안내를 접어도 조작 가능 |
| 첫 친구 | 지급된 파라 배치·급식 | 서버의 배치·급식 기록 인정 |
| 재개장 | 길을 확인하고 개장, 손님과 첫 입장료 확인 | 검증된 유료 입장 실적 |
| 첫 투자 | 번 입장료로 관람대 선택·배치·건설 | 취소 시 무차감, 완공 후 관람 정원 증가 |
| 첫 탐험 | 초원 정찰, 이구아노돈 알 확정 획득 | 첫 탐험 한 번의 보상만 지급 |
| 두 번째 친구 | 기본 부화 슬롯에서 부화·배치 | 알 소모와 새 개체 지급 한 번 |
| 다음 목표 | 종 다양성에 따른 수요 변화, DNA 연구 예고 | DNA 샘플·레시피 목표 화면을 확인 |

첫 튜토리얼에서 별도 부화장 선구매를 요구하지 않는다. 기존 기본 부화 슬롯을 사용하고 부화장 확장은 후속 시설 기획으로 남긴다. 탐험·부화와 관람대 건설의 첫 시간만 튜토리얼 전용 값을 사용한다. 상세 가격·시간은 밸런스 문서에서만 관리한다.

튜토리얼은 목표 카드 하나와 짧은 대화로 구성한다. 진행은 기존 `User.tutorialStep`을 사용하고, 보상 지급 이력만 별도로 관리한다. 보유 골드 총액을 매출로 보거나, 이미 배치·급식한 유저에게 같은 행동과 시작 보상을 다시 요구하지 않는다.

관람대는 기존 Lv.2 해금을 유지한다. 첫 입장료 목표의 파크 경험치 보상으로 그 레벨에 도달하게 한다. 시설 해금은 `Park.level`을 기준으로 하며 `User.level`을 별도 시설 해금값으로 병행하지 않는다. 경험치 공식의 기존 불일치는 연결 단계에서 한 기준으로 정리한다.

## 6. 첫 합성까지의 진행

첫 스테고케라톱스 탄생은 **첫날 경과 4~6시간, 실제 조작 40~60분**을 설계 목표로 한다. 탐험·부화·합성의 대기는 앱을 꺼도 진행한다. 타이머에 맞춰 수령하는 경우의 목표이며, 하루 2~3회 접속하면 다음 날까지 이어질 수 있다. 이 구간에는 대략 6~9회의 짧은 확인이 필요하다. 세션 횟수·조작 시간은 아직 실측하지 않았다.

| 개장 후 구간 | 공룡·탐험 | 시설·운영·스토리 |
| --- | --- | --- |
| 첫 10분 | 파라 돌봄 → 첫 정찰 → 이구아노돈 | 재개장 → 첫 관람대. 기존 첫 플레이 유지 |
| 약 10~45분 | 초원 심층에서 트리케라 알, 삼림에서 스테고 알. 첫 목표 탐험은 해당 알 확정 | 부화장으로 병렬 부화, 관람대 확장으로 다음 수요 수용. 챕터 1 재건 마무리 |
| 약 45~105분 | 원종 두 알 부화·돌봄, 합성 목표를 도감에 등록 | DNA 연구소 준비. 부화 대기 동안 배치·시설 정리 후 다음 접속 안내 |
| 약 105~150분 | 첫 원종 보유 후 연구 재료 탐험. 스토리의 랩터 도입·안전 사건 | 육식 서식지와 보안센터, 챕터 2 안전 절차. 보안 완료 전 일반 손님에게 랩터 전시하지 않음 |
| 약 150~230분 | 다른 연구 재료 탐험과 구 연구소 조사로 촉매 확보 | 챕터 3의 지하 연구소·과거 사건·연구 방향 선택, 초식 하이브리드 서식지 준비 |
| 약 230~270분 | 원종 보유·재료·레시피 확인 → 첫 지정 합성 100% 성공 | 시나리오 3-6 영웅 스테고케라톱스 1마리 탄생·전시. 이후 반복 연구부터 등급별 실패 적용 |

구간의 숫자는 대략적인 진행 순서이며 비용·타이머·필수 해금과 검산 결과는 [밸런스](balance.md)가 소유한다. 탐험·건설·부화는 서로 다른 슬롯에서 병행한다. 화면은 지금 해야 할 목표 하나와 진행 중 타이머를 함께 보여준다.

첫 원종 알과 핵심 연구 재료는 각 목표 탐험의 첫 완료 보상으로 보장한다. 대화만으로 재료를 즉시 지급하지 않는다. 원종 알을 받았다는 이유로 합성을 허용하지 않으며 부화한 실제 개체를 보유해야 한다.

첫 스테고케라톱스의 장면과 챕터 순서는 기존 시나리오를 유지한다. 구버전의 수일~수주 잠금과 챕터별 시간 목표는 승계하지 않는다. 프롤로그·챕터 1~2·3-6까지의 대사와 미션 분량은 이 시간대에 맞게 편집하되, 사건·관계·선택의 결과는 보존한다. 원본 대사와 스토리 데이터는 아직 수정하지 않았다.

관람대는 Lv.2, 부화장·연구소 준비는 Lv.3, 원종 두 종 돌봄 후 안전 시설은 Lv.4, 챕터 2 안전 완료 후 첫 하이브리드 전시는 Lv.5를 목표로 한다. 골드 총액만으로 스토리와 합성을 건너뛰지 않는다.

첫 합성 이후에는 원종 수집·탐험·재료 승급·연구를 반복하며 변종과 상위 하이브리드를 해금한다. 상위 레시피는 결과 등급에 따른 실패율과 재도전 규칙을 사용한다. 야간·해양·전설급의 구체적인 전체 진행 일수는 후속 검증 대상이다.

## 7. 시설 건설과 연구 조작

건설은 `선택 → 가격·효과 → 배치 미리보기 → 확정 → 완공`으로 진행한다. 전체 점유 면적·경계·동선·공룡/건물 점유를 서버에서 검사하고 확정 시 골드를 차감한다. 첫 시설은 관람대 한 종으로 이 흐름을 끝까지 완성한다.

연구는 `결과 공룡 선택 → 부족 재료 확인 → 탐험·재료 승급 → 합성 → 완료 수령 → 배치`다. 결과 종의 등급에 따라 실패율과 최대 시도 횟수를 표시하고, 실패 시 필수 재료 일부를 돌려준다. 원종 공룡은 유지하며 재료를 탐험으로 보충해 재도전한다. 변종과 하이브리드도 전시 수요에 기여하며 직접 골드를 주지 않는다.

## 8. 에셋

실물 자산 기준은 [임시 에셋 목록](../../../apps/client/public/assets/placeholders/README.md)이다. 과거 프롬프트 문서의 수백 종 파일은 제작 완료 자산이 아니다.

| 재사용 | 필요한 보충 |
| --- | --- |
| 파라 SVG | 이구아노돈의 머리·엄지 발톱·색상 등 구별 가능한 파생본 |
| 초원 서식지 SVG | 외곽 울타리·길 반복 요소 |
| 입구 게이트 SVG | 개장 상태·입장료 피드백 |
| 기존 SVG의 목재·잔디 표현 | 관람대·작은 방문객·알 |
| 파라의 몸체·동작 | 룩스 연구 단계에서 발광 볏·무늬·야간 표현 |

연구소와 스테고케라톱스는 해당 구현 단계에서 필요한 만큼 만든다. 지금 모든 공룡의 아트를 새로 생성하지 않는다. 다른 종에 파라 이름과 실루엣을 그대로 쓰는 대체 표현은 최종 완료로 보지 않는다.

## 10. 구현 순서와 완료 기준

1. **PLAY-02:** 경계·길·입구·손님·입장료. 폐장 시 새 입장 0, 중복 정산 없음, 온라인/오프라인 동일 계산, 기존 계정 보존.
2. **PLAY-03:** 관람대와 초반 밸런스 적용. 미리보기·차감·완공·수용량 증가를 실제 플레이로 검증.
3. **PLAY-04:** 확정 알·부화·두 번째 공룡·목표 카드. 신규 첫 세션 완주와 기존 진행 인정, 보상 중복 방지.
4. **DNA-01:** 공용 DNA·다섯 재료/세 품질·재료 승급, 레시피·연구소와 기존 DNA 보존.
5. **DNA-02:** 원종 확보와 재료 탐험·시설 확장, 챕터 3 첫 영웅 스테고케라톱스 100% 성공·한 번 수령·전시, 반복 연구의 실패·반환·재도전 검증.
6. **DNA-03:** 남은 종·서식지 정합성, 파라 룩스의 야간 관람·격리와 상위 연구·전시 효과 연결. 파라 룩스의 도감·카탈로그·예정 레시피는 CODEX-01에서 완료.

## 변경 기록

- 0.3 수정 / 2026-11-16: 변종·하이브리드는 영웅/전설에만 배치. 파라 시작·첫 합성 4~6시간 목표를 유지하고 첫 지정 합성은 100% 성공으로 영웅 스테고케라톱스 1마리를 확정 획득.

- 0.3 / 2026-11-15: 보유 원종·등급별 실패·탐험 재료 조건 반영. 첫 합성을 첫날 목표로 당기고 부화장·관람대 확장·안전 시설·연구소의 중간 여정 구체화. 공용 DNA와 전체 다섯 재료·다섯 품질·승급을 채택. 상세 원천은 DNA 기획이다.

- 0.2 / 2026-11-15: 구버전과 최신 기준 분리. 재건·입장료·경계·기존 아트 사용 기준 승계, 탐험과 DNA 합성을 함께 성장 경로로 정의.
