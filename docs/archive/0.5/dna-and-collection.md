# 공룡 도감·합성·재료 기획 0.5

기준일: 2026-11-16 · 상태: 도감·레시피 조회 구현, 첫 자연종 획득 구현·검증 완료, DNA 합성 실행 후속 · [문서 안내](../../README.md)

이 문서는 공룡 획득·개별 DNA 합성 레시피·합성 실패·도감을 소유한다. 연구원은 [연구소 기술 연구트리](research-trees.md)의 기술 항목을 연구하며 DNA 합성 담당 인력이 아니다. 이 문서의 합성 연구비·시간과 기술 연구의 비용·시간을 구별한다. 전체 자원 종류·품질·생산/사용처는 [자원·생산 기획](resources-and-production.md), 운영·생산 수치는 [밸런스](balance.md)가 소유한다.

## 1. 이번 결정

- 레시피에 필요한 원종 공룡을 실제 보유해야 합성을 시작한다. 도감 등록이나 알 보유만으로 대신할 수 없다.
- 합성에 쓰는 재료는 탐험으로 얻는다. 종별 정기 채취·자동 생산·대화에서 즉시 재료 지급은 사용하지 않는다.
- 결과 공룡 등급이 높을수록 기본 실패율이 높아진다. 원종 개체는 성공·실패 모두 유지한다.
- 변종·하이브리드는 영웅 또는 전설 등급에만 배치한다. 첫 지정 합성은 100% 성공해 모든 플레이어가 영웅 스테고케라톱스 한 마리를 얻는다.
- 연구 재료는 아래 다섯 종류로 통합한다. 일반 운영 자원은 목재·석재·금속·사료 네 종류이며, 기본 소모품은 총 9종이다. 종별 DNA·발광 DNA·전설 유전자 등을 별도 연구 재료로 늘리지 않는다.
- 재료 품질은 하급 → 중급 → 상급의 세 단계다. 공룡 희귀도는 기존 다섯 등급을 유지한다. 같은 재료 세 개로 한 단계 승급할 수 있다.

0.2의 종별 DNA 인벤토리·정기 채취·전 등급 확정 성공·첫 재료 즉시 지원은 폐기했다. 0.2는 [보관본](../../archive/0.2/dna-and-collection.md)으로 남겼다.

## 2. 연구 재료: 다섯 종류

| 종류 | 역할 | 처음 사용하는 구간 |
| --- | --- | --- |
| DNA 샘플 | 모든 합성의 유전자 재료. 모든 공룡이 공유 | 첫 연구 |
| 합성 촉매 | 합성 반응을 진행하는 소모품 | 첫 연구 |
| 배양액 | 새 개체를 배양하는 소모품 | 첫 연구 |
| 안정제 | 선택 사용. 실패하면 다른 필수 재료를 전부 돌려받음 | 첫 합성 이후 |
| 변이세포 | 변종 레시피의 추가 필수 재료 | 변종 연구 |

골드·다이아·탐험 에너지는 재화이며 이 다섯 재료의 종류 수에 포함하지 않는다. 공룡은 보유 조건으로 사용하고 소모품으로 취급하지 않는다.

연구 재료의 저장 조합은 최대 15개다. 일반 자원 네 조합을 더한 전체 기본 재료함은 19개 조합이며, 일반 4개·연구 5개의 카드에서 연구 품질만 펼쳐 본다. 일반 자원에는 품질을 추가하지 않는다. 첫 합성은 연구 재료 앞의 세 종류만 사용하며 안정제·변이세포는 이후 소개한다.

구버전의 발광 DNA·커틀피쉬 DNA는 독립 재료로 승계하지 않는다. 발광 등 특성은 연구 레시피의 해금 정보로, 변종의 재료 비용은 변이세포로 표현한다. 전설 유전자라는 여섯 번째 재료도 만들지 않는다.

## 3. 품질과 승급

| 품질 | UI 표기 | 다음 품질 |
| --- | --- | --- |
| 1 | 하급 | 같은 하급 재료 3개 → 중급 1개 |
| 2 | 중급 | 같은 중급 재료 3개 → 상급 1개 |
| 3 | 상급 | 추가 승급 없음 |

승급은 같은 종류·같은 품질끼리만 가능하며 확정 성공·즉시 완료다. 예를 들어 DNA와 촉매를 섞어 승급할 수 없다. 하급 재료만으로 상급 한 개를 만들려면 9개가 필요하다. 골드 비용은 [밸런스](balance.md)가 관리한다.

레시피는 재료마다 최소 품질과 수량을 표시한다. 상위 품질은 한 개를 한 개로 대체할 수 있지만 자동 선택은 요구를 충족하는 가장 낮은 품질부터 한다. 상위 재료를 사용한다는 이유만으로 성공률이 바뀌지 않는다. 하위 품질 여러 개를 합성 창에서 즉시 상위로 간주하지 않으며 승급을 먼저 완료한다.

전설급 공룡은 가장 높은 **상급 재료**를 요구한다. 재료에는 최상급·전설급 품질을 별도로 두지 않는다. 현재 합성 대상인 영웅 공룡은 중급, 전설 공룡은 상급을 최소 품질의 기본 기준으로 한다. 하급 재료는 수집 후 승급해 사용할 수 있다. 레시피별 수량·해금·실패율로 난이도를 구분하며 네 번째 품질을 추가하지 않는다.

재료함에 품질별 숫자를 모두 외우도록 요구하지 않는다. 합성 화면은 필요한 재료·부족량·최소 품질과 해당 재료를 얻을 탐험, 승급 가능 여부만 보여준다.

## 4. 공룡 도감과 등급

공룡 희귀도는 기존 Rarity 다섯 등급을 사용한다. 개체 레벨과 희귀도를 다른 정보로 표시하고, 레벨이 높아졌다는 이유로 희귀도나 실패율을 바꾸지 않는다.

| 공룡 등급 | 표시 | 예시 |
| --- | --- | --- |
| 커먼 | 일반 · ★ | 파라사우롤로푸스, 이구아노돈 |
| 언커먼 | 고급 · ★★ | 트리케라톱스, 스테고사우루스, 벨로시랩터 |
| 레어 | 희귀 · ★★★ | 티라노사우루스 렉스 |
| 에픽 | 영웅 · ★★★★ | 스테고케라톱스, 파라 룩스, 스피노랩터 |
| 레전더리 | 전설 · ★★★★★ | 인도미누스 렉스 |

도감은 등급·생태 분류·획득 경로로 필터한다. 자연종·변종·하이브리드는 획득/연구 분류이며 별도의 여섯 번째 등급이 아니다. 레시피가 없는 공룡은 등급표가 있어도 임의로 합성할 수 없다.

변종·하이브리드는 영웅·전설에만 존재한다. 기존 희귀 하이브리드였던 안키로덕터(Ankylodocus)·스테고케라톱스·카르노랩터는 영웅으로 올렸다. 자연종의 기존 등급은 유지하며 영웅·전설 자연종도 존재할 수 있다.

미발견은 실루엣, 단서나 알 획득은 발견, 실제 개체를 처음 얻으면 영구 도감 등록, 현재 살아 있는 개체 수는 보유로 구분한다. 등록 기록은 유지하지만 원종을 모두 방생하면 그 원종이 필요한 새 합성은 잠긴다. 도감의 총수는 실제 공개된 종 목록을 사용하며 과거의 82종·가짜 수집률을 그대로 표시하지 않는다.

결과 공룡 상세에는 등급·현재 보유 원종·레시피·재료 품질·확률·현재 실패 보호 진행·서식지를 보여준다. 레시피와 개체 등급은 game-data의 기존 소유 데이터를 참조한다.

## 5. 실제 보유 조건

합성 시작 시 필요한 각 원종에서 실제 개체 한 마리씩 선택한다. 행복도 30 이상·배고픔 80 이하가 필요하며 배치 대기 중인 보유 개체도 사용할 수 있다. 선택 개체는 DNA 합성 시작부터 결과 수령·실패 정산까지 방생·이전·다른 합성 참여를 잠그되 기존 전시는 유지한다.

원종 개체를 합쳐 없애거나 결과 공룡으로 교체하지 않는다. 완료·실패를 처리하면 잠금을 푼다. 같은 공룡 두 마리를 요구하는 레시피는 개체 두 마리가 필요하다. 현재 첫 레시피는 서로 다른 두 종을 사용한다.

### 기술 연구와 DNA 합성의 구분

연구원은 연구소 내 기술 연구트리의 기술 항목을 연구한다. 게임 시작부터 무료1명을 보유하고 추가 인원은 다이아로 영구 구매한다. 실제 기술 연구는 연구소 완공 뒤 가능하며 완공 때 무료 연구원을 다시 지급하지 않는다. 각 기술 항목은 3~5레벨로 성장하며 보유 연구원 수만큼 여러 기술 항목을 동시에 연구할 수 있다. 연구소 건물의 25레벨, 기술 항목 레벨, 연구원 보유 수는 서로 다른 값이다. 항목별 효과·비용·시간·선행 조건과 인원 점유는 [기술 연구트리](research-trees.md), 인원 구매 조건은 [밸런스](balance.md)를 따른다.

기술 연구에는 공룡 개체를 배정하거나 잠그지 않는다. 연구원 추가 구매나 기술 연구 완료가 DNA 합성 슬롯·원종·첫 보장 예약·확정 보호 시도 수를 늘리거나 바꾸지 않는다. 상위 레시피 권한·일반 합성 시간·실패 재료 반환율에 적용하는 기술 효과는 [기술 연구트리](research-trees.md)가 소유하며, 레시피의 원종/재료 조건은 그대로 충족해야 한다. 기술 작업비는 골드·목재·석재·필요시 금속이며 합성용 연구 재료5종을 사용하지 않는다. 연구원 구매비인 다이아와 기술 작업비를 구별한다.

DNA 합성은 기존 기준인 **기본 한 슬롯**의 별도 작업으로 유지하고 기술 연구와 연구원 슬롯을 공유하지 않는다. 첫 지정 합성에 연구원 추가 구매나 다이아 소비를 필수 조건으로 넣지 않는다. 선택 원종의 보유·작업 잠금·성공/실패 후 보존·수동 결과 수령은 기존 합성 규칙을 따른다.

DNA 합성 자체의 병렬 확장과 복수 합성 간 동일 개체의 중복 배정 정책은 미정이다. 기술 연구의 병렬 인력 결정으로 이 정책을 자동 확정하지 않는다. 현재 기본 한 슬롯에서는 시작 시 사용 가능한 합성 슬롯·원종·재료 품질/수량·골드·첫 보장 예약을 함께 검사하며 어느 조건이든 실패하면 일부 비용이나 원종 잠금만 처리하지 않는다.

## 6. 결과 등급별 실패와 보호

| 결과 등급 | 기본 성공률 | 기본 실패율 | 일반 레시피의 확정 시도 |
| --- | --- | --- | --- |
| 커먼 | 95% | 5% | 최대 2번째 |
| 언커먼 | 85% | 15% | 최대 3번째 |
| 레어 | 70% | 30% | 최대 3번째 |
| 에픽 | 50% | 50% | 최대 5번째 |
| 레전더리 | 30% | 70% | 최대 8번째 |

현재 합성 레시피의 결과는 영웅·전설뿐이며, 일반·고급·희귀 행은 공용 기준값으로 남아 있지만 합성 대상에는 사용하지 않는다.

확률은 결과 공룡 등급 기준이다. 원종 레벨을 높였다는 이유로 불리해지지 않는다. 실패 보호는 파크·레시피별 연속 실패 횟수를 보존하고, 표의 마지막 시도는 100% 성공한다. 성공하면 해당 레시피의 횟수를 초기화한다. 다른 저등급 레시피 실패를 전설 레시피에 옮길 수 없다.

실패하면 실제 투입한 종류·품질별 필수 재료의 기본 80%를 내림하여 반환한다. 안정제 미사용 시에는 [시료 보존 기술](research-trees.md)의 완료 단계에 따라 반환율을 높인다. 단계별 수치는 연구트리 원천을 읽는다. 골드·연구 시간은 돌려주지 않는다. 한 개를 넣은 재료는 반환 수량이 0개가 될 수 있으므로 시작 전에 실제 소모/반환을 보여준다. 선택 안정제를 넣었다면 기술 단계와 관계없이 필수 재료 전부 반환이 우선하며 안정제 한 개만 소모한다. 안정제는 성공해도 소모하며 해당 레시피가 요구하는 최소 품질 이상이어야 한다.

첫 지정 스테고케라톱스 연구는 파크당 한 번, 첫 시도에 **100% 성공**해 영웅 개체 한 마리를 얻는다. 파라 한 마리로 시작하고 원종 확보·시설 확장·탐험 재료 수집을 거쳐 첫 합성을 완료하는 흐름이다. 첫 실패·회복 탐험은 사용하지 않는다. 첫 연구를 마친 이후 같은 레시피를 반복하면 일반 영웅 규칙인 성공률 50%·최대 5번째 확정을 사용한다.

첫 지정 보장은 작업 시작 때 파크의 해당 작업에 예약하고 결과 수령 때 사용 완료로 확정한다. 다른 합성 작업·레시피·기기에서 같은 예약을 다시 쓸 수 없으며, 도감 등록·기술 연구·채용·재접속으로 예약을 이전하거나 초기화하지 않는다. 레시피별 실패 보호는 유지한다. DNA 합성의 병렬 확장을 채택한다면 동시 시도의 예약·수령·보호 갱신 순서를 별도로 확정해야 한다.

확률과 반환·보호 규칙은 시작 시 확정한다. 시료 보존을 나중에 완료해도 진행 중 합성의 반환율을 소급 변경하지 않는다. 새로고침·중복 수령으로 결과를 다시 뽑지 않는다. 과거 위인/시설의 성공률 보너스는 현재 표에 자동 합산하지 않는다.

## 7. 우선 레시피

원종 조합·특징과 첫 합성의 서사는 구버전 도감·시나리오에서 승계했다. 아래 재료 체계와 수치는 0.3에서 재설계했으며 과거 종별 DNA 요구량보다 우선한다.

첫 스테고케라톱스 재료는 전용 탐험들에서 확보한다. 최초 주요 탐험 보상은 확정이지만 일반 탐험은 별도 표를 따른다. 연구 시간에 배양·탄생을 포함하므로 같은 결과에 알 부화 시간을 다시 붙이지 않는다. 성공하면 배치 대기 공룡 한 마리를 받는다.

파라 룩스는 CODEX-01에서 실제 카탈로그·영웅 등급·변종 분류와 임시 도감 아트를 연결했다. 야간 관람·발광 연구·합성 실행은 아직 개방되지 않았다. 인도미누스의 가격·시간과 최종 연구 레시피는 미검토 상태에서는 비활성이다.

### 건물 성장과 연구 조건

첫 지정 영웅은 DNA연구소Lv.1과 기존 챕터/원종/재료 조건으로 진행하며 기술 연구를 필수로 요구하지 않는다. 주요 건물25레벨은 장기 투자 목표이며 첫 합성을 최고 레벨에 잠그지 않는다. 상위 영웅 하이브리드·변종·전설 분기의 권한은 [고급 유전자 분석](research-trees.md), 시설 성능은 [밸런스](balance.md#5-건물별-성능)를 따르고 레시피 품질/원종/챕터와 실제 안전 시설 조건도 충족해야 한다. 격리 연구는 위험종 유지비를 줄이는 선택 기술이며 상위 합성의 필수 해금 조건이 아니다.

일반 합성 시간은 `레시피 기본 시간 × (1 - 연구소 단축률) × (1 - 배양 공정 단축률)`로 계산한다. 단계별 효과·최종 계산은 [기술 연구트리](research-trees.md)를 읽으며, 첫 지정100% 합성은 연구소·기술 단축 없이 표의30분을 유지한다. 작업 시작 때 시간과 효과 버전을 고정한다. 성공률·첫100%·확정 보호 시도 수는 그대로 유지하며 실패 재료 반환율만 시료 보존 기술의 적용 대상이다.

기존 파라 룩스의 유전자센터/발광 특성 조건은 고급 유전자 분석Lv.2로, 스피노랩터의 과거 격리 연구 표기는 고급 유전자 분석Lv.1과 실제 안전 시설 조건으로, 전설 분기는 Lv.3으로 버전 매핑할 계획이다. 현재 game-data 레시피와 도감·코드에는 기존 조건이 남아 있고 기술 트리는 구현 전이므로 문서만으로 연구가 개방됐다고 표시하지 않는다. 이미 얻은 연구 해금은 이관 때 보존한다.

## 8. 탐험 중심의 진행

첫 자연종 안내는 초원 조사 → 이구아노돈 지정 알 → 실제 부화·보유·배치로 연결했고 해당 흐름의 기능 검증을 완료했다. 이후 첫 원종 알 → 실제 부화·보유 → 연구 재료 탐험 → 구 연구소의 촉매 → 합성 순서로 확장한다. 첫 원종 두 종은 각각의 목표 탐험에서 알을 확정 제공한다. 종별 DNA를 모으는 대신 공용 재료를 모으되, 합성은 현재 보유한 원종으로만 가능하다.

탐험은 장소 선택 → 그 장소의 목표 미션 플레이 → 검증된 보상 한 번 수령으로 진행한다. 한 장소의 기본 연구 재료는 한 종류이며 대응 관계는 자원 기획, 첫 목표의 보상량은 밸런스 문서를 따른다. 알·스토리 단서는 별도 목표로 다루고 여섯 번째 상시 연구 재료를 추가하지 않는다.

첫 초원 정찰은 첫 관람대 완공 뒤 세 단서를 직접 선택하는 조사 미션이다. 준비비·연료(현재 코드의 탐험 에너지)는 출발 때 한 번만 쓰며 오답·재접속에는 추가 소비가 없다. 알은 한 개를 수령해 보관한 뒤 기본 자리에서 부화를 수동 시작하고, 완료 후 개체·영구 도감·건강한 첫 개체의 XP700을 한 번 처리해 파크 배치로 잇는다. 첫60초 부화 외에 조사90초 강제 대기를 넣지 않는다. 상세 수치는 밸런스가 소유한다.

기존 이구아노돈 보유 또는 도감 등록은 튜토리얼 이력으로 인정해 지정 알·XP를 다시 지급하지 않는다. 도감만 남고 방생한 계정의 튜토리얼 완료 인정은 합성의 실제 원종 보유 조건을 대신하지 않는다. 재입수 일반 미션은 후속이다.

기본 탐험은 하나의 진행 미션을 저장해 접속 후 이어 하며, 시간 경과만으로 성공시키지 않는다. 건설은 보유 건설자 수만큼, 기술 연구는 보유 연구원 수만큼 병렬 진행한다. 건설자는 서버 완공 처리 때 반환하며 기술 연구의 점유/완료 규칙은 연구트리를 따른다. DNA 합성은 기본 한 슬롯으로 별도 진행하고, 부화 자리도 별도 시설 수용량으로 관리한다. 두 기능은 연구원 슬롯을 공유하지 않는다. 부화장은 기본 슬롯을 포함해 총 세 알을 병렬 부화하는 초기 앵커를 유지한다. 이미 시작한 생산·부화·합성 타이머는 앱을 꺼도 진행한다. 첫 합성 4~6시간은 다회 분산 접속 목표이며, 새 자재·미션을 포함한 모델 결과와 집중 진행 시간은 [밸런스](balance.md)의 접속 조건·가정·검증 범위를 따른다.

첫 합성에는 실패가 없으므로 기존 첫 실패 반환·회복 탐험 보상은 폐기한다. 반복 합성부터 실패·기본80% 반환과 시료 보존/안정제 효과·연속 실패 보호를 적용한다. 시간·비용·탐험 보상 원천은 [밸런스](balance.md)다.

일반 탐험에서는 장소·목표 재료·기본 보상·품질을 출발 전에 보여준다. 하급을 모아 승급하는 경로와 후반 조사에서 상급을 직접 얻는 경로를 모두 둔다. 첫 레시피를 위해 하급을 수백 개 먼저 모으도록 강제하지 않는다. 구체 미션의 조작·재미·추가 보상·일반 수급량은 아직 검증하지 않았다.

중복 공룡을 방생해 신규 합성 재료를 만드는 경로는 추가하지 않는다. 기존 공용 DNA 보상/상점 경로는 현재 런타임 기능이므로 탐험 중심 전환 때 조정하고 기존 잔액은 보존한다.

연료는 기존 탐험 에너지 하나를 자동 회복/보급소로 공급한다. 재료5종·3품질이나 합성 레시피에 연료를 다시 넣지 않는다. 기본 합성 비용은 골드/연구 재료이고 탐험 연료는 출발 때만 차감한다. 금고가 차도 이미 보유한 재료·알·진행 중 연구를 지우지 않는다.

## 9. 데이터와 구현 범위

현재 첫 자연종의 지정 알 보관·부화·수령·도감·배치는 연결돼 있으며 해당 흐름의 UI 검증을 완료했다. 목재·석재는 공통 재료함에 부분 연결했으나 연구 재료 재고/품질·승급·실제 DNA 합성은 아직이다. 현재 Currency.dna는 품질 없는 공용 숫자다. 새 구현에서는 일반 자원과 연구 재료를 공통 재료함에서 관리하고 종류·해당 품질별 재고를 수량의 단일 원천으로 한다. 기존 DNA는 하급 DNA로 1:1 이관하고 지급 이력을 남긴다. 구 API의 dna 값은 하급 DNA를 읽는 호환용 투영으로 제공하며 독립 잔액을 계속 갱신하지 않는다. 이관 전·후를 동시에 소비할 수 없도록 한다. 이번 문서 작업에서 실제 DB 이관은 수행하지 않았다.

레시피 데이터는 game-data, 재료 타입·품질·응답 계약은 shared가 소유한다. DNA 합성 시작 시 원종·품질별 재료·골드·합성 슬롯을 함께 검증/차감하고 작업·확률·레시피 버전·보장 예약을 저장한다. 병렬 합성 자체와 개체 중복 배정 여부에 따른 추가 예약·정산 규칙은 미정이다. 수령은 작업 결과를 다시 뽑지 않는다. 성공 개체/도감 등록 또는 실패 반환·레시피별 보호 갱신·첫 보장 사용 확정·원종 잠금/합성 슬롯 해제를 해당 작업의 같은 거래에서 한 번 처리한다. 중복 수령이 비용·결과·반환·빈 합성 슬롯 수를 더하지 않는다. 재료 승급은 하위 차감·상위 지급·골드 차감을 같은 거래로 처리한다.

첫 지정 합성의 보장 상태는 파크의 해당 연구 예약과 합성 완료 이력이 소유하며, 예약된 작업의 결과 한 마리 지급·도감·사용 완료 기록을 한 거래로 처리한다. 도감 등록이나 현재 보유 수로 적용 여부를 추정하지 않는다. 방생·새로고침·중복 요청으로 첫 합성 혜택을 다시 받을 수 없다. 도감의 첫 지정 합성 안내는 공통 규칙 설명이며 현재 계정의 실행 가능 여부를 판정한 값이 아니다.

서식지 ID·종 호환·개체 수와 점유 공간을 정리해야 첫 결과를 전시할 수 있다. 구버전 도감의 Ankylodocus 중복과 카탈로그 누락은 숫자를 맞추려고 복제하지 않고 별도 대조한다.

실제 검증 대상: 미보유 원종·부화 전 알·낮은 품질 거절, 전설 최소 품질, 승급 보존량·동시 요청, 첫 지정 합성 100%의 시작 예약과 파크당 한 번 수령, 반복 합성의 실패 확률·보호 횟수·반환, 원종 작업 잠금·기본 합성 슬롯 초과 거절, 중복 결과/환급·원종/슬롯 이중 해제 방지, 정확한 종·등급과 서식지, 기존 DNA·개체·해금 보존. 기술 연구가 DNA 합성 슬롯이나 공룡 개체를 점유하지 않는지도 구분 검증한다. 병렬 합성/개체 중복 배정과 그 보호 예약·정산은 정책을 확정한 뒤 검증한다. 실제 DNA 합성과 기술 연구·채용은 아직 구현 전이다.
