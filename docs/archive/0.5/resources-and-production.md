# 기본 운영 자원·생산 기획 0.5

기준일: 2026-11-16 · 상태: 25레벨·전체 골드 금고·탐험 연료 통합 설계, 새 규칙의 런타임 적용 전. 현재 목재·석재 부분 적용·검증 범위는 12절 참조 · [문서 안내](../../README.md)

## 1. 범위와 기준

이 문서는 기본 운영에 필요한 자원의 종류·필요성·품질·획득처·생산 방식·사용처를 소유한다. 가격·생산 수량·시간·저장 한도는 [밸런스](balance.md), 개별 공룡 합성 레시피와 실패 규칙은 [DNA 기획](dna-and-collection.md)이 소유한다. 요약 문서에서 다른 값을 만들지 않는다.

사용자 확정 요구는 자원의 용도를 먼저 정리하고 복잡도를 억제하는 것, 스토리·이벤트 아이템은 이후 추가하는 것, 합성 재료 5종·품질 3단계·장소별 미션 수급과 입장료 경제를 유지하는 것이다. 0.5에서는 주요 건물 25레벨·5레벨마다 큰 변화, 보유 골드 전체에 적용하는 금고 한도, 기존 탐험 에너지를 연료 한 재고로 통합하고 자동 회복과 보급소 생산을 병행하는 방향을 반영한다. 개별 비용·생산량·시간·한도는 밸런스의 설계값을 읽고 실제 게임 구현·플레이 검증과 구별한다.

기본 소모품은 **일반 자원 4종 + 연구 재료 5종 = 총 9종**으로 정리한다.

| 구분 | 종류 | 품질 | 재고 조합 수 |
| --- | --- | --- | --- |
| 일반 자원 | 목재·석재·금속·공용 사료 | 품질 구분 없음 | 4 |
| 연구 재료 | DNA 샘플·합성 촉매·배양액·안정제·변이세포 | 하급·중급·상급 | 15 |
| 합계 | 기본 소모품 9종 | 합성용 연구 재료에만 품질 적용 | 19 |

골드·다이아·탐험 연료는 별도 재화/행동 자원이다. 연료는 기존 탐험 에너지의 표시와 공급 경로를 통합하므로 열 번째 소모 재료를 추가하지 않는다. 공룡 알은 부화 대상으로 관리하고, 공룡 개체·경험치·시설 레벨·청결 표현은 소모 재료로 세지 않는다. 시즌/위인 포인트와 이벤트 물품은 기본 운영의 필수 재료에 넣지 않는다.

0.4의 자원 구성과 당시 모델 입력은 [보관본](../../archive/0.4/resources-and-production.md)에 남긴다. 이 문서는 기존 9종·19조합을 유지하면서 골드 한도와 행동 연료의 운영 규칙을 바꾸며, 실행 코드·DB·기존 계정은 변경하지 않는다.

지역 이름은 이번 설계의 명칭이다. 장소별 기본 재료를 한 종류로 고정한다는 규칙을 유지하며, 구체적인 미션 조작은 아직 검증 중이다. 장소마다 별도 미니게임을 반드시 새로 만들기로 확정한 것은 아니다.

DNA·촉매·배양액은 첫 스테고케라톱스에 쓰고, 안정제·변이세포는 처음부터 학습시키지 않는다. 모든 재료를 모든 레시피에 넣지 않는다. 공룡 원종은 실제 보유 조건이며 성공·실패 모두 소모하지 않는다.

## 3. 골드·다이아·탐험 연료

| 자원 | 획득 | 사용 | 기본 운영의 원칙 |
| --- | --- | --- | --- |
| 골드 | 실제 받은 방문객 입장료 | 건설·업그레이드, 건설자 고용, 기본 물자 구매·생산, 기술 연구비·합성 연구비, 시설/개체 유지비, 품질 승급 | 보유 잔액 전체에 금고 한도 적용. 공룡·생산 시설·금고가 직접 골드를 생성하지 않음 |
| 다이아 | 별도 보상·선택 구매 경로 | 연구원 추가 영구 구매·선택적 편의 기능 | 연구원은 시작부터 무료1명 보유. 첫 시설·첫 탐험·첫 합성에 필수 소비 없음 |
| 탐험 연료 | 시간 경과 자동 회복 / 골드로 기본 물자 구매 / 연료 보급소 생산 | 미션 출발 | 기존 에너지와 같은 단일 탱크. 출발 때 한 번 소비하고 오답·조사·재개에 추가 차감하지 않음 |

연구 재료의 기본 수급은 장소별 플레이 미션이다. 골드로 연구 재료를 즉시 구매하거나 생산 시설에서 자동 생성하는 경로는 기본 설계에 넣지 않는다. 현재 코드의 DNA 상점·방생·보상 지급 경로는 이관 시 조정할 기존 기능이며, 이미 얻은 잔액은 보존한다.

### 금고와 입장료 실적

| 정보 | 단일 원천과 역할 |
| --- | --- |
| 보유 골드 | `Currency.gold`가 소유하는 실제 사용 가능 잔액. 별도 예금·은행 잔액을 만들지 않음 |
| 금고 한도 | 전체 골드 잔액의 저장 한도. 금고의 최고 완공 레벨 효과를 적용하며 금고마다 돈을 따로 넣지 않음 |
| 누적 입장료 | `totalAdmissionGold`의 평생 실적. 실제 받은 입장료만 더하며 지출로 차감하지 않음. 잔액·순이익·저장 한도와 구별 |

기본 금고는 무료로 제공한다. 기존 시설을 자동 이동·삭제하지 않고 유효 위치를 안내하며, 배치를 마칠 때까지도 기본 한도를 보장한다. 첫 연구에 금고 고레벨을 새 선행 조건으로 요구하지 않는다. 금고의 레벨별 한도·강화비·필요 자재·시간은 [밸런스의 전체 금고 규칙](balance.md#7-입장료와-전체-금고-한도)과 [전 레벨 파생표](building-upgrade-tables.md)를 따른다.

금고에 입장료 한 명분의 공간이 있을 때만 유료 입장을 확정한다. 공간이 부족하면 추가 유료 입장만 멈추고 기존 관람·돌봄·생산·탐험·지출은 유지한다. 공간이 생기면 자동 재개하며 수동 휴장과 구별해 안내한다. 받지 않은 입장료·대기 손님을 미수금이나 숨은 방문 잔여로 쌓지 않는다. 소비 직후 밀린 돈을 한꺼번에 지급하거나 입장료 일부만 수납하지 않는다.

오프라인에도 같은 전체 잔액 한도를 적용하고, 실제 수령한 입장료만 유료 입장·누적 실적에 반영한다. 유지비·적립 시간 상한·입장·지출·한도 변경의 정산 순서는 밸런스를 따른다. 금고는 돈을 소비하는 시설·연구를 대신하지 않으며 이자·대출·추가 수익을 제공하지 않는다.

기존 한도 초과 잔액과 정상 취소/환불은 전액 보존한다. 초과 상태에서도 지출·환불을 허용하고 새 적립만 멈춘다. 유료 골드 구매는 공간을 확인한 뒤 결제하고 새 골드 보상도 수령 전에 한도를 확인한다. 현재 잔액을 강제로 잘라 새 한도에 맞추지 않는다.

## 4. 품질·공룡 등급·시설 레벨

| 대상 | 구분 | 영향을 주는 것 |
| --- | --- | --- |
| 목재·석재·금속·사료 | 품질 없음 | 수량만 확인 |
| 연구 재료 | 하급 → 중급 → 상급 | 레시피가 요구하는 최소 품질 |
| 공룡 | 일반 → 고급 → 희귀 → 영웅 → 전설 | 수집 등급·결과 기본 합성 확률 |
| 공룡 개체 | 개체 레벨 | 개체 성장. 공룡 수집 등급·재료 품질과 구별 |
| 주요 시설 | 시설 Lv.1~25 | 5레벨마다 큰 외형/기능 변화. 재료 종류나 품질을 새로 만들지 않음 |

영웅 합성은 중급, 전설 합성은 상급을 기본 최소 품질로 쓴다. 하급 3개로 같은 종류 중급 1개, 중급 3개로 상급 1개를 확정 승급한다. 위 품질의 재료는 한 개를 한 개로 대체하고, 좋은 품질을 넣는다고 합성 성공률을 추가로 높이지 않는다.

초기 연구 목표 미션은 필요한 중급을 직접 제공한다. 첫 합성 전에 하급을 대량 수집·승급하도록 강제하지 않는다. 상급의 일반 수급은 후반 조사 난이도와 연구 해금에 연결한다. 승급은 실제 플레이 난이도와 품질 해금 규칙을 대체하는 별도 여섯 번째 재료가 아니다.

일반 자원에 공룡 등급이나 연구 품질을 확대 적용하지 않는다. 예를 들어 희귀 목재·전설 사료·고급 금속 부품은 기본 재고에 추가하지 않는다.

## 5. 생산 시설과 생산 규칙

일반 자원 생산은 골드를 쓰고 시간을 들여 기본 물자 구매보다 효율적으로 확보하는 경로다. 초반 수치안과 같은 물량의 구매 대비 투자 회수 기준은 밸런스 문서에 기록했다. 실제 소비 수요가 필요하며, 시설 이름이나 설계 검산만으로 생산 구현이 끝났다고 보지 않는다.

| 시설 | 투입 | 결과 | 선택할 이유 | 현재 코드 상태 |
| --- | --- | --- | --- | --- |
| 벌목장 | 골드·생산 슬롯·시간 | 목재 | 반복 건설의 목재 구매비 절감 | RES-01A 구현·검증 완료 |
| 채석장 | 골드·생산 슬롯·시간 | 석재 | 기반 공사·확장의 석재 구매비 절감 | RES-01A 구현·검증 완료 |
| 금속 공방 | 골드·생산 슬롯·시간 | 금속 | 상위 시설용 금속 구매비 절감 | 구버전 제련소 역할 단순화. 새 카탈로그·생산 구현 필요 |
| 사료 공장 | 골드·생산 슬롯·시간 | 공용 사료 | 공룡이 늘어난 뒤 반복 급식비 절감 | 건물 카탈로그만 존재. 생산 구현 필요 |
| 탐험 연료 보급소 | 골드·생산 슬롯·시간 | 기존 행동 연료 탱크에 수령할 생산품 | 자동 회복과 병행해 탐험 출발 준비. 일반 자원 재료함과 구별 | 0.5 신규 설계. 카탈로그·생산·탱크 연결 필요 |

연료 보급소는 일반 자원 네 종류를 생산하는 시설과 같은 작업 조작을 사용하지만, 결과를 넣는 곳은 탐험 행동 연료 탱크다. 생산량·단위 작업비·시간·강화에 따른 할인과 탱크 한도는 [밸런스의 생산·연료 규칙](balance.md#6-생산-단가와-연료)을 읽는다. `fuel`은 이 기획의 행동 재화 표기이며 독립적인 일반 재료 잔액을 뜻하지 않는다.

원목·목재판, 철광석·정제 연료·금속괴, 곡물·고기·배합 사료처럼 여러 단계로 가공하지 않는다. 원유·정유품·연료 아이템 재고도 추가하지 않는다. 결과 한 종류와 골드 비용·시간만 본다.

생산은 종류/수량 선택 → 비용·예상 수령 시각 확인 → 시작 → 완료 → 수령이다. 시설마다 한 작업만 진행하고, 시작할 때 기본1~3회분을 선택해 비용을 한 번 차감한다. 수량·비용·시간은 같은 비율로 늘어나며 선택된 물량 전체를 한 번 수령한다. 앱을 꺼도 시작한 작업은 끝나지만 다음 작업을 자동으로 시작하지 않는다. 생산 운영비는 작업비에 포함하며 별도 대기 유지비를 중복 청구하지 않는다. 일반 자원·연료 생산 자체에 탐험 연료를 쓰거나 미니게임을 추가로 요구하지 않는다.

완료된 배치는 수령 전까지 시설에 보관한다. 창고 공간이 부족하면 수령을 보류하고 내용물을 지우지 않는다. 수령 중복·재접속으로 결과가 늘거나 비용이 다시 나가지 않도록 배치 완료 이력으로 처리한다.

기본 물자 구매는 급한 수요와 생산 시설이 없는 시작 구간을 위한 보완 경로다. 정상 운영에서는 생산의 단위당 총비용이 구매보다 낮아야 한다. 기본 재료의 골드 판매·환전은 기본 범위에 넣지 않는다.

### 탐험 연료의 자동 회복과 생산 수령

기존 `explorationEnergy`와 회복 시각을 그대로 단일 원천으로 승계하고 표시를 탐험 연료로 바꾼다. 자동 회복·구매·생산 수령·탐험 출발은 모두 같은 탱크를 읽고 갱신한다. 생산이 끝난 미수령 연료는 탱크에 들어가기 전 완료 보상이며 별도 사용 가능 잔액이 아니다. 출발 때 에너지와 연료를 이중 차감하지 않는다.

기본 자동 회복은 보급소 없이도 제공한다. 보급소 강화는 탱크 한도와 생산 효과를 확장하며 자연 회복 간격을 별도 가속하지 않는다. 탱크가 가득 차면 회복을 멈추고 가득 찬 동안의 회복 시간을 무제한 저장하지 않는다. 정확한 기본 한도·회복 간격·출발 소비량은 밸런스의 공통 값이 소유한다.

선택한 전체 생산량은 해당 최대 탱크에도 담을 수 있어야 한다. 회복과 생산 수령이 겹치면 같은 최대 연료 원천을 사용해 한도를 검사한다. 공간이 부족한 완성 배치는 온전히 보존하고 연료를 사용한 뒤 전량 수령한다. 수령 실패로 생산비를 다시 차감하거나 초과분을 버리지 않는다.

보급소 철거·이관으로 최대치가 줄어도 이미 보유한 연료를 잘라내지 않는다. 한도 아래로 소비될 때까지 새 회복·구매·생산 수령을 멈추되 기존 연료로 출발할 수 있게 한다. 자동 회복 구현도 기존 초과량을 새 최대치로 덮어쓰지 않아야 한다. 첫 탐험과 첫 합성은 기본 회복·구매로 진행할 수 있고 보급소 구매를 필수 조건으로 삼지 않는다.

## 6. 건설·업그레이드에서의 소비

일반 시설의 비용은 골드와 아래 자재 중 필요한 것만 사용한다. 모든 건물에 자재 세 종류를 일괄 요구하지 않는다.

| 건설 대상 | 자재 역할 | 도입 원칙 |
| --- | --- | --- |
| 최초 지급 입구·초원·금고 | 자재 비용 없음 | 기존 시작 콘텐츠와 보유 시설 유지. 금고의 기본 효과는 무료 보장 |
| 첫 튜토리얼 관람대 | 골드만 소비 | 자재함·생산 시설을 배우기 전에 첫 성장 경험 완료 |
| 첫 벌목장·채석장·사료 공장·연료 보급소 | 골드만 소비 | 생산 시설을 짓기 위해 그 시설의 생산품을 먼저 요구하지 않음 |
| 이후 일반 관람대·저층 시설 | 목재 중심 | 필요하면 기반 공사에 석재 추가 |
| 부화장·기초 연구소·초식 하이브리드 서식지 | 목재·석재 중심 | 첫 연구 전에 두 자재의 수급 경로 안내. 금속은 첫 합성 필수 조건에서 제외 |
| 상위 보안·대형 시설·상위 연구소 | 석재·금속 중심 | 첫 보안센터와 첫 연구에는 금속을 요구하지 않으며 첫 합성 이후 도입 |
| 금속 공방 | 목재·석재 중심 | 자신의 생산품을 최초 건설 조건으로 요구하지 않음 |

초반 자재 수량·시설 가격·해금·공급 속도와 구매/생산 경로의 검산은 밸런스 문서를 따른다. 주요 건물 25레벨의 모든 중간 단계 비용·효과는 밸런스 원천에서 [건물별 전 레벨 표](building-upgrade-tables.md)로 생성하며 이 문서에 독립 가격표를 만들지 않는다. 첫 합성에는 생산 시설·창고·금고 고레벨을 강제하지 않는다. 건설 자재는 필요한 목재·석재·금속만 사용하며 사료·연료·연구 재료를 새 건설 비용으로 추가하지 않는다. 0.3의 골드 전용 계산을 새 경제의 결과로 재사용하지 않는다.

건설 확정 시 골드·자재·점유 공간·건설 슬롯을 함께 검증/차감한다. 배치 미리보기·취소·실패한 요청은 소비하지 않는다. 업그레이드도 현재 단계의 비용을 한 번만 지불한다. 운영 중에 목재·석재·금속이 자동으로 닳거나 시설 수리비로 반복 빠지는 기능은 기본 범위에 넣지 않는다.

### 건설자와 연구원의 병렬 작업

건설자 한 명은 건설 또는 강화 하나를 맡고, 보유 인원만큼 서로 다른 시설의 공사를 동시에 진행한다. 연구원 한 명은 연구소 기술 연구트리의 기술 항목을 맡으며 보유 인원만큼 여러 기술 항목을 동시에 연구한다. 각 기술 항목은 3~5레벨이고 건물 25레벨과 구별한다. 인원을 한 작업에 여러 명 배치해 시간을 중첩 단축하지 않는다. 같은 시설의 동시 강화는 허용하지 않으며 기술 항목의 선행/단계 조건과 점유·완료 정책은 [기술 연구트리](research-trees.md)를 따른다.

기술 연구의 작업비에는 골드·목재·석재·필요시 금속을 쓰며, 합성용 연구 재료5종·사료·연료를 사용하지 않는다. 연구원 추가 구매비인 다이아와 기술 작업비를 구별한다. 별도 연구 포인트·책·과학 재화를 추가하지 않는다. 항목별 자재·비용·시간은 연구트리와 밸런스 원천을 읽는다. DNA 재료5종의 장소별 미션 수급과3품질은 DNA 합성용 규칙으로 유지한다.

연구원은 게임 시작부터 무료1명을 보유하고 추가 인원은 다이아로 영구 구매한다. 연구소 완공은 실제 기술 연구의 시작 조건이며 무료 인원을 다시 지급하는 시점이 아니다. 건설자는 기존 골드 고용을 유지한다. 인원별 구매/고용 조건·무료 개방·비용·최대 인원은 [밸런스의 인력 원천](balance.md)을 따른다. 시설/기술의 해금 조건과 실제 파크 보유 인원을 구별한다. 조건을 충족했다는 이유로 유료 인원이 자동 지급되거나 건물 레벨과 별도 인원 잔액을 중복 계산하지 않는다. 시작 지급과 무료 개방도 해당 이력에 한 번 적용하며, 유료 인원은 해당 재화 차감과 인원 증가를 함께 한 번 처리한다. 새 채용 재료·연료·별도 일일 임금·가챠는 추가하지 않는다.

| 작업 자원 | 점유와 반환 | 다른 작업과의 관계 |
| --- | --- | --- |
| 건설자 | 건설/강화 시작에 점유, 서버 완료 시각에 완공 처리와 함께 반환 | 인원이 더 있으면 다른 시설 공사 가능. 기존 완공 레벨로 운영하며 생산/탐험/부화/기술 연구/DNA 합성을 막지 않음 |
| 연구원 | 시작 무료1명·다이아 추가 구매. 완공 연구소에서 기술 항목 다음 단계를 연구하며 점유·완료 효과 적용은 연구트리 원천을 따름 | 공룡 개체를 배정하거나 잠그지 않으며 DNA 합성 슬롯을 사용하지 않음 |
| DNA 합성 슬롯 | 기존 기준 기본 한 슬롯, 결과 수령/실패 정산까지 합성 작업·선택 원종 잠금 유지 | 연구원 추가 구매로 늘어나지 않으며 기술 연구와 공유하지 않음. 병렬 합성/개체 중복 배정 정책은 미정 |
| 생산 시설 | 기존 시설당 한 작업과 미수령 보존 규칙 유지 | 건설자/연구원을 추가 점유하지 않으며 인원 증가가 생산 대기열을 늘리지 않음 |
| 부화 자리 | 기본 자리와 부화장 성능으로 정한 별도 수용량 | 연구원·DNA 합성 슬롯과 공유하지 않으며 채용이 무료 부화 자리를 늘리지 않음 |

작업 화면은 건설자·연구원의 사용 중/보유 수, 기술 항목의 현재/목표 레벨과 완료 상태, DNA 합성의 별도 진행/수령 상태를 구별한다. 기술 연구 비용·시간·효과는 연구트리와 밸런스, DNA 합성의 원종 보유/잠금·첫100% 예약·레시피별 실패 보호·원자 수령은 [DNA 기획](dna-and-collection.md#기술-연구와-dna-합성의-구분)을 따른다. 기술 연구에는 공룡 배정·잠금이 없다.

첫 합성은 기본 합성 슬롯으로 가능하고 연구원 추가 구매나 다이아를 필수 비용으로 넣지 않는다. 기존 보유 인원·해금·작업·완료 시각을 이관 때 보존한다. 장기 강화 중에 새 공사를 시작하려면 유휴 건설자가 있어야 하며, 인원 추가는 자동 반복/준비 대기열을 뜻하지 않는다.

## 7. 공룡 돌봄과 운영 비용

사료는 모든 종이 쓰는 단일 재고다. 초식·육식·어식에 맞춘 풀·고기·생선은 급식 화면의 표현으로 사용하고, 별도 재고 세 종류로 관리하지 않는다.

급식 한 번은 사료 한 단위를 사용해 현재 급식 효과를 적용하는 것을 기본 설계로 한다. 먹이를 줄 필요가 없는 상태에서는 소비하지 않는다. 큰 종의 유지 부담은 기존 개체 유지비에서 먼저 조정하고, 사료 품목·품질을 늘리지 않는다. 단위당 회복량 조정이 필요하면 밸런스 검산에서 함께 변경한다.

사료 재고가 있으면 급식 때 골드를 추가 차감하지 않는다. 재고가 없을 때는 기본 물자를 구매해 급식하는 비용을 먼저 보여주며, 구매·소비·상태 회복을 한 번 처리한다. 현재의 100골드 직접 급식에서 전환할 때 같은 행위에 구매비와 급식비를 중복 부과하지 않는다.

| 구버전 운영 항목 | 기본 운영에서의 처리 |
| --- | --- |
| 전력·물·시설 운영용 연료 | 골드 유지비에 포함. 별도 채집·충전·재고·공급망 퍼즐 없음. 탐험 행동 연료 탱크와 구별 |
| 발전소·저수지 | 이번 기본 자원 생산 목록에서 제외. 추후 운영비 절감 시설로 검토하며 신규 필수 게이트로 넣지 않음 |
| 청결도 | 소모 아이템 아님. 별도 수치·청소 플레이는 후속 운영 콘텐츠로 검토 |
| 육류 저장소·어류 양식장 | 별도 고기/생선 재고가 없는 기본 버전에서는 신규 필수 시설로 넣지 않음. 후속 사료 시설 확장 후보 |
| 창고 | 일반 자원 네 종류의 저장 한도를 높이는 역할 |

시설/개체 유지비는 관리·보안·용수·전력 등 운영 비용이고, 사료 생산/구매는 급식 재료 비용이다. 동일한 먹이 비용을 두 곳에 중복 산정하지 않도록 수치 이관 때 현재 유지비의 포함 범위도 확인한다.

## 8. 저장과 사용자에게 보여줄 정보

전체 설계의 재료함은 일반 자원 4개와 연구 재료 5개의 카드로 보여준다. 현재 부분 연결 화면에는 도입한 목재·석재만 표시하며, 나머지 재료가 이미 저장/생산된다고 표현하지 않는다. 연구 품질은 카드 안에서 펼치며 19개 품질/재고 조합을 같은 깊이에 나열하지 않는다. 아직 배우지 않은 재료는 필요해지는 시점에 소개한다.

탐험 연료는 기존 에너지 표시 자리를 이어받는 행동 재화와 보급소 작업 화면에서 보여주고 일반 재료 카드에 열 번째 항목으로 추가하지 않는다. 탱크의 현재량·최대량·다음 회복·출발 소비와 생산 미수령 상태를 구별한다. 골드는 보유 잔액/금고 한도를 표시하고 평생 누적 입장료는 운영 실적으로 분리한다. 금고가 찼을 때는 추가 유료 입장 중단과 지출·금고 확장으로 재개할 방법을 안내한다.

일반 자원은 창고 레벨로 정한 같은 종류별 한도를 사용한다. 네 종류 합계 한도로 경쟁시키지 않아 목재를 모았다는 이유로 사료가 들어가지 못하는 상황을 피한다. 연구 재료는 기본 버전에서 별도 창고 한도를 두지 않는다. 골드 금고·일반 자원 창고·행동 연료 탱크의 한도를 서로 대신 적용하지 않는다. 알은 부화 보관/슬롯 규칙을 따른다. 부패·유통기한·중량은 추가하지 않는다.

공통 재료의 저장량은 하나의 재료함이 소유한다. 생산 시설의 완료 배치는 미수령 보상이며, 창고 재고에 동시에 포함하지 않는다. 기본 구매·생산 수령·건설·급식이 같은 재고를 사용하도록 한다.

작업 화면은 필요한 재료·현재 보유·부족량·획득처를 함께 보여준다. 골드·재료·유휴 인원·시설 해금 중 부족한 것 하나만 숨기지 말고 전체 부족 조건을 표시한다. DNA 합성 화면의 실제 원종 보유와 도감 등록을 구별하고 현재 합성 작업이 잠근 개체를 표시한다. 기술 연구 화면은 공룡 선택 없이 기술 항목·다음 레벨·선행 조건·연구원을 보여준다.

## 9. 공룡 알·원종·이벤트 아이템

알은 재료 9종에 포함하지 않는다. 자연종을 얻는 부화 대상이며, 종이 지정된 목표 알과 등급 기반 일반 알을 구별한다. 공룡 희귀도 다섯 단계는 알 내용물의 등급이지 연구 재료 품질이 아니다. 변종·하이브리드는 연구 결과로 얻는 경로를 유지한다.

실제로 부화해 보유한 스테고·트리케라와 중급 연구 재료를 확보해 첫 합성을 한다. 첫 지정 합성의 영웅 스테고케라톱스 100% 성공·원종 보존·한 번 지급·도감 등록 원칙은 유지한다. 알만 보유한 상태는 원종 보유 조건을 대신하지 않는다.

스토리의 열쇠·일지·설계도·유물·이벤트 표본은 필요할 때 별도 추가할 수 있다. 기본 건설·급식·합성의 상시 필수 재료로 미리 늘려 놓지 않는다. 가속권·상자·스킨·프레임·칭호도 기본 재료 9종에 합산하지 않는다.

## 12. 구현 상태·이관·완료 기준

PLAY-02/03의 입장료·첫 관람대에 이어 PLAY-04/RES-01A에서 첫 조사/지정 알·수동 부화와 목재/석재 재고·기본 구매·생산·관람대 Lv.2 소비를 코드에 연결했다. 종합 UI·재접속 검증을 완료했다. 현재 시작 골드는10,000이고 탐험 에너지는 최대30·10분마다1 회복하는 기존 구현이다. 목재·석재는 종류별 기본 한도를 사용하고 생산은 선택 수량 전체를 수동 수령한다. 이0.5 문서 변경으로 새 금고 한도·연료 명칭/구매/보급소·25레벨 강화·건설자/연구원 채용·병렬 공사·기술 연구트리가 게임에 적용되지는 않는다. 금속·사료 재고/생산·창고·품질별 연구 재고·실제 DNA 합성 수령도 후속이다. 사료 공장 등 일부 시설 이름과 상점 item ID만으로 기능 완료로 판단하지 않는다.

이 설계 문서 변경으로 기존 계정의 골드·DNA·에너지·회복 시각·개체·배치·시설을 덮어쓰지 않는다. 금고와 행동 연료를 도입할 때는 이 문서3·5절의 한도 초과 보존·공통 잔액/회복 원천을 적용한다. 이후 구현에서는 기존 DNA를 하급 DNA로 1:1 보존하고, 이관 이력과 실제 재료함을 수량의 단일 원천으로 쓴다. 기존 dna API는 하급 DNA의 호환용 값이며 별도 이중 소비를 허용하지 않는다. 장기 누적 입장료/방문객 카운터의64비트 보존 이관과 API 표현은 밸런스의 진행·보존 계약을 따른다.

기존에 완료한 돌봄·시설·진행 이력은 재사용한다. 새 온보딩의 지급/구매 보정을 넣을 경우 계정별 적용 이력을 남기고 같은 물자를 반복 지급하지 않는다. 기존 건물의 자재를 소급 청구하거나 자료 정리만으로 기존 시설을 삭제하지 않는다.

완료 검증은 일반 자원 수급/자체 생산품 건설의 순환 막힘, 사료 비용 중복, 품질 혼용, 생산/미션/합성의 한 번 수령, 재료·골드 동시 차감, 저장 한도·미수령 보존, 원종 보존·도감 등록·배치, 기존 DNA와 계정 보존을 포함한다. 추가로 금고 다음 강화가 직전 한도 안에서 가능한지, 금고가 찼을 때 미수입을 쌓지 않는지, 연료 자동 회복·구매·생산 수령의 동시 처리와 이중 차감 방지, 생산 전량의 탱크 수용 가능성, 한도 축소/정상 환불의 기존 초과분 보존을 확인한다. 인원 확장은 동일 채용/무료 개방의 한 번 적용·보유 수 초과 공사/기술 연구 거절·동일 시설/기술 항목 단계 충돌·건설 완료와 기술 연구의 반환 시점·중복 완료의 인원/효과 이중 적용 방지·기존 고용 인원과 진행 작업 보존을 함께 검증한다. 기술 연구의 연구원 슬롯과 DNA 합성/원종 잠금·부화 자리가 독립적인지도 확인한다.

구매가·생산비·수량/시간·시설 비용과 해금·자재·창고/금고/연료 한도는0.5 밸런스 원천을 따른다. 이전 부분 구현의 단위/DB/UI 검사, 새 상세 수치의 설계 모델 검산, 전체 경로와 실플레이 판정은 TASK에서 구별한다. 목재/석재 재고를 연구 재료 재고와 별도 독립 경제로 늘리지 않고 이후 같은 재료함을 확장한다. 후반 시설·안정제/변이세포·상급 수급량, 구체 미션의 재미·조작·실제 플레이 시간은 후속 검증 대상이다.

## 변경 기록
