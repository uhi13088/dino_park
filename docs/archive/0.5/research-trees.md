# 기술 연구트리 기획 0.5

기준일: 2026-11-16 · 상태: 연구원 역할은 사용자 확정, 아래 12항목·효과·선행 조건은 구현 전 설계안 · [문서 안내](../../README.md)

## 1. 연구소·기술·연구원의 역할

연구소는 기술을 연구하는 시설이고, 연구원은 기술 항목 하나의 다음 단계를 진행한다. 기술마다 최대3 또는5레벨을 가진다. 연구원을 더 고용하면 **서로 다른 기술을 동시에 연구**할 수 있다. 한 기술의 여러 레벨을 동시에 연구하거나 연구원 여러 명으로 한 작업의 시간을 나누지 않는다.

| 구분 | 성장/작업 | 역할과 원천 |
| --- | --- | --- |
| 파크 레벨 | 기존 경험치 | 지역·시설·스토리의 해금. 연구 경험치를 별도로 만들지 않음 |
| 연구소 건물 | Lv.1~25 | 기술 단계 접근·기술/일반 합성 시간 단축·연구원 추가 고용 자격. [건물 수치](balance.md#5-건물별-성능) |
| 기술 항목 | 미연구0 → 각 최대3 또는5 | 완료한 기술의 파크 공통 영구 효과. 항목·선행·효과는 이 문서, 비용/시간은 [밸런스](balance.md#13-기술-연구-비용과-시간) |
| 연구원 | 시작부터 무료1명, 다이아 추가 구매로 최대5명 | 기술 연구의 병렬 작업 수. [고용 조건](balance.md#12-건설자와-연구원-고용) |
| DNA 합성 | 별도 기본1개 합성 작업 | 보유 원종과 탐험 재료로 새 공룡 획득. 연구원 슬롯을 쓰지 않음. [합성 기획](dna-and-collection.md) |

기술 연구는 100% 완료하며 공룡을 배정·소모·잠그지 않는다. DNA 합성은 기존의 등급별 성공률·실패 보호를 사용한다. 합성 결과 공룡의 개체 레벨·희귀도, 합성 재료의3품질, 건물25레벨, 기술3~5레벨은 서로 다른 정보다.

첫 스테고케라톱스는 기술 연구 없이 기존 조건으로 100% 합성한다. 아래 상위 기술·추가 연구원은 첫 영웅 이후의 선택 성장이다. 무료 연구원1명은 게임 시작부터 보유하고, 연구소 완공 후 기술 연구를 시작한다. 완공 때 추가 연구원을 지급하지 않는다. 기술 연구와 DNA 합성은 각각 진행할 수 있다.

## 2. 처음 공개할 연구트리

총4계열·12항목·48단계다. 계열 전체에 경험치나 별도 레벨을 붙이지 않는다. 같은 계열의 앞 항목을 전부 최대 강화할 필요 없이, 표의 선행 단계만 충족하면 다음 항목을 선택할 수 있다. 최대 레벨 연구를 다음 연구의 일괄 선행 조건으로 사용하지 않는다.

표의 선행은 해당 기술을 처음 시작하는 조건이다. 모든 레벨은 자기 직전 단계 완료·비용군의 연구소 레벨 조건도 필요하다. 첫영웅후=1은 첫 지정 영웅의 실제 합성 완료/수령 이력을 확인한다. 기술 연구로 파크 경험치나 공룡을 지급하지 않는다.

읽는 예: `연료 저장2 → 연료 회복1~2 → 정밀 채집1`로 반복 탐험에 투자하거나, `고급 유전자 분석1 → 배양 공정1~2 → 시료 보존1`로 합성 손실을 줄이는 방향을 먼저 고를 수 있다. 모든 계열을 동시에 올릴 의무는 없다.

### 운영

- **입장 수속:** 입구의 처리 상한만 올린다. 티켓 가격·관람대 정원·실제 공룡 수요는 늘리지 않는다. 최고 입구1000명/분이면 연구 최대에서1200명/분이며 실제 입장객은 수요·관람 정원·금고 여유까지 함께 제한한다.
- **시설 정비:** 가동 시설의 골드 유지비에 적용한다. 건설비·강화비·일회 생산 작업비·직원 채용비는 할인하지 않는다. 생산 대기 유지비0은 그대로0이다.
- **파크 홍보:** 실제 관람 가능한 공룡으로 만든 기본 수요에 적용한다. 푸드코트 보너스와는 더해서 기본 수요에 한 번 적용한다. 합성만 하고 미배치한 공룡은 홍보 수요에 포함하지 않는다.

### 사육

- **환경 적응:** 실제 배치된 호환 서식지의 돌봄 완화와 곱해 적용한다. 방치해도 상태가 전혀 줄지 않는 효과는 없다. 서식지의 물리적 최대9개체·식성·호환 규칙은 바꾸지 않는다.
- **사육 관리:** 모든 보유 공룡의 기존 유지비 대상에 적용한다. 연구를 이유로 미배치 개체에 새 유지비를 도입하지 않는다. 무료/유지비0 개체는 그대로0이다.
- **격리 연구:** 보안센터가 담당하는 위험 공룡 유지비에 추가 적용한다. 각 단계는 유지비 효율만 높이며 새 레시피의 필수 조건으로 추가하지 않는다. 보안센터·격리 서식지·위험 점수 한도는 여전히 필요하다. 첫 초식 스테고케라톱스·초반 자연 랩터·상위 합성은 이 연구를 필수 요구하지 않는다.

### 탐험

- **연료 저장:** 기본30 또는 보급소의 최고 완공 레벨 한도에 더한다. 최대 보급소120+기술15=135다. 새 연료 잔액을 만들거나 탱크 확장 때 연료를 무료 충전하지 않는다.
- **연료 회복:** 기본600초를 표의 간격으로 교체한다. 출발 비용5·보급소 생산 시간/수량은 바꾸지 않는다. 완성 시 이전 회복 간격으로 그 시각까지 정산하고, 남은 회복 진행률을 새 간격에 같은 비율로 옮긴다. 만료 시간을 소급해 중복 회복하지 않는다.
- **정밀 채집:** `반복 가능 DNA 수집 미션`의 성공 완료 보상에만 하급 DNA를 추가한다. 목표/스토리 첫 보장·첫 원종 알·촉매/배양액/안정제/변이세포·실패/중단은 제외한다. 새 보상 종류·품질을 추가하지 않고 자동 수집도 없다. 미션 시작 때 보상 버전을 고정하며 같은 미션에 한 번만 지급한다. 반복 미션 기본 보상량/조작 길이는 아직 설계 전이므로 전체 DNA 수급 속도는 이 표로 검증됐다고 보지 않는다.

### 유전

| 고급 유전자 분석 단계 | 새 권한 | 함께 필요한 조건 |
| --- | --- | --- |
| Lv.1 | 스피노랩터 등 영웅 하이브리드의 상위 레시피 분기 | 실제 공개된 레시피·원종·재료. 육식 하이브리드는 호환 격리 서식지·보안센터/위험 점수 |
| Lv.2 | 파라 룩스 등 영웅 변종 분기 | 연구소Lv.5·파크Lv.15·변이세포·해당 원종. 파라 룩스의 과거 발광 특성 연구/유전자센터 조건을 이 단계로 명시적으로 이관 |
| Lv.3 | 전설 변종·하이브리드 분기 | 연구소Lv.10·챕터6 이후·상급 재료·실제 레시피. 육식 하이브리드는 호환 격리 서식지·보안센터/위험 점수 |

상위 분기는 **레시피 사용 권한**이다. 연구 완료만으로 공룡이나 재료를 주지 않으며, 아직 레시피가 없는 종을 임의로 합성 가능하게 하지 않는다. 스테고케라톱스 레시피는 이 분기의 예외로 기초 연구소에서 제공한다. 첫 지정 보장 이후 반복 스테고 합성도 고급 유전자 분석을 추가 요구하지 않는다.

**배양 공정**은 반복 합성 시간을 줄이고 첫 지정100% 합성의30분은 그대로 유지한다. **시료 보존**은 필수 재료의 실제 종류·품질별 반환율만 바꾼다. 종류별 내림 때문에 촉매1개처럼 적은 수량은 여전히0개 반환될 수 있어 실제 반환 개수를 시작 화면에 보여준다. 안정제를 넣었으면 필수 재료100% 반환이 우선하며 안정제 자체는 소비한다. 성공률·확정 보호 시도 수·골드 반환은 바꾸지 않는다.

## 4. 효과 중첩·정산 기준

| 대상 | 최종 계산 |
| --- | --- |
| 방문 수요 | 기본 수요 × (1 + 푸드코트 증가율 + 파크 홍보 증가율). 두 효과 모두 최대면1.22배 |
| 입구 상한 | 입구 건물 상한 × (1 + 입장 수속 증가율). 입장료20 유지 |
| 돌봄 상태 변화 속도 | 기본 속도 × (1 - 해당 서식지 완화율) × (1 - 환경 적응 감소율). 최대0.76×0.90=0.684배 |
| 일반 공룡 유지비 | 기존 대상 유지비 × (1 - 사육 관리 감소율) |
| 위험 공룡 유지비 | 기존 대상 유지비 × (1 - 보안센터 완화율) × (1 - 사육 관리 감소율) × (1 - 격리 연구 감소율). 최대0.88×0.90×0.90=0.7128배 |
| 시설 유지비 | 가동 시설 유지비 × (1 - 시설 정비 감소율) |
| 기술 연구 시간 | max(밸런스의 단계별 최소 시간, 기본 시간 × (1 - 연구소 시간 단축률)의 초 단위 올림). 하한 없는 단계는 연구소 최대에서0.76배, 지정 후반 단계는 보정 후에도 최소7일 |
| 일반 DNA 합성 시간 | 레시피 시간 × (1 - 연구소 시간 단축률) × (1 - 배양 공정 감소율). 최대0.684배 |
| 첫 지정 DNA 합성 시간 | 기존 레시피30분 고정. 기술·연구소 시간 단축 제외 |
| 연료 한도 | 기본 또는 보급소 최고 완공 레벨의 한도 + 연료 저장 기술 효과 |

비율은 마지막에 한 번 적용한다. 작업 시간은 마지막에 초 단위로 올림하고 기존 입장료 정산의 소수 잔여는 보존한다.

기술의 효과는 파크당 한 번만 적용한다. 같은 연구소를 여러 개 짓거나 연구원 수를 늘려 효과를 곱하지 않는다. 기술 완료 시각까지 이전 효과로 입장료·유지비·돌봄·연료를 정산하고 그 이후 새 효과를 적용한다. 장기 오프라인 중 여러 완료가 있으면 시간순으로 정산한다.

이미 시작한 기술 연구·DNA 합성·탐험의 시간/확률/보상 버전은 고정한다. 나중의 연구소 강화·새 기술·추가 고용이 진행 중 작업의 완료 시각이나 실패 반환율을 소급 변경하지 않는다. 현재 태스크가 끝난 뒤 시작하는 작업부터 새 보너스를 사용한다.

## 5. 비용·시간과 첫 안내

기술 연구에는 **골드·목재·석재·필요시 금속**만 사용한다. 연구 포인트·책·별도 과학 재화·연료를 추가하지 않는다. 합성용 연구 재료5종은 DNA 합성에 남겨두고 기본 기술 연구로 소모하지 않는다. 레벨별 자재/연구소 요구·기본 시간은 [밸런스 표](balance.md#13-기술-연구-비용과-시간) 하나가 원천이다.

연구소Lv.1에서 세 계열의 첫 기술을 소개한다. 입장 수속1을 추천해500골드·목재5·석재5·기본1분의 짧은 선택 목표를 보여주되, 첫 합성 튜토리얼의 필수 단계로 추가하지 않는다. 첫 영웅을 받은 다음에는 ‘다음 공룡의 레시피 열기’와 ‘운영/탐험 효율 높이기’ 중 현재 목표에 맞춰 선택한다.

연구원은 시작부터1명이고 이후 다이아로 영구 추가 구매한다. 연구소 레벨은 추가 구매 자격만 열고 인원을 자동 지급하지 않는다. 첫 연구/첫 합성/기술 자체 해금에 추가 연구원 구매를 요구하지 않는다. 가격/조건은 고용 원천을 따르며 무료 다이아 수급에 따른 접근성은 아직 검증하지 않았다.

연구원2명 예: 한 명은 입장 수속3, 다른 한 명은 환경 적응2를 진행할 수 있다. 입장 수속3이 끝나기 전에 다른 연구원으로 입장 수속4를 예약하거나 같은3단계를 중복 연구할 수 없다. 연구원5명을 모두 얻어야 특정 기술이 열리는 조건은 없다.

초반 시간은 A군1분→5분→30분→2시간→6시간, 중간은 B군30분→6시간→1일→3일→7일, 전문 연구는 C군2일→4일→7일→10일→14일로 늘린다. 유전/격리 U군은30분→1일→7일이다. 모두 기본 시간이며 B5·C3~5·U3은연구소 단축 뒤에도 **그 단계 한 번이 최소7일**이다. 개별 기술의 최대3/5레벨에 해당하는 행까지만 사용한다. 초반 A3/5와 중간 B3은기초/중간 기술이므로 전문 장기 단계와 구분한다.

화면에는 계열별3개 기술 카드, 현재/최대 레벨, 다음 효과, 선행 조건, 실제 비용·시간, 연구원 사용 중/보유 인원을 보여준다. 잠긴 항목은 이유와 필요한 연구/시설을 바로 안내한다. 전 단계 표는 상세에서 펼치고 첫 화면에48단계 전체를 나열하지 않는다. 원종 보유 여부·합성 성공률·재료 품질은 DNA 합성 화면의 정보다.

## 6. 작업 상태와 보존

- `미연구/완료 n단계 → 다음 단계 연구 중 → 완료 n+1단계`. 서버 완료 시각에 기술 효과를 활성화하고 연구원을 자동 반환한다. 완료 알림을 누르지 않았다고 연구원을 계속 붙잡지 않는다.
- 시작 시 서버가 연구원 여유·직전 단계·선행 기술·첫영웅 이력·완공 연구소 레벨·골드/자재를 함께 확인해 한 번 차감/예약한다. 같은 항목의 중복 시작과 보유 인원 초과 작업은 실패하며 부분 차감은 없다.
- 초기 버전은 시작 후 취소·중간 환불·자동 반복·예약 대기열을 제공하지 않는다. 시작 전 확인 화면에서 비용/완료 시각을 충분히 보여준다.
- 연구소 강화 중에는 이전 완공 레벨의 조건/효과로 연구를 시작할 수 있고 진행 중인 연구는 유지한다. 연구소가 없어져도 완료 기술은 파크 지식으로 보존하며, 진행 중 작업을 삭제하는 시설 철거는 허용하지 않는다.
- 완료 레벨·연구 이력·연구원 고용 수는 파크가 소유한다. 효과를 별도 누적 보너스 잔액으로 저장하지 않는다. 동일 완료 요청/재접속은 레벨·효과·연구원을 재지급하지 않는다.
- 기존 합성/기술 해금이 있다면 권한 이관표로 보존한다. 기획 변경 때문에 이미 수집한 공룡·해금된 레시피·기존 개체를 잠그지 않는다. 단순 도감 발견만으로 새 연구를 전부 완료 처리하지 않는다.

## 7. 기존 자료에서의 승계와 구현 범위

구버전의 화석 분석·유전자 센터·진화 연구소 아이디어는 하나의 DNA 연구소 기술 분기로 정리한다. 파라 룩스의 ‘발광 특성 연구’는 고급 유전자 분석2로 매핑한다. 스피노랩터의 과거 ‘격리 연구’ 표기는 고급 유전자 분석1과 실제 안전 시설 조건으로 통합하고 선택 기술인 격리 연구를 중복 필수 게이트로 추가하지 않는다. 챕터6 전설 분기는 고급 유전자 분석3으로 매핑한다. 기존 자료의 별도 발전·발광 DNA·조합 실패0%·위인 시간 할인은 승계하지 않는다.

현재 `packages/game-data/src/research/`는 합성 레시피이며 기술 트리 구현이 아니다. 서버에는 이12항목의 기술 레벨·연구원·타이머 API가 아직 없다. 이 문서와 검산은 기획이며 플레이 가능 상태를 의미하지 않는다. 구현 때에는 기존 shared/game-data의 역할을 명확히 나눠 하나의 기술 카탈로그를 서버·클라이언트가 함께 사용한다.

먼저 운영/사육/탐험 첫 기술과 연구원1명 → 다음 단계/병렬 연구 → 상위 합성 권한 이관 순서로 구현한다. 완료 시간·중복 차감·정산 전환·권한 보존·첫100% 비의존성을 각각 검증한다. 전체 수급 속도·실제 선택의 재미·후기 진행 일수는 구현 후 측정하고 조정한다.
