# 다이노 파크 타이쿤 — 게임 기획 0.4

기준일: 2026-11-16 · 상태: 재정비 기준안·초반 흐름 순차 적용, PLAY-04/RES-01A 검증 완료 · [문서 안내](../../README.md)

## 1. 어떤 게임인가

**버려진 공룡 파크를 재건하고, 방문객의 입장료로 시설과 연구에 투자하는 수집·경영 게임.** 탐험으로 자연종을 만나고, 수집한 DNA를 합성해 변종과 하이브리드를 만든다. 새로운 공룡을 안전하게 전시하면 방문 수요가 늘고 다음 구역·연구에 투자할 수 있다.

앱인토스의 짧은 세션을 목표로 한다. 처음에는 파크를 열고 손님을 받는 경험을 완성하고, 이후 세션마다 운영·생산·탐험·연구 중 하나의 목표를 진행한다. 자원 종류·품질·생산/사용처는 [자원·생산 기획](resources-and-production.md), 운영·생산 수치는 [밸런스](balance.md), 공룡 획득과 개별 합성 레시피는 [DNA 기획](dna-and-collection.md)이 관리한다. 전체 건물의 역할 통합·최대5단계는 [건물 검토안](buildings.md)의 미승인 제안이며 현재 초반 Lv.1~2 구현과 구별한다.

### 사용자 확정 요구

- 도입은 창립자의 편지를 받고 15년간 버려진 파크를 재건하는 설정이다.
- 파크 외곽 경계와 입구가 보여야 한다. 서식지 울타리와 공원 테두리를 구분한다.
- 매출은 방문객 입장료다. 공룡을 골드 생산기로 취급하지 않는다.
- 배치·돌봄 → 입장료 → 시설 투자 → 두 번째 공룡을 짧은 튜토리얼로 잇는다.
- 탐험뿐 아니라 DNA 합성으로 변종·하이브리드를 얻는다. 레시피의 원종을 실제 보유해야 하며 결과 등급이 높을수록 실패율이 높아진다.
- 변종·하이브리드는 영웅 또는 전설 등급만 사용한다. 파라 한 마리로 시작하고 첫 지정 합성은 100% 성공해 모두 영웅 스테고케라톱스 한 마리를 획득한다.
- 합성 재료는 탐험으로 모은다. 연구소의 정기 채취나 자동 재료 생산은 추가하지 않는다.
- 탐험 장소를 선택하고 미션을 수행해 그 장소의 연구 재료를 얻는다. 구체적인 미션 조작과 재미는 검증 중이며, 대기 시간만 지난 것을 플레이 완료로 취급하지 않는다.
- 기본 운영 자원의 필요성·획득처·사용처를 먼저 연결하고 복잡도를 억제한다. 스토리·이벤트 아이템은 필요할 때 이후 추가한다.
- 이미 있는 에셋을 사용하고, 필요한 부분만 보충한다.

이번 기본 자원 설계는 일반 자원 4종과 연구 재료 5종, 총 9종이다. 품질은 연구 재료에만 적용한다. 이 구조와 공식·가격·연구 시간은 설계 기준안이며, 미정 수치와 실제 구현 상태를 담당 문서에서 구분한다.

## 2. 핵심 루프

```text
공룡 배치·돌봄 → 안전한 관람 환경 → 방문객 유료 입장 → 골드
       ↑                                             ↓
새 공룡 전시 ← 탐험 미션·알 부화 / DNA 합성 ← 시설·탐험·연구 투자

입장료 골드 → 일반 자원 구매·생산 → 자재로 건설 / 사료로 돌봄 → 운영 확장
```

탐험은 새로운 원종과 합성 재료를 찾는 경로다. 합성은 보유 원종과 탐험 재료를 사용해 원하는 결과를 연구하는 경로이며 등급별 실패와 재도전이 있다. 원종은 성공·실패 모두 소모하지 않는다.

일반 자원은 목재·석재·금속·공용 사료다. 이들의 생산은 골드와 시간을 사용하며, 탐험 에너지나 별도 미니게임을 요구하지 않는다. 전력·물·연료는 유지비로 처리하고 생산 건물이 직접 골드를 만들지 않는다.

## 3. 먼저 완성할 플레이 범위

한 파크, 시작 초원 구역, 파라사우롤로푸스와 이구아노돈, 입구·길·관람대, 첫 탐험·부화, 목표 카드까지 먼저 완성한다. 이어서 재료 종류·품질별 인벤토리·연구소와 첫 하이브리드를 연결한다.

82종·50명 위인·다섯 섬·시즌·결제·소셜은 과거 문서의 장기 목표다. 콘텐츠 데이터가 있다는 이유로 이번 구현량에 포함하지 않는다. 육식·격리·해양·야간 관람은 필요한 서식지와 동선이 준비된 뒤 확장한다.

## 4. 공간과 파크 운영

| 요소 | 동작 기준 |
| --- | --- |
| 외곽 경계 | 저장된 `Park.gridSizeX/gridSizeY`의 바깥선을 사용. 별도 토지 크기 입력이나 구매는 없음 |
| 입구 | 경계와 이어진 출입구. 개장/폐장, 누적 유료 입장객, 입장료 매출 표시 |
| 기본 길 | 입구에서 초원 관람 지점으로 연결. 손님은 길과 관람 지점에서만 이동 |
| 서식지 | 공룡의 생활 공간. 방문객 길과 분리. 호환 종·수용량을 검증 |
| 관람대 | 길에 연결된 관람 지점과 동시 관람 정원 추가. 건물 자체의 자동 골드 생산은 없음 |
| 연구소 | 탐험 재료·보유 원종·성공률을 확인해 합성. 완성한 공룡은 전시해야 방문 수요에 기여 |

개장에는 입구와 길, 관람 가능한 공룡, 돌봄 완료가 필요하다. 폐장·동선 단절·전시 공룡 없음이면 새 유료 입장은 없다. 손님이 입장할 때 한 번 결제하고, 관람·퇴장 때 다시 매출을 만들지 않는다.

신규 파크는 입구와 기본 길이 경계에 맞는 배치를 제공한다. 기존 계정의 배치·골드는 보존하고, 경계 도입으로 출입구 이동이 필요한 경우 무료 이동을 제공한다. 과거 저장 좌표를 일괄 덮어쓰지 않는다.

서버가 입장 인원·골드·정산 시각을 확정한다. 화면의 손님 수는 혼잡을 보여주는 연출이며 서버의 실제 정산 인원과 구별한다. 온라인·오프라인을 같은 규칙으로 정산하고, 예전 공룡 직접 수익을 함께 지급하지 않는다.

## 5. 첫 10분

| 순서 | 플레이와 목적 | 완료 조건 |
| --- | --- | --- |
| 파크 보기 | 닥터 진의 짧은 안내, 외곽 경계·입구·첫 서식지 확인 | 안내를 접어도 조작 가능 |
| 첫 친구 | 지급된 파라 배치·급식 | 서버의 배치·급식 기록 인정 |
| 재개장 | 길을 확인하고 개장, 손님과 첫 입장료 확인 | 검증된 유료 입장 실적 |
| 첫 투자 | 번 입장료로 관람대 선택·배치·건설 | 취소 시 무차감, 완공 후 관람 정원 증가 |
| 첫 탐험 | 완공된 첫 관람대 뒤 초원 정찰에서 단서 세 개를 직접 조사 | 순서에 맞게 단서를 확인한 뒤 이구아노돈 지정 알 한 개 수령 |
| 두 번째 친구 | 받은 알을 보관 → 기본 슬롯에서 수동 부화 시작 → 수령 → 파크 배치 | 부화 시간 경과와 개체 수령을 구분하고 새 개체·도감·목표 XP 한 번 처리 |
| 선택 확장 | 파크 Lv.2부터 벌목장·채석장과 목재·석재 구매/생산을 탐험과 병행 | 생산 시설은 첫 탐험의 필수 조건이 아니며, 재료를 모아 파크 Lv.3에서 관람대 Lv.2 확장 |
| 다음 목표 | 종 다양성에 따른 수요 변화, DNA 연구 예고 | 원종·재료 연구는 후속 범위임을 안내 |

첫 튜토리얼에서 별도 부화장 선구매를 요구하지 않는다. 기존 기본 부화 슬롯을 사용하고 부화장 확장은 후속 시설 기획으로 남긴다. 첫 급식은 현재 직접 급식 흐름을 유지하고 사료 재고/생산 전환은 후속으로 둔다. 첫 관람대는 골드만 사용한다. 탐험 미션의 조작 시간과 부화·건설의 서버 타이머를 구별하며 상세 가격·시간은 밸런스 문서에서 관리한다.

튜토리얼은 목표 카드 하나와 닥터 진의 짧은 단서 안내로 구성한다. 초원 정찰에서는 발자국·먹이 흔적·둥지를 구별하는 세 번의 선택을 서버가 순서대로 확인한다. 강제90초 대기나 타이머 자동 성공은 없고, 오답·재접속·같은 단계 재전송에 준비비를 다시 받지 않는다. 알은 직접 수령해 보관하고, 수동 부화 시작 후 정해진 시간이 지나야 새 개체를 수령한다.

튜토리얼 표시 진행은 기존 `User.tutorialStep`, 미션 조사 체크포인트는 해당 탐험의 단계가 소유하며 실제 보상은 알·부화·수령 이력으로 검증한다. 클라이언트의 튜토리얼 숫자만 올려 보상을 건너뛰지 못한다. 보유 골드 총액을 매출로 보거나, 이미 배치·급식한 유저에게 같은 행동과 시작 보상을 다시 요구하지 않는다.

관람대는 기존 Lv.2 해금을 유지한다. 첫 입장료 목표의 파크 경험치 보상으로 그 레벨에 도달하게 한다. 시설 해금은 `Park.level`을 기준으로 하며 `User.level`을 별도 시설 해금값으로 병행하지 않는다. 현재 서버의 파크 경험치 공식은 공유 함수를 사용한다. 이전 돌봄 이력(관람 가능한 공룡의 친밀도 양수)도 인정해, 오래 쉰 기존 계정에 첫 급식을 다시 강제하거나 낮은 행복도 때문에 개장을 영구 차단하지 않는다. 현재 돌봄 상태는 방문 수요에 계속 반영한다. 새 첫 이구아노돈은 건강한 부화 상태를 돌봄 완료로 인정해 목표 XP700을 한 번 받고, 추가 급식을 강제하지 않는다. 기존에 이구아노돈을 보유했거나 도감에 등록한 계정은 이전 진행을 인정하며 지정 알·XP를 다시 주지 않는다. 도감만 있고 방생했다면 튜토리얼 완료 인정과 현재 개체 보유를 구별하고, 재입수 미션은 후속으로 남긴다.

## 6. 첫 합성까지의 진행

첫 스테고케라톱스는 **여러 번 짧게 돌아오는 첫날 경과4~6시간, 조작40~60분**을 설계 목표로 삼는다. BAL-01 당시의 0.4 설계 모델은 집중 진행 약2시간30분,20~30분 주기 복귀 약5시간~5시간35분·조작 가정44~51분이었다. 이는 시작500골드·첫 미션 조작90초·생산 시설 파크 Lv.3을 입력한 과거 검산 기록이다. 현재 시작10,000골드·단서 선택 미션·생산 시설 파크 Lv.2의 게임 실측이나 최신 전체 경로 재검산으로 제시하지 않는다. 집중 진행을 늦추는 별도 잠금은 넣지 않는다. 미션·서사 길이는 가정이므로 실제 플레이 시간과 재미는 구현 후 측정해야 한다. 상세 접속 조건과 검산 범위는 [밸런스](balance.md)를 따른다.

| 진행 구간 | 공룡·탐험 | 시설·운영·스토리 |
| --- | --- | --- |
| 첫 10분 | 파라 돌봄 → 첫 정찰 → 이구아노돈 | 재개장 → 첫 관람대. 기존 첫 플레이 유지 |
| 원종 탐색 | 목표 미션으로 트리케라·스테고 알 확정 획득 | 목재·석재의 구매/생산 소개, 부화장·관람대 확장과 챕터 1 재건 |
| 부화·돌봄 | 원종 두 알을 실제 부화·보유 | 부화 대기 동안 일반 자원 생산·시설 정리·연구소 준비 |
| 첫 연구 재료 | 화석 계곡·원시 습지에서 DNA·배양액 확보 | 육식 서식지·보안센터와 챕터 2 안전 절차. 금속은 아직 필수 아님 |
| 연구 준비 | 버려진 연구소의 미션으로 촉매 확보 | 챕터 3의 지하 연구소·과거 사건·연구 방향 선택, 초식 하이브리드 서식지 준비 |
| 첫 합성 | 원종 보유·중급 재료·레시피 확인 → 첫 지정 합성 100% 성공 | 시나리오 3-6 영웅 스테고케라톱스 1마리 탄생·전시 |
| 이후 확장 | 금속·안정제·승급, 이후 변이세포·상급 연구 | 반복 연구부터 등급별 실패 적용, 상위 시설·변종 연구로 확장 |

이 표는 진행 순서다. 비용·필수 해금·타이머·목표 미션 보상량과 검산 결과는 [밸런스](balance.md)가 소유한다. 생산·건설·부화·합성의 시작한 타이머는 앱을 꺼도 진행하고, 탐험 미션은 플레이 진행 상태를 보존해 돌아와 이어 한다. 앱을 껐다는 이유로 미션을 자동 성공시키지 않는다.

첫 원종 알과 핵심 연구 재료는 각 목표 탐험의 첫 완료 보상으로 보장한다. 대화만으로 재료를 즉시 지급하지 않는다. 원종 알을 받았다는 이유로 합성을 허용하지 않으며 부화한 실제 개체를 보유해야 한다.

첫 스테고케라톱스의 장면과 챕터 순서는 기존 시나리오를 유지한다. 구버전의 수일~수주 잠금과 챕터별 시간 목표는 승계하지 않는다. 프롤로그·챕터 1~2·3-6까지의 대사와 미션 분량은 이 시간대에 맞게 편집하되, 사건·관계·선택의 결과는 보존한다. 원본 대사와 스토리 데이터는 아직 수정하지 않았다.

첫 관람대 해금은 파크 Lv.2, 관람대 건물 Lv.2 강화와 부화장·연구소 준비는 파크 Lv.3, 원종 두 종 돌봄 후 안전 시설은 파크 Lv.4, 챕터 2 안전 완료 후 첫 하이브리드 전시는 파크 Lv.5를 목표로 한다. 골드 총액만으로 스토리와 합성을 건너뛰지 않는다.

첫 합성 이후에는 원종 수집·탐험·재료 승급·연구를 반복하며 변종과 상위 하이브리드를 해금한다. 상위 레시피는 결과 등급에 따른 실패율과 재도전 규칙을 사용한다. 야간·해양·전설급의 구체적인 전체 진행 일수는 후속 검증 대상이다.

## 7. 시설 건설과 연구 조작

건설은 `선택 → 골드·자재·효과 → 배치 미리보기 → 확정 → 완공`으로 진행한다. 전체 점유 면적·경계·동선·공룡/건물 점유와 비용을 서버에서 함께 검사/차감한다. 첫 관람대와 초기 생산 시설의 골드 전용 예외·이후 자재 구분은 자원 기획을 따른다.

생산은 `일반 자원 선택 → 골드·수량·완료 시각 → 시작 → 완료 수령`이다. 급한 기본 물자는 골드로 구매할 수 있다. 사료 재고가 있으면 급식 때 골드를 다시 차감하지 않는다. 연구 재료는 이 구매/생산 경로에 포함하지 않는다.

연구는 `결과 공룡 선택 → 부족 재료 확인 → 탐험·재료 승급 → 합성 → 완료 수령 → 배치`다. 결과 종의 등급에 따라 실패율과 최대 시도 횟수를 표시하고, 실패 시 필수 재료 일부를 돌려준다. 원종 공룡은 유지하며 재료를 탐험으로 보충해 재도전한다. 변종과 하이브리드도 전시 수요에 기여하며 직접 골드를 주지 않는다.

## 8. 에셋

실물 자산 기준은 [임시 에셋 목록](../../../apps/client/public/assets/placeholders/README.md)이다. 과거 프롬프트 문서의 수백 종 파일은 제작 완료 자산이 아니다.

| 재사용 | 연결·보충 범위 |
| --- | --- |
| 파라 SVG | 이구아노돈의 머리·엄지 발톱·색상 등 구별 가능한 파생 SVG 연결 |
| 초원 서식지 SVG | 외곽 울타리·길 반복 요소 |
| 입구 게이트 SVG | 개장 상태·입장료 피드백 |
| 기존 SVG의 목재·잔디 표현 | 관람대·작은 방문객·알 |
| 파라의 몸체·동작 | 룩스 연구 단계에서 발광 볏·무늬·야간 표현 |

연구소와 스테고케라톱스는 해당 구현 단계에서 필요한 만큼 만든다. 지금 모든 공룡의 아트를 새로 생성하지 않는다. 다른 종에 파라 이름과 실루엣을 그대로 쓰는 대체 표현은 최종 완료로 보지 않는다.

1. **BAL-01 — 설계 검산 완료:** 일반 자원 구매/생산·자재 건설·직접 미션의 초반 수치안과 5경로 모델. 아래 구현 묶음에서 실제 연결·검증한 뒤 적용.

5. **DNA-01/02:** 연구 5종/세 품질·승급·연구소·첫 영웅 스테고케라톱스 100%·한 번 수령·도감·배치, 반복 실패·반환.
