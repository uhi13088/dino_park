# 건물 역할과 강화 단계 검토안

기준일: 2026-11-16 · 상태: 전체 건물 정리와 최대 5단계 강화에 대한 제안, 일괄 적용 전 · [문서 안내](../../README.md)

기능이 있는 건물은 **최대 5단계**, 순수 장식은 **강화 없이 외형 선택**으로 정리하는 방안을 권장한다. 초기에는 필요한 건물만 차례로 열고, 비슷한 기능의 건물을 여러 번 짓게 하지 않는다. 이 레벨 상한은 아직 확정·적용된 규칙이 아니다.

기존 카탈로그의 52종은 유지·통합·후속·신규 제외를 검토할 목록이다. 52종을 한꺼번에 구현하거나 모든 건물을 5단계까지 올리기로 승인한 목록은 아니다. 기존 계정의 고레벨 건물은 이 제안만으로 낮추거나 삭제하지 않는다.

## 2. 파크 레벨과 건물 레벨

**파크 레벨**은 새 시설·지역·기능의 해금 조건이다. **건물 레벨**은 이미 지은 한 시설의 수용량·생산량·저장 한도 같은 성능 단계다. 건물 이름의 연구 단계, 공룡의 희귀도, 재료 품질과도 구별한다.

현재 벌목장·채석장은 **파크 Lv.2에서 해금되는 건물 Lv.1 시설**이다. 각 최초 건설은 1,500골드·60초이며 두 시설 자체의 강화는 아직 열지 않는다. 관람대는 건물 Lv.1과 Lv.2까지만 연결하는 범위다. 현재 값의 원천은 [건물 카탈로그](../../../packages/game-data/src/buildings/index.ts)와 [초반 생산/관람대 설정](../../../packages/game-data/src/production/index.ts)이다. 관람대 Lv.2는 파크 Lv.3·3,000골드·목재20·석재10·120초로 연결하며 총 관람 정원은 기본12+관람대40=52로 교체한다. 밸런스의 벌목장·채석장 해금도 Lv.2로 맞추되, BAL-01의 당시 Lv.3 입력 결과는 역사적 모델 기록으로 분리한다. 이 부분 연결은 최대5단계·52종 전체 개편을 승인/검증한 뜻이 아니다.

권장 상한이 5라고 해서 모든 시설을 파크 Lv.5에서 해금하거나, 건물 5단계가 되면 전설 공룡을 자동 지급하지 않는다. 새 기능을 처음 이용하는 데 필요한 단계와 장기 투자 단계를 분리한다. 첫 합성을 위해 모든 기본 건물을 최고 단계로 올리도록 요구하지 않는다.

## 3. 최대 5단계 강화의 역할 제안

| 건물 단계 | 성장의 목적 | 적용 예 | 비용·잠금의 원칙 |
| --- | --- | --- | --- |
| Lv.1 | 그 시설의 기본 기능 시작 | 서식지 기본 수용량, 관람 지점, 생산 한 작업, 부화 자리 확장, 첫 연구 | 첫 관람대·최초 생산 시설의 골드 전용 예외 유지 |
| Lv.2 | 처음 느끼는 운영 여유 | 관람 정원, 생산/저장 효율, 부화 운영 편의 | 목재·석재를 필요한 시설부터 사용. 첫 탐험에 생산 시설 구매를 강제하지 않음 |
| Lv.3 | 중반 수집과 연구 범위 확대 | 여러 자연종 관리, 연구 분기·변종 연구 준비 | 금속은 첫 영웅 합성 이후에 소개. 별도 연구소를 중복 건설하는 잠금은 정리 |
| Lv.4 | 후반 운영의 병목 완화 | 많은 개체의 수용·돌봄, 상위 전시·격리 운영 보조 | 상급 자재라는 새 일반 재료 품질을 만들지 않음. 연구 재료 품질과 구분 |
| Lv.5 | 장기 투자 완성 | 최종 수용/효율·외형 변화 | 필수 기능의 반복 잠금보다 효율·선택적 완성에 집중. 상세 수치와 달성 일수는 후속 검산 |

모든 건물에 같은 보너스를 적용하지 않는다. 시설군별 주효과는 다음 하나를 중심으로 잡는다.

| 시설군 | 강화의 주효과 제안 | 확대하지 않을 기능 |
| --- | --- | --- |
| 서식지 | 해당 호환 종의 수용량·안전한 전시 환경 | 전 종 공통 수용, 원종 소비, 공룡 등급 자동 상승 |
| 관람 시설·입구 | 접근 가능한 관람 정원·처리량·전시 동선 | 건물별 시간당 골드 직접 지급, 같은 방문객의 중복 입장료 |
| 일반 자원 생산 | 같은 결과물의 생산량/단위비/작업 효율 중 필요한 항목 | 연구 재료 자동 생성, 에너지 소모, 여러 원료를 거치는 가공망 |
| 부화장 | 부화 자리·운영 편의 | 기본 첫 부화의 유료 잠금, 부화 완료만으로 공룡 자동 전시 |
| DNA 연구소 | 연구 분기·레시피 이용 조건·연구 편의 | 공룡 희귀도별 기본 확률을 임의로 덮는 무제한 버프, DNA 정기 채취 |
| 창고 | 일반 자원 종류별 저장 한도 | 연구 재료 15조합까지 강제 창고 과금, 네 자원이 하나의 총량으로 경쟁하는 구조 |
| 운영·편의 시설 | 해당 운영 문제의 완화 | 필수 자원 품목·단계 추가, 설치하지 않았다는 이유만의 반복 처벌 |
| 장식 | 배치와 외형 선택 | 강화 단계·자동 골드·첫 성장의 필수 잠금 |

생산은 현재 자원 기획의 **시설당 한 작업·1~3회분 선택·수동 수령·미수령 보존**을 유지한다. 상위 건물 레벨을 이유로 자동 재시작이나 무제한 생산 대기열을 함께 확정하지 않는다. 강화 후 점유 면적을 늘리려면 주변 점유와 무료 이동 처리도 필요하므로, 기본 권장안은 같은 부지에서 성능·외형을 개선하는 것이다.

## 4. 기존 52종의 정리 제안

**유지**는 독립적인 역할을 남기는 제안이고 즉시 구현을 뜻하지 않는다. **통합**은 다른 시설의 기능·강화·외형 선택으로 옮기는 제안이다. **후속**은 관련 운영이나 콘텐츠가 마련된 뒤 검토하며 초반 필수 조건에서 뺀다. **신규 제외**는 새 해금을 넣지 않는 방향이며 기존 저장 건물을 삭제한다는 뜻이 아니다.

분류 결과는 유지 22종(그중 장식 6종), 통합 14종, 후속 15종, 신규 제외 1종이다. 새 시설 후보 3종은 이 52종 집계와 별도로 다룬다. 유지 대상도 초반에 전부 지어야 하는 것은 아니다.

아래 최대 레벨은 모두 **현재 카탈로그 값**이다. 권장 5단계와 혼합해서 읽지 않는다. 도입 순서는 최신 진행 기획을 따르며 구버전 `unlockCondition.parkLevel`을 전체 재승인하지 않는다.

## 7. 확정이 필요한 부분과 이관 원칙

| 아직 정할 것 | 확정할 때 함께 확인할 것 |
| --- | --- |
| 최대 5단계 공통 상한 | 시설군별 예외, 현재 Lv.1/2 코드와 고레벨 기존 계정의 공존 |
| Lv.3~5 효과와 가격 | 관람 수요·정원 상한, 생산 투자 회수·실제 수요, 연구 진행 기간. 기존 25단계 비용식을 그대로 줄여 이식하지 않음 |
| 연구 시설 통합 | 파라 룩스 등 현재 해금 조건의 의미를 DNA 연구소 단계/연구 분기로 어떻게 대응할지 |
| 편의 시설의 효과 | 만족도·체류·수용 보정의 중복과 상한. 입장료 외 직접 수익 도입 여부는 별도 결정 |
| 부화장 상위 단계 | 현재 기본 1자리·첫 부화장 총 3자리 이후의 필요 슬롯 수 |
| 서식지 태그와 신규 후보 | 각 종의 실제 배치·격리 조건, 공유 타입·카탈로그·서버·도감 안내의 같은 기준 |
| 금속·사료·창고의 확장 | 기존 공통 재료함 재사용, 종류별 한도, 일괄 생산량·수령 보존. 새 재료 품목 추가 금지 |
| 장식·길·울타리 | 무강화 전환, 선택 외형, 기존 배치와 유료 구입 내역 보존 |

이 제안을 채택해도 다음 원칙을 지킨다.

- 기존 건물 Lv.6~25를 일괄 Lv.5로 자르거나, 통합 대상 건물을 자동 삭제하지 않는다. 기존 레벨·효과·소비 이력의 대응과 보존/보상을 먼저 정한다.
- 앞으로 얻는 새 건물의 단계 체계와 기존 저장 건물의 이관 버전을 구별한다. 승인된 매핑 없이 값을 덮어쓰지 않는다.
- 이미 지은 건물에 목재·석재·금속 비용을 소급 청구하지 않는다. 별도 재고로 쪼개지 않았던 전력·물·고기·생선도 이관 부채로 만들지 않는다.
- ATM 등 신규 해금 제외 건물과 통합 대상은 기존 저장·좌표·구입 내역을 유지하고 적용 방식을 따로 정한다.
