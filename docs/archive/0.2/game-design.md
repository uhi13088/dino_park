## 1. 어떤 게임인가

**버려진 공룡 파크를 재건하고, 방문객의 입장료로 시설과 연구에 투자하는 수집·경영 게임.** 탐험으로 자연종을 만나고, 수집한 DNA를 합성해 변종과 하이브리드를 만든다. 새로운 공룡을 안전하게 전시하면 방문 수요가 늘고 다음 구역·연구에 투자할 수 있다.

앱인토스의 짧은 세션을 목표로 한다. 처음에는 파크를 열고 손님을 받는 경험을 완성하고, 이후 세션마다 시설·알·연구 중 하나의 진행 결과를 확인한다. 운영 경제의 원천은 [밸런스](balance.md), 공룡 획득과 레시피의 재료·제작비·시간은 [DNA 기획](dna-and-collection.md)이 관리한다.

### 사용자 확정 요구

- 도입은 창립자의 편지를 받고 15년간 버려진 파크를 재건하는 설정이다.
- 파크 외곽 경계와 입구가 보여야 한다. 서식지 울타리와 공원 테두리를 구분한다.
- 매출은 방문객 입장료다. 공룡을 골드 생산기로 취급하지 않는다.
- 배치·돌봄 → 입장료 → 시설 투자 → 두 번째 공룡을 짧은 튜토리얼로 잇는다.
- 탐험뿐 아니라 DNA 합성으로 변종·하이브리드를 얻는다.
- 이미 있는 에셋을 사용하고, 필요한 부분만 보충한다.

그 외 공식·가격·연구 시간은 이번에 정리한 설계값이며 플레이 검증 후 조정한다. 현재 게임에 모두 적용됐다는 뜻은 아니다.

## 2. 핵심 루프

```text
공룡 배치·돌봄 → 안전한 관람 환경 → 방문객 유료 입장 → 골드
       ↑                                             ↓
새 공룡 전시 ← 탐험·알 부화 / DNA 수집·합성 ← 시설·탐험·연구 투자
```

탐험은 새로운 원종과 재료를 찾는 경로다. 합성은 필요한 재료를 목표로 모아 원하는 공룡을 만드는 경로다. 둘을 서로 대체하는 무작위 뽑기로 만들지 않는다.

## 3. 먼저 완성할 플레이 범위

한 파크, 시작 초원 구역, 파라사우롤로푸스와 이구아노돈, 입구·길·관람대, 첫 탐험·부화, 목표 카드까지 먼저 완성한다. 이어서 종별 DNA 인벤토리·연구소와 첫 하이브리드를 연결한다.

82종·50명 위인·다섯 섬·시즌·결제·소셜은 과거 문서의 장기 목표다. 콘텐츠 데이터가 있다는 이유로 이번 구현량에 포함하지 않는다. 육식·격리·해양·야간 관람은 필요한 서식지와 동선이 준비된 뒤 확장한다.

## 4. 공간과 파크 운영

| 요소 | 동작 기준 |
| --- | --- |
| 외곽 경계 | 저장된 `Park.gridSizeX/gridSizeY`의 바깥선을 사용. 별도 토지 크기 입력이나 구매는 없음 |
| 입구 | 경계와 이어진 출입구. 개장/폐장, 누적 유료 입장객, 입장료 매출 표시 |
| 기본 길 | 입구에서 초원 관람 지점으로 연결. 손님은 길과 관람 지점에서만 이동 |
| 서식지 | 공룡의 생활 공간. 방문객 길과 분리. 호환 종·수용량을 검증 |
| 관람대 | 길에 연결된 관람 지점과 동시 관람 정원 추가. 건물 자체의 자동 골드 생산은 없음 |
| 연구소 | 샘플 수집·합성 작업을 관리. 연구 중인 공룡이 손님 수에 즉시 포함되지는 않음 |

개장에는 입구와 길, 관람 가능한 공룡, 돌봄 완료가 필요하다. 폐장·동선 단절·전시 공룡 없음이면 새 유료 입장은 없다. 손님이 입장할 때 한 번 결제하고, 관람·퇴장 때 다시 매출을 만들지 않는다.

신규 파크는 입구와 기본 길이 경계에 맞는 배치를 제공한다. 기존 계정의 배치·골드는 보존하고, 경계 도입으로 출입구 이동이 필요한 경우 무료 이동을 제공한다. 과거 저장 좌표를 일괄 덮어쓰지 않는다.

서버가 입장 인원·골드·정산 시각을 확정한다. 화면의 손님 수는 혼잡을 보여주는 연출이며 서버의 실제 정산 인원과 구별한다. 온라인·오프라인을 같은 규칙으로 정산하고, 예전 공룡 직접 수익을 함께 지급하지 않는다.

## 5. 첫 10분

| 순서 | 플레이와 목적 | 완료 조건 |
| --- | --- | --- |
| 파크 보기 | 닥터 진의 짧은 안내, 외곽 경계·입구·첫 서식지 확인 | 안내를 접어도 조작 가능 |
| 첫 친구 | 지급된 파라 배치·급식 | 서버의 배치·급식 기록 인정 |
| 재개장 | 길을 확인하고 개장, 손님과 첫 입장료 확인 | 검증된 유료 입장 실적 |
| 첫 투자 | 번 입장료로 관람대 선택·배치·건설 | 취소 시 무차감, 완공 후 관람 정원 증가 |
| 첫 탐험 | 초원 정찰, 이구아노돈 알 확정 획득 | 첫 탐험 한 번의 보상만 지급 |
| 두 번째 친구 | 기본 부화 슬롯에서 부화·배치 | 알 소모와 새 개체 지급 한 번 |
| 다음 목표 | 종 다양성에 따른 수요 변화, DNA 연구 예고 | DNA 샘플·레시피 목표 화면을 확인 |

첫 튜토리얼에서 별도 부화장 선구매를 요구하지 않는다. 기존 기본 부화 슬롯을 사용하고 부화장 확장은 후속 시설 기획으로 남긴다. 탐험·부화와 관람대 건설의 첫 시간만 튜토리얼 전용 값을 사용한다. 상세 가격·시간은 밸런스 문서에서만 관리한다.

튜토리얼은 목표 카드 하나와 짧은 대화로 구성한다. 진행은 기존 `User.tutorialStep`을 사용하고, 보상 지급 이력만 별도로 관리한다. 보유 골드 총액을 매출로 보거나, 이미 배치·급식한 유저에게 같은 행동과 시작 보상을 다시 요구하지 않는다.

관람대는 기존 Lv.2 해금을 유지한다. 첫 입장료 목표의 파크 경험치 보상으로 그 레벨에 도달하게 한다. 시설 해금은 `Park.level`을 기준으로 하며 `User.level`을 별도 시설 해금값으로 병행하지 않는다. 경험치 공식의 기존 불일치는 연결 단계에서 한 기준으로 정리한다.

## 6. 첫 세션 이후

| 구간 | 플레이 목표 |
| --- | --- |
| 초반 운영 | 손님 대기·관람 정원을 보며 시설을 개선하고 새로운 자연종 획득 |
| 연구 준비 | DNA 연구소를 복구해 종별 샘플을 모으고 만들고 싶은 종의 재료 추적 |
| 챕터 3 | 시나리오 3-6의 스테고케라톱스로 첫 합성 완주. 단순 연구소 건설만으로 스토리를 건너뛰지 않음 |
| 변종·상위 연구 | 파라 룩스 같은 변종과 상위 하이브리드를 목표로 특수 DNA·안전한 전시 시설 확보 |

접속 시에는 입장료 정산, 돌봄, 건설·탐험·연구 완료 중 가까운 목표를 보여준다. 모든 카운트다운과 완료 수령 상태는 저장한다. 장기 해금까지 걸리는 일수와 콘텐츠 전체의 경제는 아직 검증하지 않았다.

## 7. 시설 건설과 연구 조작

건설은 `선택 → 가격·효과 → 배치 미리보기 → 확정 → 완공`으로 진행한다. 전체 점유 면적·경계·동선·공룡/건물 점유를 서버에서 검사하고 확정 시 골드를 차감한다. 첫 시설은 관람대 한 종으로 이 흐름을 끝까지 완성한다.

연구는 `결과 공룡 선택 → 부족 재료 확인 → 샘플 확보 → 합성 → 완료 수령 → 배치`다. 안정화된 레시피는 자원과 시간이 비용이며, 재료를 모두 잃는 확률 실패를 넣지 않는다. 변종과 하이브리드도 전시 수요에 기여하며 직접 골드를 주지 않는다.

## 8. 에셋

실물 자산 기준은 [임시 에셋 목록](../../../apps/client/public/assets/placeholders/README.md)이다. 과거 프롬프트 문서의 수백 종 파일은 제작 완료 자산이 아니다.

| 재사용 | 필요한 보충 |
| --- | --- |
| 파라 SVG | 이구아노돈의 머리·엄지 발톱·색상 등 구별 가능한 파생본 |
| 초원 서식지 SVG | 외곽 울타리·길 반복 요소 |
| 입구 게이트 SVG | 개장 상태·입장료 피드백 |
| 기존 SVG의 목재·잔디 표현 | 관람대·작은 방문객·알 |
| 파라의 몸체·동작 | 룩스 연구 단계에서 발광 볏·무늬·야간 표현 |

연구소와 스테고케라톱스는 해당 구현 단계에서 필요한 만큼 만든다. 지금 모든 공룡의 아트를 새로 생성하지 않는다. 다른 종에 파라 이름과 실루엣을 그대로 쓰는 대체 표현은 최종 완료로 보지 않는다.

## 10. 구현 순서와 완료 기준

1. **PLAY-02:** 경계·길·입구·손님·입장료. 폐장 시 새 입장 0, 중복 정산 없음, 온라인/오프라인 동일 계산, 기존 계정 보존.
2. **PLAY-03:** 관람대와 초반 밸런스 적용. 미리보기·차감·완공·수용량 증가를 실제 플레이로 검증.
3. **PLAY-04:** 확정 알·부화·두 번째 공룡·목표 카드. 신규 첫 세션 완주와 기존 진행 인정, 보상 중복 방지.
4. **DNA-01:** 종별·특수 샘플과 공용 DNA 역할 분리, 채취·레시피 화면·연구소, 기존 잔액 보존.
5. **DNA-02:** 챕터 3 첫 스테고케라톱스, 합성 비용·작업·수령·전시 검증.
6. **DNA-03:** 도감/카탈로그 불일치 정리, 파라 룩스와 상위 연구·전시 효과 연결.
