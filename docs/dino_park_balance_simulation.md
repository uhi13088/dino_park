# 1. 시뮬레이션 개요

## 1.1 목적

- 무과금 유저도 모든 콘텐츠 도달 가능한지 검증
- 과금 유저와의 적절한 격차 확인
- 성장 곡선의 지루함/급격함 포인트 발견
- 자원 병목 구간 식별
- 장기 플레이 동기 유지 검증

## 1.2 시뮬레이션 기준

| 항목             | 기준값            |
| ---------------- | ----------------- |
| 시뮬레이션 기간  | 365일 (1년)       |
| 일일 플레이 세션 | 3회               |
| 세션당 평균 시간 | 10분 (총 30분/일) |
| 광고 시청 의향   | 일 5회 (최대치)   |

## 1.3 핵심 지표 (KPI) - 조정 후

| 지표              | 조정 전 목표 | 조정 후 목표 | 허용 범위    |
| ----------------- | ------------ | ------------ | ------------ |
| 챕터 1 클리어     | 3일          | 3일          | 2~5일        |
| 챕터 6 클리어     | 90일         | **100일**    | 80~120일     |
| 첫 Lv.25 건물     | 329일        | **262일**    | 200~300일    |
| 전체 Lv.25 달성   | 730일        | **580일**    | 450~700일    |
| DAU 유지율 (D30)  | 20%          | **25%**      | 20~35%       |
| 중반 이탈률 (D90) | 40~50%       | **15~25%**   | 10~30%       |
| ARPU (월간)       | ₩3,000       | ₩3,500       | ₩2,500~5,000 |

> ✅ 조정 효과: 모든 핵심 지표 개선

# 2. 유저 세그먼트 정의

## 2.1 세그먼트 분류

| 세그먼트      | 월 과금액    | 비율 (예상) | 특징                   |
| ------------- | ------------ | ----------- | ---------------------- |
| 🐟 **무과금** | ₩0           | 70%         | 광고만 시청, 시간 투자 |
| 🐬 **소과금** | ₩10,000 이하 | 20%         | 월정액 + 가끔 패키지   |
| 🐋 **과금**   | ₩50,000+     | 8%          | 적극 과금, 시간 단축   |
| 🦈 **고래**   | ₩200,000+    | 2%          | 모든 것 즉시 구매      |

## 2.2 세그먼트별 일일 행동 패턴

### 🐟 무과금 유저

```
[일일 루틴]
06:00 - 기상, 오프라인 수익 수집 (광고 2배)
12:00 - 점심 세션, 공룡 먹이주기, 탐험 1회
21:00 - 저녁 세션, 미션 완료, 탐험 2회, 건설 체크

일일 광고 시청: 5회
- 오프라인 수익 2배 x1
- 탐험 추가 x2
- 부화 단축 x1
- 건설 단축 x1
```

### 🐬 소과금 유저

```
[일일 루틴]
기본 루틴 + 월정액 패스 혜택

월정액 효과:
- 광고 제거 (선택적 시청)
- 건설 슬롯 +1
- 일일 다이아 💎30
- 건설 시간 -25%
```

### 🐋 과금 유저

```
[일일 루틴]
기본 루틴 + 적극 다이아 사용

주요 과금 포인트:
- 건설 시간 즉시완료
- 프리미엄 공룡 구매
- 에너지 충전
- 시즌 패스 (프리미엄)
```

### 🦈 고래 유저

```
[일일 루틴]
시간 = 돈으로 해결

주요 과금 포인트:
- 모든 건설 즉시완료
- 모든 프리미엄 공룡
- 모든 패스 구매
- 자원 팩 대량 구매
```

### 월별 골드 추이 (무과금)

| 12개월 | 2,000,000 | 1,400,000 | 600,000 | 4,230,000 |

### 일일 골드 수입 공식

```
일일_기본_수입 = Σ(공룡별_기본수익) + Σ(건물별_수익) - Σ(유지비)

일일_실제_수입 = 일일_기본_수입 × (1 + 파크레벨_보너스) × (1 + 위인_버프) × (1 + 시너지_보너스)

파크레벨_보너스 = (파크레벨 - 1) × 0.02  // 레벨당 2% 증가
위인_버프 = Σ(배치된_위인별_수익버프)     // 위인별 상이
시너지_보너스 = Σ(활성화된_시너지)        // 공룡 조합에 따라

예시 (1개월차, 파크 Lv.5, 공룡 10마리):
- 기본 수입: 500/시 × 24시 = 12,000/일
- 파크 보너스: +8% (Lv.5)
- 위인 버프: +5% (기본 위인 1명)
- 시너지: +10% (초식 3마리 조합)
→ 일일 수입 ≈ 12,000 × 1.23 = 14,760 골드/일
```

## 수익 계산 공식

```
기본 수익 = 공룡 기본 수익 × (1 + (레벨-1) × 0.1)
상태 보정 = 행복도/100 × (배고픔 > 80 ? 0.5 : 1.0)
위인 보너스 = 1 + 배치된 위인 보너스 합
시설 보너스 = 1 + 시설 보너스 합

최종 수익 = 기본 수익 × 상태 보정 × 위인 보너스 × 시설 보너스
```
