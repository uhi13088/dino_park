
## 6.2 핵심 UX 플로우

```
[공룡 부화 플로우]
메인 파크 → 부화장 탭 → 알 선택 → 부화 시작 → (타이머) → 부화 완료 → 공룡 배치

[건설 플로우]
메인 파크 → 건설 탭 → 건물 선택 → 위치 지정 → 건설 확인 → (타이머) → 완료

[탐험 플로우]
메인 파크 → 탐험 탭 → 지역 선택 → 팀 편성 → 탐험 시작 → (타이머) → 결과/보상

[먹이주기 플로우]
파크 뷰 → 공룡 탭 → 먹이주기 → 애니메이션 → 상태 업데이트
```
